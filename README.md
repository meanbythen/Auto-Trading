# Auto-Trading 期货自动交易机器人

当前版本 **9.23.0**（2026-11-01）。更新记录在 `CHANGELOG.md`。

面向初学者的「同花顺期货通」辅助自动交易方案。  
**日内主策略：日内实体（ETH 开盘箱体 + 收盘突破）。另有「长线趋势加减仓」：日线定方向、60 分钟回调进出，可加可减。**  
华泰期货_CTP主席 · 沥青/玉米 · 模拟默认；未开通程序化 → 信号用数据计算，下单走 `sim`/`gui`。

## 版本

版本号写成三节：`大更新.功能更新.小更新`。现在是 `9.23.0`。

| 哪种改动 | 什么时候用 | 版本怎么变 |
|----------|------------|------------|
| 大更新 | 开仓、止损、反向或清仓规则变了，或者旧配置不能直接用。你要重新理解什么时候会下单 | `1.0.0` → `2.0.0` |
| 功能更新 | 多了一个能用的功能，原来的配置和用法还在 | `1.0.0` → `1.1.0` |
| 小更新 | 修错误、改文字、改间距、日志少刷。不改变哪根 K 线会开仓 | `1.0.0` → `1.0.1` |

一次修改里如果又加了功能、又改了开仓规则，按更高的那一档，也就是大更新，后面两节回到 0。

每次交给你用的修改，都在 `CHANGELOG.md` 最上面加一节：版本号、日期、以及你能注意到的变化。已经写过的旧版本不再改写。只提问、不改程序时，版本号不动。

窗口左上角会显示这个版本号。改完版本后要重新打开程序才能看到。

## 一、这个软件能做什么

1. **行情数据**：拉取指定合约分钟 K 线（如 `bu2612`）。配置页、历史回测页、策略优化页、交叉测试页都可以下拉选择行情来源，一次只用一家：新浪、东方财富，或天勤（天勤要账号密码登录，这一版只给分钟线）。点「按配置页重新填入」时，来源会和策略、品种、周期一起抄过去。读取最近一次历史回测时，交叉测试的来源也跟着那一次。5 分钟、15 分钟、30 分钟、60 分钟在新浪这边用 1 分钟拼出来，时间和同花顺图上一样，从这一段的开始算。1 分钟盖得到、并且分钟已经齐的那些 K 线，会换成拼出来的；更早的历史仍留在 `data/klines/market.sqlite`。选东方财富时直接用它给出的 K 线，并单独存放，不盖掉新浪已经存下的。选天勤时用它登录后取到的分钟 K 线，同样单独存放（后缀 `@tq`，例如 `fu2701@tq`），天勤的日线/周线这一版不提供，需要时切回新浪或东方财富。回测时天勤按服务端上限取满（免费账号实测最多约 10000 根，fu 的 5 分钟约能回到三月下旬），实盘只取最近 200 根。本地没有的新 K 线会补上，并刷新最后一根。对不齐周期整点、或者价格带一长串小数的K线会丢掉，避免演示数据混进 15 分钟线把 SAR 算歪。回测开始日期早于网上窗口时，用本地更早的K线接上；你选的整段都已在本地，并且结束日不是今天，就不再下载，直接用本地。开仓前不再额外对另一家，避免下单前多等一次
2. **策略引擎**：日内实体、早盘/趋势/均线，以及「长线趋势加减仓」（大小周期自相似：日线+60 分钟，或 60+15 分钟；浮盈可加、伸展先减）。配置页可改搭配与仓位参数；长线不跟总信号周期走。已删策略的旧配置项会在加载/保存时清掉  



3. **资金管理**：按每笔风险%算意图手数，再和仓位上限%取小  
4. **风控刹车**：仓位上限%、开仓间隔、日亏损熔断、紧急清仓  
5. **执行通道**：`sim` 模拟 / `gui` 点击同花顺 / `ctp` 华泰柜台（代码已通，配好前置与账号即可用）  
6. **状态持久化**：持仓与当日盈亏写入 `data/bot_state.json`，重启可恢复。文件里写明换了交易日，才把当日盈亏和报单次数清零一次并写回，持仓保留。没写交易日时只补上今天，不会把同一句日志反复刷出来。启动时还会以信号账户为准对一次账，账本还没有成交记录时跳过；有差异写 `ledger_reconcile` 事件  
7. **监控与下单模拟器**：心跳、事件日志、下单模拟器、图形控制台；每轮拉K后有「扫描解说」（最新K形态 + 是否符合开仓）  
8. **登录辅助**：点「启动常驻」会先打开软件、登录、确认下单界面，并把价格改成对手价。这几步不点买卖。都成功后才开始扫描，并且不再登录第二遍。每天 08:50 和 20:50，以及启动常驻、单次扫描，只要会登录，都会先看下单窗口。窗口里能看到「普通下单」或标题里的「CTP主席」就不点登录，避免把窗口关掉；看不到才登录一次。完整自检不会去点真实登录。价格没改成功，就不会点买卖。运行页「测试工具」里选「点击下单自检」，可以按你填的限价真的点一次同花顺，用来看委托能不能挂上；常驻扫描仍用对手价，这一笔不记入账户。  
9. **历史回测 / 策略优化**：用历史K线验证策略，网格搜索更优参数。结果里除了胜率、净盈亏、盈利因子、最大回撤，还有盈利覆盖、每笔收益、日均（算法和交叉测试相同），方便对照「赚的钱盖住回撤后还剩多少」  
10. **收盘复盘**：用当天真实行情给策略打有效性/稳定性/可信度；含 MAE/MFE/R、信号与实盘对照、缺陷诊断，并和近几日复盘、最近回测对照，补充历史优化与检验  
11. **账户分析**：从 1.8.0 起按程序自己的开仓价和平仓参考价自动记账，用来看策略成果。可以设置初始资金，也可以填入金、出金；和实盘对不上时用每日结算把余额改成你填的数。交易软件里已经平掉、程序还记着仓时，点「按实际价格平账」并填写实际成交价，只改程序的账，不会去点同花顺。配置页的账户权益只显示这个余额，不能在配置页手改。回测和优化可以另填权益来测保证金高的品种，也能从配置页抄回当前余额。不算滑点，也不扣手续费。没平掉的仓只展示，浮动盈亏先不进余额  
12. **交叉测试**：点「开始交叉测试」，只测配置页关注品种里的合约，每套配置里的参与策略都配一遍。左边列出这两份名单，都跟配置走。全品种主力连续写在 `config/全品种备查.txt`，只供查看，不参加这一轮。不看账户权益，也不看保证金，每个组合都按本页的持仓手数开，保证金高的品种不会因为钱不够被跳过。开仓限制只留每笔风险、持仓手数、开仓最小间隔和每天最多开仓。每笔风险不改开几手。周期、日期和行情来源用本页自己的数字，不跟某一次历史回测比，也不改正在用的策略。配置页的账户权益仍只给实盘和历史回测用。左边可以选行情来源、信号周期、止损周期、日期，以及收盘清仓和开仓限制，这些和历史回测页分开，改这里不会改历史回测页。行情来源这一轮只用选中的那一家。得分看盈利因子和净赚能不能盖住回撤，胜率不参与。净赚、盈利因子大于 1、成交不少于 5 笔，并且得分排在这些组合前四分之一的，标成「较好」。这只是这段历史上相对好看，不代表以后会赚钱。交易频率不参与筛选。备查文件里是上期所、能源中心、大商所、郑商所、中金所、广期所能做主力连续的品种。线材、胶合板、稻谷标成流动性偏少。你写进关注品种的合约仍会测。右边的表列出每个组合的品种、策略、胜率、盈利因子、最大回撤、净盈亏、盈利覆盖、收益率、交易频率、笔数、每笔收益、实际测试时段、开始时间、结束时间、天数、日均、K线根数、得分、流动性和结果。盈利覆盖＝净盈亏−最大回撤；每笔收益和日均都用盈利覆盖去除。胜率、收益率、实际时段、覆盖相关列和 K 线根数只供查看。净盈亏进得分。收益率用净盈亏除以这次占用最多的一笔保证金。保证金按开仓价×乘数×手数×10%估算，前后两笔不把保证金加总。实际时段是这次真正用到的第一根到最后一根，K线根数是信号周期有多少根。原油、国债这类带小数的报价也会按时间留在本地行情库里。列多的时候，结果表可以左右拖。测完可以点「导出本次交叉测试」，追加到 `data/Auto-Trading导出.xlsx` 的「交叉测试」表。每一行是一个品种和一套策略，第一列是这一轮的完成时间，同一轮再导出不重复。导出全部时也会带上这张表。导出成功后，界面上的结果表会清空，下次打开不再画这些行。Excel 里的记录还在。测的就是配置里的合约，例如 rb2701，不会改成 rb0。不会改正在用的策略，也不会改关注名单。运行页顶部显示当前选中的那一个，启动时也只盯这一个。同花顺一次只盯一个合约。开仓和止损规则不变

## 二、重要说明（请先读）

| 事项 | 说明 |
|------|------|
| 风险 | 期货有杠杆，自动交易可能快速亏损，请先用模拟盘 |
| 合规 | 请遵守期货公司与同花顺用户协议；部分券商禁止程序化外挂 |
| 稳定性 | **同花顺界面自动化**易受窗口位置、分辨率、皮肤影响，属于「辅助方案」 |

> 本项目是学习与工程骨架，不构成投资建议。实盘前请自行充分测试。

## 三、路线选择（两层菜单，保留多套可切换）

一次只跑一套策略 + 一个执行通道，用配置切换，**不删旧代码**。

### 1）先选执行通道 `trade.executor`

| 值 | 含义 | 何时用 |
|----|------|--------|
| `sim` | 模拟成交（默认） | 现在主用，不下真单 |
| `gui` | 鼠标点击同花顺 | 标定坐标后；未开程序化时的实盘路径 |
| `ctp` | CTP 柜台接口 | 认证、登录、确认结算单、报单、成交回报、对账、断线重连都已实现；华泰给了交易前置、BrokerID、认证码之后填上即可。现在的实盘仍用 `gui` |

### 2）再选策略引擎 `strategy.engine`

主推 **日内实体**（`daily_body`）。还保留：早盘 A/B、趋势跟随、SuperTrend、单/双均线。已删的旧引擎名（含缺口 C、SAR 翻转、均值回归、流动性耗尽等）会回退到日内实体。

| 值 | 含义 | 说明书 |
|----|------|--------|
| `daily_body` | **当前主推**：ETH 画开盘箱体，收盘突破才开；止损守箱体对沿，打破才平，否则拿到收盘；开盘跳空超过 50 点（可改，0 关闭）不开；箱体宽超过 100 点（可改，0 关闭）不开；日盘、夜盘各自有个开仓截止钟点（默认 10:30 / 22:15，可改），过了不再开；日盘第一段止损后、截止前可用第二段 ETH 箱体再开一次（eth_minutes2 默认 30，0 关闭），日盘上限 2 次、夜盘 1 次 | `strategies/daily_body.yaml` |
| `morning_box_a` / `morning_structure_b` | 早盘定方向两套（短名 `morning_a/b`） | `strategies/morning_*.yaml` |
| `trend_follow` / `supertrend` / `single_ma` / `dual_ma` | 经典对照策略 | 见 `strategies/` 同名 yaml |

```yaml
strategy:
  engine: daily_body   # 或 morning_box_a / trend_follow / …
trade:
  executor: sim       # 或 gui / ctp
```

推荐组合（技术还没给前置地址时）：**日内实体 + gui**。拿到地址后再改成 ctp。

### 3）华泰仿真测试

执行通道仍保持 `gui`。仿真测试用运行页的「仿真柜台测试」，不要把常驻扫描改成 `ctp`，避免策略单打到测试环境。点「连接登录」后登录在旁边进行，窗口保持可点；结果写在测试窗口下面。登录成功后，窗口会连上仿真行情，把最新价、买一、卖一、涨停价、跌停价显示在价格上面。这些是仿真柜台的价，不是同花顺上的实盘价。买开要填在买一和卖一附近，并且不能超出涨停、跌停。

若提示「端口能通，但柜台没有完成握手」，说明本机网络到了华泰地址，但仿真前置暂时没完成 CTP 握手——不是账号密码写错。过几分钟再点一次「连接登录」；仍不行就问华泰仿真环境是否可用。超时后程序会丢掉旧连接，下次会重新连，不会干等同一条死线。

已经写好的：

| 项目 | 内容 |
|---|---|
| 交易前置 | `tcp://59.36.3.115:27226` |
| 行情前置 | `tcp://59.36.3.115:27236`。测试窗口用它显示仿真报价 |
| BrokerID | `8080` |
| AppID | `client_AutoTrading_1.0` |
| 认证码 | 已放在 `config/secrets.local.yaml` 的 `ctp_auth_code`，不写在 config.yaml |
| 单笔最多 | 2 手。再多的单在本机拦住 |
| 报单、撤单提醒 | 各 8 笔。到了会在日志里警告 |
| 最小变动价位 | 1。沥青是 1。换成别的品种要改 `trade.ctp.price_tick` |

还要你自己填：`trade.ctp.user_id` 用指引里的仿真账号；`secrets.local.yaml` 另起一行 `ctp_password` 填这个仿真账号的密码。不要改原来的 `password`，那一行是同花顺用的。

测试窗口可以：连接登录、买开、卖平、撤最近一笔、暂停报单。点「错误合约」「错误价位」「超过手数」只会在本机拒绝，不会发到柜台。柜台退回来的资金不足、持仓不足、市场状态不对，会写进日志。日志文件在 `logs/auto_trading_日期.log`。

程序已经带上 CTP 6.7.11 的动态库，在 `ctp/api` 里。看穿式信息由这个正式库在认证时采集。

策略怎么找针、怎么止损，这次都没有改。

### 5.3 怎么做账户分析

1. 打开图形界面，点顶部「账户分析」。  
2. 左边「初始资金」和金额框、「初始化」在同一排。点「初始化」会先把现在这本账整份存进 `data/signal_periods`，再另建一本新账。新账期用新的存档，从现在按时间重新统计，余额改成你填的本金。同花顺里的真实持仓不会被平掉。存档没写成功时，当前账不会被清掉。「金额」旁边是「入金」「出金」。「实际余额」旁边是「每日结算」。还没有账时，程序第一次按信号开仓或平仓，会用当时配置里的账户权益当本金。  
3. 实盘有入金、出金时，在「金额」里填正数，再点「入金」或「出金」。  
4. 和实盘对账后如果差一截，把实际余额填进「实际余额」，点「每日结算」。差额会单独记一笔，已经记过的开平仓价格不动。  
5. 右边按「近1周 / 近1月 / 近3月 / 近6月 / 全部」看这一段的胜率、盈利因子、最大回撤和资金使用率。盈利因子是这段里赚到的钱除以亏掉的钱，和历史回测用的是同一个名字。资金使用率是这段保证金最高占用除以这段开始时的余额。下面按品种再列一遍。权益曲线看余额，每日盈亏看每天的柱子。盈亏日历按月显示每天赚亏，红字是赚，绿字是亏。再往下是每一笔资金变动记录。左边可以单独导出交易记录或资金变动记录。点「刷新」可以马上重看。常驻运行时，新的开平仓也会自己出现。  
6. 交易软件里已经平掉、程序顶部还显示持仓时，点「按实际价格平账」，填写实际成交价。程序账上的仓会清掉，这笔盈亏按这个价格算进余额。不会去点同花顺。运行页也有同一个按钮。

当前账本在 `data/signal_account.json`。每一本账期另外留在 `data/signal_periods`。从 1.8.0 这一版才开始记，更早的成交和以前手工记的账不会补进来。  
统计口径：同一品种、同一方向先开先平。盈亏 = 价差 × 合约乘数 × 手数。不扣手续费，也不把滑点算进去。沥青、玉米、螺纹默认乘数是 10，可在配置 `risk.contracts` 里改。  
当前余额等于全部资金变动相加。每一笔都会写明方式，只有五种：初始资金、入金、出金、每日结算差额、交易盈亏。这个余额会显示在配置页的账户权益上，配置页不能手改。下一笔按风险算手数时用它。  
历史回测和策略优化可以另填账户权益，方便测保证金高的品种。点「按配置页重新填入」会抄回这个当前余额。把回测限制写入配置时，不会把回测里手填的权益写成实盘余额。  
开仓、还没平的浮动盈亏、手续费，都不会单独改余额。滑点不单列，放进每日结算差额。点「初始化」会先把旧账存档，再开始新账期，不是在旧记录上改差额。  
没平掉的仓会显示在右边，浮动盈亏先不改余额，平仓后才算。  
模拟模式只看信号、不点击下单，这种单不会记进来。程序真的按信号开仓或平仓之后才会记。价格用的是程序自己的开仓价和平仓参考价，不是交易所成交价。

密码保存在 `config/secrets.local.yaml`（已加入 gitignore），不写进主配置。天勤的账号和密码在「配置」页「账号与登录」里填：账号写进 `data.tq.user`，密码只写进同一密钥文件的 `tq_password`（也可以设环境变量 `TQ_PASSWORD`）。天勤只提供分钟K线，周期选日线/周线会拉不到行情，配置页会变红字提示。  
回测时间段可选「全部可用 / 最近3、7、14天 / 自定义」。开始日期默认是当年1月1日（今年就是 2026-01-01），结束日期空着表示到最新。开始日期或结束日期只要填了，就会按填写的截取（时间段若还停在「全部可用」，程序会自动改成「自定义」）。「最近3/7/14天」仍以今天为准，不看日期框。公开的分钟线大约只有最近一千根。5 分钟大约能覆盖一个月，1 分钟大约只能覆盖最近几天。结果里会同时写明你选的区间、行情能给的区间和实际回测区间。

### 7. 同花顺自动点击下单（软件已打开时）

华泰未开程序化时，机器人用「鼠标点你的同花顺界面」下单。

1. **保持期货通已登录**，打开下单面板（能看到买开/卖开/手数），**之后不要移动窗口**。
2. **标定坐标**（二选一）  
   - 双击 `标定坐标.bat`  
   - 或打开图形界面 → 配置页 →「标定下单坐标」  
   窗口打开时就会带上「保存到配置」和「退出」，不用再自己拉高。从主界面点「标定下单坐标」时，只弹出这个窗口，不再旁边再开一个黑框。  
   点「开始记录」后 3 秒内把鼠标移到目标上停住（价格→手数→买多→卖空→平仓），录完点「保存到配置」。
3. **图形界面里**：执行通道改成 `gui`，**模拟模式先保持打开**，点保存，再点启动。  
   有信号时日志会出现 `[模拟点击] ...`，**不会真点鼠标**。
4. 确认无误后，再**关掉模拟模式**并保存，才会真实点击下单。
5. 点「启动常驻」。它会先打开软件、登录、确认下单界面，并把价格改成**对手价**，不点买开、卖开、平仓。这些都成功才开始扫描。每天 08:50 和 20:50，以及每次启动，只要会登录，都先看下单窗口：里面有「普通下单」或「CTP主席」就不登录，没有才登录一次，然后再核对对手价。登录过程中不会同时点买卖。完整自检不点真实登录。价格没改成就不下单。要检查点击是否真的生效：运行页「测试工具」→「点击下单自检」，把价格填得离现价远一些。

启动常驻后的**第一轮扫描**会多做一次「回溯补开仓」：最多往前看 3 根已收盘信号 K 线。若当时有开仓信号，并且同时满足——信号出现不超过 20 分钟、现价离开仓价不超过 0.5 倍 ATR、从信号到现在没碰到当时的止损——就会补开一笔。之后每轮仍只看最新一根，不会反复补。**程序里已经记着持仓，或这根信号已经开过仓时，不会再补。**配置项在 `strategy.catch_up_on_start`，把 `enabled` 改成 `false` 可关掉。
6. **紧急停止**：把鼠标快速甩到屏幕**左上角**。

注意：软件已打开时程序只激活窗口、不敲账号密码；换分辨率/挪窗口后必须重标。

### 7.5 实盘挂机：品种与策略选择优化流程（最终流程）

这一节是**准备实盘挂机时**该怎么选品种、选策略、调参数的完整顺序。后面第 8 节起是各页的细用法。请按阶段做，不要跳到「写入配置 → 实盘」就结束。

**先记住四条总原则**

1. 程序**一次只盯一个合约**（配置页关注名单里当前选中的那一个）。名单里可以有很多合约，挂机只跑选中的这一个。  
2. **交叉测试**是「固定参数 × 多合约 × 多策略」的对照筛选，用来缩小候选；**不是**多品种交叉验证。  
3. **策略优化**才是调旋钮：训练段挑参数，检验段只验收；还可滚动前进、再拿到其它关注品种上原样验收。  
4. 回测和优化**再好看也不等于以后赚钱**。公开分钟线往往偏短，写入后必须先模拟、再小仓。

**和公开渠道常见软件/说法怎么对照**

| 公开渠道常见做法 | 本程序现在有没有 | 说明 |
|------------------|------------------|------|
| 粗筛多品种×多策略矩阵 | 有（交叉测试） | 和「对照筛选」一类，不是参数交叉验证 |
| 单组合历史回测 | 有（历史回测） | 看成交和回撤 |
| 训练 / 检验切断 | 有（一次切断 + 可调检验比例） | 默认约 7:3，接近常见 3:1～4:1 |
| 滚动前进（走一步再验一步） | 有（滚动前进） | 类似 MultiCharts / 开拓者滚动样本外 |
| 拼接检验段成绩 | 有 | 结果里「检验成绩」是各段拼起来的 |
| 检验效率（检验÷训练） | 有 | 滚动时低于约 0.30 不能写入；一次切断也会显示 |
| 检验段赚钱比例 | 有（滚动） | 赚钱段不到一半不能写入 |
| 参数是否乱跳 | 有（滚动） | 结果里写「参数稳定」说明 |
| 多品种样本外验收 | 有 | 优化结束自动做；交叉测试页也可再点 |
| 手续费 / 滑点压力测试 | 无 | 当前回测不算滑点和手续费，实盘要更保守 |
| 蒙特卡洛打乱成交顺序 | 无 | TradeStation 一类有；算力大，暂不做成默认 |
| 多策略组合加权（CTA 组合） | 无 | 本程序一次挂一套策略、一个合约 |
| 把别人的神秘指标整包搬进来 | 不做 | 开仓规则不能随便换；要用另开需求 |

结论：流程骨架已经和公开「严肃一点的零售量化」对齐。这次补上的是他们常看的**检验效率、检验段赚钱比例、参数稳不稳**，写进策略优化结果，并在滚动前进时当作能不能写入的门槛。不另抄一套来路不明的策略当「圣杯」。

```
配置关注名单
    ↓
交叉测试粗筛（哪些合约配哪套策略相对好看）
    ↓
历史回测细看（单组合：成交、回撤、开关）
    ↓
策略优化（训练 / 检验；可选滚动前进）
    ↓
多品种验收（同一组参数拿到其它关注合约上）
    ↓
写入配置（策略参数 + 开仓限制分开写）
    ↓
模拟挂机 → 测试工具里点「点击下单自检」 → 小仓实盘
    ↓
每日复盘 + 账户分析（不对就停、回溯版本）
```

#### 第 0 步：挂机前硬件与通道

1. 同花顺期货通能登录，下单面板露出来，窗口位置固定。  
2. 配置页填好软件路径、账号；需要点击下单时执行通道选 `gui`，先标定坐标。  
3. 账户分析里初始化本金（或沿用已有账）。配置页的「账户权益」只显示余额，不能在那里手改。  
4. **模拟模式先打开**，保存。在确认点击可靠之前，不要关模拟。

#### 第 1 步：定关注品种名单（候选池）

1. 打开「配置」→「关注品种」。  
2. 只加你愿意盯、也流动性够的**具体月份合约**（如 `rb2701`、`bu2612`），不要一次塞满全市场。  
3. 全市场主力连续名单只在 `config/全品种备查.txt`，**交叉测试不会自动测那份**。  
4. 点保存（或添加移出后程序会写入）。名单会同步到历史回测、策略优化、复盘的品种下拉。

#### 第 2 步：交叉测试粗筛（先缩小范围）

目的：在**同一套配置参数**下，看「哪个合约 + 哪套策略」这段历史上相对好看。

1. 打开「交叉测试」。左边应能看到配置里的参与策略和关注合约。  
2. 选行情来源、信号周期、止损周期、时间段；收盘清仓按你的习惯。  
3. 开仓限制用本页的持仓手数等（交叉测试不看账户权益和保证金，避免高保证金品种被跳过）。  
4. 点「开始交叉测试」，等跑完。标成「较好」的 = 净赚、盈利因子大于 1、成交不少于 5 笔，且得分在本轮前四分之一。  
5. 导出到 Excel 后，界面表会清空；Excel 里还在。从「较好」里记下 **2～5 个候选组合**（合约 + 策略名），不要只认一个。  
6. **不要**在这一步就把实盘策略改掉。交叉测试不会改正在用的策略。

#### 第 3 步：历史回测细看（单个组合说清楚）

目的：对每一个候选组合，看成交密不密、回撤能不能接受、开关是否合理。

1. 打开「历史回测」。  
2. 策略、品种、周期、时间段改成候选组合；或点「按配置页重新填入」再改。品种用下拉，和关注名单同一份。  
3. 打开「启用限制」，手数、日亏损等尽量接近你准备实盘用的数字；需要对比时再关掉限制看固定 1 手。  
4. 点「开始历史回测」。看净盈亏、盈利因子、最大回撤、成交明细。  
5. 不满意就换下一个候选；满意的留下，准备优化。  
6. 需要把本页测完的内容写进实盘配置时，再点「把本页参数写入配置页」：策略、品种、周期、行情来源、三个开关和开仓限制一起写（不会把回测里手填的权益写成实盘余额，也不写回测日期）。

#### 第 4 步：策略优化（调参数，必须过检验）

目的：在**已选定的合约 + 策略**上搜参数；检验段和其它品种通不过就不能写入。

1. 在历史回测页点「把条件同步到策略优化页」（策略、品种、周期、时间段、行情来源一起过去）。  
2. 打开「策略优化」：  
   - **检验比例%**：默认 30（训练大约七成），可填 10～50。  
   - **检验方式**：先用「一次切断」；样本够长再试「滚动前进」（默认 3 段，更久更严）。  
   - 搜索深度：先「精简」或「标准」；「完整」组合多、更慢。  
3. 点「开始策略优化」。结果里会分开写 **训练成绩** 和 **检验成绩**（字段和历史回测整体结果一样）。  
4. 看 **稳健性**：检验效率（检验净盈亏÷训练净盈亏）。滚动前进时还看检验段赚钱比例、参数稳不稳。赚钱段不到一半，或效率过低，不能写入。  
5. 同时看 **多品种验收**：同一组参数在其它关注合约上的成绩。超过一半大亏，程序不允许写入。  
6. 只有提示可以写入时，再点「把最优参数写入配置」。  
   - 这只改**这一套策略的参数**（和相关开关），**不会**自动改正在用的策略名、品种、周期。  
   - 策略、品种、周期和开仓限制仍要另点历史回测页「把本页参数写入配置页」。  
7. 写入前会自动留参数版本；坏了可在策略优化页「回溯」。

若检验不过：换时间段、换候选组合、或先别写入，继续用出厂/上一版参数。

#### 第 5 步：多品种验收（可选再验一次）

优化结束已经自动验过其它关注品种。若要单独再跑：

1. 打开「交叉测试」→「用最近优化参数做多品种验收」。  
2. 这是**参数原样**拿到关注名单上跑，不再搜旋钮。  
3. 和「开始交叉测试」不是同一件事：那边是固定配置参数的对照筛选。

#### 第 6 步：定实盘「盯哪一个、用哪一套」

1. 打开「配置」：  
   - 策略引擎改成你决定挂机的那一套。  
   - 关注名单里**选中**要盯的那一个合约（排到当前）。  
   - 信号周期、止损周期、收盘清仓按回测/优化时用的来。  
   - 执行通道：模拟阶段用 `sim` 或 `gui`+模拟开；真点击前用 `gui`。  
2. 点「保存全部配置」（会再留一份配置存档）。  
3. 顶部状态栏确认：策略名、当前合约，就是你要挂的那一对。

#### 第 7 步：模拟挂机与点击自检

1. **模拟模式打开**，保存 →「运行」→「启动常驻」。看扫描解说、有没有乱开仓。  
2. 需要测真点击时：先**停止常驻**→「测试工具」→「点击下单自检」，价格离现价远一点，核对委托后撤单。  
3. 也可跑 `挂机前自检.bat`（配置和坐标，不按限价下单）。  
4. 模拟观察至少若干个交易时段，账户分析里应能看到程序记下的开平（模拟模式若不点击，则不会记进信号账户——以你当前通道为准）。

#### 第 8 步：小仓实盘挂机

1. 确认同花顺面板合约与程序当前合约一致。  
2. 关掉模拟模式并保存；执行通道 `gui`；每笔风险、仓位上限%、日亏损先偏保守。  
3. 「启动常驻」。启动后只盯状态栏那个合约。  
4. 盘中定期对一下同花顺真实持仓与顶部「程序持仓」。软件已平、程序还记着时，用「按实际价格平账」。  
5. 出问题：紧急清仓 / 鼠标甩到屏幕左上角；策略优化页可回溯参数；配置页可一键应用旧存档。

#### 第 9 步：挂机后的日常闭环（不要停）

| 频率 | 做什么 |
|------|--------|
| 每天收盘后 | 「复盘」看成绩单、信号质量与缺陷；对照账户分析和近几日基准 |
| 每周 | 看账户分析胜率、盈利因子、回撤；导出 Excel 留档 |
| 换月 / 换合约 | 改关注名单当前合约并保存；必要时再跑交叉测试和回测 |
| 连续亏或行为异常 | 先停常驻 → 复盘 → 回溯参数或换回上一份配置存档 → 再模拟 |

**不要做的事**

- 只看交叉测试「较好」就实盘，不做检验段优化。  
- 检验段或其它品种大亏仍强行写入。  
- 关注名单留很多合约，却以为会同时挂机（实际只盯选中的一个）。  
- 优化写入后不保存配置、不核对状态栏策略和合约。  
- 一上来就关模拟、放大手数。

按上面 0→8 做完，才算走完「选型 → 优化 → 挂机」；第 9 步是长期维护。各页按钮和数字的细说明见下面第 8 节起。

#### 单品种挂机 vs 多品种组合（要不要新开项目）

本仓库（Auto-Trading）定位是：**一套策略 + 同花顺点一下盯一个合约**的挂机闭环。关注名单可以很长，但启动常驻时**只盯当前选中的那一个**；执行通道 `gui` 也是点一个下单面板，做不到同时给十几个合约排队下单。

| 能力 | 放进本仓库？ | 原因 |
|------|--------------|------|
| 交叉测试、优化、多品种验收（研究） | 已在本仓库 | 只做回测对照，不要求同时下单 |
| 动量 / CTA 组合 / 机器学习选因子的**研究回测** | 可另开模块，不建议塞进现有挂机循环 | 数据、打分、持仓权重和流动性耗尽不是同一套 |
| 多品种**同时监控并同时下单** | **不适合硬塞进本仓库的 gui 挂机** | 同花顺点击通道天生单合约；要组合下单应走 CTP/API |
| 完整多品种组合实盘系统 | **建议新建项目** | 产品目标、风控、下单、界面都不同，合在一起会互相拖累 |

共享可以复用、不必重写的：行情拉取与本地 K 线库思路、回测绩效字段、账户记账口径、版本与导出习惯。  
不能直接复用的：gui 坐标点击下单、`bot_state` 单策略持仓卡片、一次只盯一个合约的启动逻辑。

若要做多品种组合：新建项目（例如 `Futures-Portfolio`），研究阶段可先只做信号与纸面组合，开通程序化后再接 CTP。本仓库继续专心单品种可靠挂机。

### 8. 历史回测与策略优化

**历史回测**（用当前策略参数，在历史K线上模拟开平仓）：

```powershell
python tools/run_backtest.py
# 或双击 历史回测.bat
# 或界面「历史回测」
```

报告：`data/backtest_last.json`（胜率、净盈亏、盈利因子、最大回撤、每笔明细）。  
界面「历史回测」页跑完后，可点「导出本次历史回测」，追加进 `data/Auto-Trading导出.xlsx` 的「回测摘要」和「回测成交」。两张表第一列都是「回测时间」，就是这次回测跑完的时刻，同一次的摘要和每一笔成交用同一个时间。以前导出的行会留下。回测时间和其他内容都相同的一行不会重复写。更早导出、还没有这一列的行，如果和这次完全一样，会补上这次的时间，不另起一行。

程序正在跑的时候也可以点回测。下载行情最多等大约 20 秒。开始日期比网上能给的更早时，程序会先下载新K线，再和本地库接在一起：本地已经有的K线优先保留，网上多出来的新K线补在后面。你填的开始日到结束日在本地都已经有，并且结束日不是今天，就直接用本地，不再下载。新浪没有按时返回时，同样改用本地库，再按日期截取。两段行情中间如果缺了交易时段里的 K 线，结果区会写「中间断了」，回测仍会计算，但空档里的涨跌不算进去。午休、夜盘间隔、周末和休市日不算断开。结果区会写出回测结果或失败原因，不会一直停在「请稍候」。如果现在这个窗口已经卡住，先点停止再重新打开程序，旧的那次下载还停在旧代码里。

启动、历史回测、策略优化、复盘各自拿一份配置副本。在历史回测页改策略或限制，不会改到配置页，也不会改到已经在跑的程序。只有点「保存全部配置」、点「一键应用选中的配置」、点「把本页参数写入配置页」或点「把最优参数写入配置」时，才会写进配置文件。

配置页的「保存全部配置」会把这一页上的数字和开关都写进配置文件，并按「关注品种-策略名称-时间」再留一份，例如 `fu2701-日内实体-2026-10-27 12:58:03`。份里包含策略、周期、品种、收盘清仓、模拟模式这些开关。密码不写进这份存档。在「配置存档」里选中一份，点「一键应用选中的配置」，页面会整页换回去。常驻正在跑时不能应用。应用之后要先看一眼开关，再重新启动，已经在跑的程序不会自己换成新开关。最近 30 份留在 `data/config_presets.json`。下拉框里不想要的那一份可以删除，删的只是备份，不会改当前配置。这和策略优化页的参数版本不是同一份：策略优化页只改当前选中的那一套参数。

历史回测页和策略优化页用同一组开仓限制，改一边另一边会跟着变。策略优化打分也按这组限制算手数。「启用限制」关掉后，每笔固定 1 手，不看止损距离、日亏损和开仓次数，用来和打开限制的结果对比：

- 仓位模式 `risk_pct`：手数 = 权益 × 每笔风险% ÷（止损距离 × 合约乘数）。算出来不够最少手数就不开，结果里记「止损过宽」。
- 仓位模式 `fixed`：用固定手数，再和仓位上限%取小。
- 关注合约、保证金和手续费写在同一张表：`config/品种与合约.xlsx`（列：合约代码、中文名、每手保证金、乘数、每手手续费、平今手续费、启用）。配置页可「打开表格 / 重新读取」；界面添加/移出关注也会改这张表的「启用」。同品种多合约时保证金、乘数、手续费必须填成一样。**每手手续费**是开仓、平昨各扣一次；**平今手续费**可另填（空=跟每手相同，0=平今免费）。回测净盈亏和信号账户都会扣手续费。表里写了的品种用表里的数；没写的用配置页「每手保证金」。保证金填 0 表示不看保证金。不要只改 yaml 里的 `symbols` / `contracts`——启动和保存时会按总表覆盖。旧的 `config/品种保证金.xlsx` 仅在首次生成总表时用来补数，之后以总表为准。
- 历史回测和策略优化这一次只认历史回测页上的「每手保证金」。填 0 就是这次不看保证金，不会偷偷改用配置页里按品种写的数。复盘只重放策略信号，不算手数和保证金。
- 当天已实现亏损达到「日最大亏损」后，当天不再开新仓，平仓仍然会做。换到下一根 K 线的新日期才重新计算。
- 每天最多开仓次数、两笔开仓的最小间隔，也按 K 线时间计算。
- 点「按配置页重新填入」会把配置页现在的策略、当前选中的合约、周期、行情来源、资金数字，以及收盘清仓一起抄到历史回测页。点「把本页参数写入配置页」是反方向：把本页测完的策略、品种、信号/止损周期、行情来源、收盘清仓和开仓限制一并写回配置并保存。账户权益仍是当前余额，不写回测里手填的数，也不写回测日期。「启用限制」只影响回测，不写进配置。历史回测、策略优化、复盘的品种下拉和配置页关注品种是同一份。

**策略优化**（多组参数网格搜索。训练段打分，检验段只验收）：

```powershell
python tools/run_optimize.py
python tools/run_optimize.py --apply   # 只有检验通过，才写入 config.yaml
# 或双击 策略优化.bat / 界面「策略优化」
```

报告：`data/optimize_last.json`。  
注意：
- **检验比例%** 可手调，默认 30（训练大约七成）。可填 10～50
- **一次切断**：按比例切一刀，前一段挑参数，后一段只看一次，不会为了检验段再改参数
- **滚动前进**：把检验段拆成多段（默认 3 段），走一步再验一步；写入用最后一段挑出的参数，总检验成绩把各段加在一起
- 结果里「训练成绩」和「检验成绩」与历史回测整体结果同一套字段：成交、胜率、净盈亏、盈利因子、最大回撤、综合得分
- 挑参数的得分不看胜率。盈利因子到 2 就不再加分，还要看净赚能不能盖住最大回撤。不满 30 笔会少给一点分
- 训练段分数接近时，留更靠近出厂参数的一组
- 训练段要赚钱。检验段还赚钱、没开仓，或只是小亏，才可以写入。检验段亏掉的超过训练盈利的一半，点写入也会被拒绝
- 结果里会写 **检验效率**（检验净盈亏÷训练净盈亏）。滚动前进时还写 **检验段赚钱比例** 和 **参数稳不稳**。赚钱段不到一半，或效率低于约 0.30，不能写入（和 MultiCharts / 公开滚动优化常见门槛同类）
- 优化结束后，会把同一组参数原样拿到其它关注品种上再跑一遍（多品种样本外验收）。超过一半的其它品种大亏，也不能写入
- 交叉测试页的「开始交叉测试」是固定参数的对照筛选，不是多品种交叉验证。要单独再验一次，可用交叉测试页的「用最近优化参数做多品种验收」

## 九、日内单边趋势：该用哪个周期？

你的目标：开盘噪音（或 ETH 时段）过后，用流动性耗尽定**当日主趋势**；不转向就拿到收盘；SAR 要钝，触发≈转向。

| 用途 | 推荐周期 | 原因 |
|------|----------|------|
| 定方向 / 开仓 | **5 分钟** | 早盘单根 Pin（如 09:05）在 15m 会被揉合丢失 |
| SAR 移动止损 | **15 分钟** | 比 5m 钝，少被中途扫损 |
| 更稳备选 | 开仓 15m / 止损 30m | 信号更少、更晚，抓不到开盘第一根细 Pin |

当前已配置：`timeframe: "5"` + `trail_timeframe: "15"` + 更慢 SAR（0.01/0.01/0.10）。  

**开仓信号（都要贴着关键支撑或压力）**  
1. 确认 Pin：长影线刺破后收回，下一根确认。这是最优先的信号。  
2. 高潮反转：一根成交量明显大于前 20 根，振幅也要拉到平时的大约 2 倍，收盘拒绝继续下跌或上涨，下一根确认。普通幅度的回落即使成交量看着大，也不开仓。针的成交量如果和同花顺对不上（很多 K 线只有几手），不再用这个残缺手数把已经确认的针否决掉。  
3. 弹簧 / 上冲失败：放量刺破并留下拒绝影线，下一根把价格收回来。收回那根成交量会变小，但至少要有刺破那根的四分之一，几乎没人成交的 K 线不算。  
4. 吸收：关键位上振幅很窄、成交量很大，下一根价格顺着离开。  
量价背离只提示，不单独开仓。

**收盘清仓开关**（配置页「收盘清仓」，对应 `strategy.flatten_at_close`）  
默认开着：到 `14:55` 和 `22:55` 强制平仓，周五夜盘临收也会平掉已有仓。  
关掉之后，开仓信号不变，但不再按收盘时间平仓。仓可以留过午盘、夜盘和周末，只靠初始止损和 SAR。周五临收盘仍然不开新仓。回测区间的最后一根 K 线仍会按当时价格把没平的仓结算掉，那一笔的平仓原因会写成「回测结束强平」，不是收盘清仓。想对比隔夜表现：先保存配置，同一段日期各跑一次开和关。

**ETH 时间（开盘后 30 分钟）**  
- 早盘从 `09:00` 起、下午从 `13:30` 起、夜盘从 `21:00` 起，各观察配置里的分钟数。国内期货下午 13:30 才开盘，13:00 到 13:30 是午休，这段不拉 K 线。  
- `eth_mode: strict_pin`（默认）：ETH **允许开仓**，但只用更严格 PinBar（影线更长、反向影线更短、放量更高）。弹簧、高潮、吸收在开盘这 30 分钟里不用  
- `eth_mode: block`：旧行为，ETH 内完全不开新仓  
- `eth_mode: off`：不做 ETH 特殊处理  

**挂机防休眠**  
- 点击「启动常驻」后，程序用 Windows 官方 `SetThreadExecutionState` 阻止系统睡眠/息屏（同类方案：PowerToys Awake）  
- 停止机器人后自动恢复电脑原来的电源计划  
- 配置项：`runtime.keep_display_awake: true`（GUI 点击需要屏幕保持可用）  

**收盘后关机（可选，默认关）**  
- 配置页开关「收盘后关机」，或 `runtime.auto_shutdown_after_close: true`  
- 等到**当日最后一节**清仓/收盘之后才预约关机（有夜盘时不会在下午 14:55 就关）  
- 默认再等 5 分钟缓冲，然后倒计时约 180 秒关机；期间可在命令行执行 `shutdown /a` 取消  

**PinBar 止损（按盘面习惯）**  
1. 确认棒进场后，初始止损 = 长影线顶端（空）/ 底端（多），例如今日 09:05 影线高 **4786**  
2. 未打到初始止损前仓单不动，**不**因小周期抖动或未确认的 SAR 提前挪止损  
3. 等 **15 分钟 SAR 转到与仓位同向**（空单绿点在价上 / 多单红点在价下）后，才开始随 15m SAR 移动止损  
4. 打掉 SAR 止损则平；否则拿到 `flatten_times`（如 14:55）收盘清仓  
5. 止损没打到时，若出现和持仓相反、并且已经确认的流动性信号，先平仓。反向开关打开时，同一根再按新方向开仓

注意：判断「是否打止损」用信号周期（5m）K 线，避免把入场那根 15m 大棒的影线高点误判成已止损。开仓那根 5 分钟 K 线自己的影线就是止损端点，也要等下一根 5 分钟收盘之后，才开始用新 K 线的最高价、最低价判断有没有打到。

信号仍要求：**信号 + 关键点位 + 时段**；背离只预警；清仓 14:55/22:55。

## 十一、常见问题

**Q: 图形界面怎么开？**  
A: `python -m src.ui`、双击 `启动界面.bat`，或直接运行 `src/main.py`。

**Q: 怎样让程序自动点同花顺下单？**  
A: 见「五 → 7. 同花顺自动点击下单」。软件已登录 → 标定坐标 → 执行通道 `gui` → 先开模拟再实点。

**Q: 每次开几手？有资金管理吗？**  
A: 有。默认 `risk_pct`：意图手数 = (权益×每笔风险%) ÷ (止损距离×合约乘数)；再和「仓位上限%」算出的保证金手数取小。仓位上限默认 80%。总仓位靠仓位上限%和日最大亏损管，不再有「最大持仓手数」。  
配置页的账户权益就是当前余额，不能在那里手改。要改余额，去账户分析里记初始资金、入金、出金或每日结算。历史回测和策略优化可以另填一个权益，用来测保证金高的品种，点「按配置页重新填入」会抄回当前余额。想固定手数就改 `sizing_mode: fixed`。

**Q: 配置里写了密码，为什么没有自动登录？**  
A: 配置页要打开「自动登录」，并先保存。启动时程序会点「交易 → 期货交易 → 期货交易(主界面)」。如果弹出「同花顺期货通交易」登录框，会先等它自己把资金账号填完。账号填完会把密码清掉，所以要等账号停住再填密码；若仍被清掉，会再填一次。登录按钮还是灰的，就不会点登录。没有这个框，就当作已经登录，不会把密码打到别的地方。关掉「自动登录」时，请先自己登录同花顺再挂机。

**Q: 能不能只扫描 bu2612，不要主连？**  
A: 可以。配置里 `strategy.symbols` 写成 `bu2612`（可多个：`bu2612,c2601`）。  
写 `bu` 才会映射成主连 `BU0`；写带年月的合约会直接拉该合约行情。改完后停止再启动。

**Q: 没开通程序化还能自动交易吗？**  
A: 能「自动算信号」。现在真下单仍用 `gui` 点击同花顺，或先用 `sim` 模拟。`ctp` 已经能做认证、登录、确认结算单、报单、区分沥青和玉米的平今平昨、接收成交回报、和柜台对账、断线重连。前置地址和认证码要等华泰技术给了再填，填好之前不要把 `executor` 改成 `ctp`。

**Q: 为什么不用截图认针？**  
A: 用行情里的开高低收计算。截图认针和旧的手工流水已经删掉。导出 Excel 里的交易记录和资金变动记录，来自现在的账户分析。

**Q: 点错按钮怎么办？**  
A: 鼠标甩到屏幕左上角（FAILSAFE）；重新量坐标填到 `trade.gui`。

- 「历史回测」「策略优化」「复盘」「账户分析」独立选项卡。复盘在收盘后把当天走势、技术面、基本面和策略开仓/观望原因写在一篇里。账户分析从 1.8.0 起按程序自己的开平仓点位自动记账，可填初始资金、入金、出金和每日结算。配置页的账户权益只显示当前余额。回测和优化的权益可手改，也可从配置页抄回当前余额
- 优化参数版本历史（`data/param_history.json`）：每次写入前自动备份。新版本默认叫「品种合约-策略名称-写入时间」，例如 `bu2612-流动性耗尽-2026-10-16 22:56:03`，策略优化页可以改成自己认得的名字。下拉列表只显示策略优化页当前选中的那一套。写入、回溯、重置都只改这一套的参数，不改正在用的策略、品种、周期，也不改另外几套。不想要的历史版本可以删除，出厂默认不能删，删除也不会改当前参数。每一套各自保留最近 30 条。改名不改内部编号，Excel 仍按编号认出同一条
- 配置页增加整页存档。点「保存全部配置」时，按「关注品种-策略名称-时间」再留一份，里面有这一页的数字和开关（收盘清仓、模拟模式、各策略必要参数都在）。选中后点「一键应用选中的配置」会整页换回去并写入配置文件。密码不进这份存档。常驻正在跑时不能应用，停掉再启动才会用上。和策略优化页的参数版本分开存，互不影响。应用时会清掉已删策略的旧小节
- 历史回测页「按配置页重新填入」会连收盘清仓一起抄，以及策略、品种、周期和资金数字。打开程序时收盘清仓先跟配置文件一致。趋势跟随、SuperTrend 仍用各自小节里的清仓设置
- 历史回测同步到策略优化、再写回配置的闭环：同步会刷新策略优化页的版本列表。写入最优参数时，把这次打分用到的开关一起留下，避免写完后开关被重新加载成旧状态。不改正在用的策略、品种、周期，也不改开仓限制
- 各功能导出共用 `data/Auto-Trading导出.xlsx`：说明、优化参数、交易记录、资金变动记录、复盘、回测摘要、回测成交、交叉测试、优化结果各占一张表。账户分析左边也可以只导出交易记录或资金变动记录这两张。优化参数按版本ID追加；回测摘要/成交、交叉测试每次导出也追加，不盖掉以前的行。回测时间、测试时间用来分清每一次。回测摘要带策略中文名、夜盘分钟、收盘清仓；优化结果带检验方式、检验成绩和是否通过。表结构若和程序对不上（例如还没有盈利覆盖等新列），点「导出全部」会自动整本重建；单表追加时也会丢掉缺列的旧行。也可手动删掉 data/Auto-Trading导出.xlsx 后再导出。旧的单表文件仍可导入
- 优化网格已扩充：含 Pinbar 定义（影线/实体、占K比例、反向影线）、放量、关键点位、双K量能、ETH分钟、SAR 等；支持精简/标准/完整三档，组合过多时随机抽样

已知问题：
- 分钟 K 线已按右标签用 1 分钟重拼并对齐同花顺；回测某日夜盘若本地没有足够 1 分钟，仍可能对不齐，先拉一次 1 分钟再回测
- 早盘A/B/C 的夜盘按 21:00/21:30/22:30/23:00 对齐日盘；若某品种夜盘收得更晚（过 23:00），默认不会再开新仓，需要时再改 `night_session_close`
- 复盘里的库存、基差、快讯来自公开网站，沥青/玉米经常没有对口新闻；没拉到会在报告里写明，不影响技术面、信号质量和缺陷诊断
- 复盘重放假设当天开始时是空仓，和「早上已经持仓」的实盘不一定相同；真实下单以第六节事件日志和第七节三边对照为准
- 单日成绩单不能推翻历史回测；连续多日有效性明显低于近几日或回测预期时，再去策略优化页改参数
- 账户分析看的是程序自己的开平仓点位，不含滑点和手续费。没平掉的仓不改余额。和实盘不一致时，用每日结算把余额改成实际金额
- 影线/实体分时量能只能近似；关键位用摆动点近似
- 未开通程序化时真下单仍靠 GUI（窗口一动就要重标）
- **GUI 点击成功 ≠ 交易所成交**：请定期打开同花顺核对持仓；重要阶段可设 `trade.gui.assume_fill: false`
- 历史回测默认按历史回测页填写的权益、每笔风险和止损距离算手数；止损过宽会跳过。想跟以前一样固定 1 手，把仓位模式改成 fixed
- 正式盘建议开通 CTP 后替换 gui 执行通道
- 启动回溯补开仓过了三道门仍可能追价；周期很长（如 60 分钟）时「20 分钟」往往只能罩住最新一根。不需要时把 `strategy.catch_up_on_start.enabled` 关掉
- 日内实体止损是开盘箱体对沿再让 `stop_extra_ticks` 跳。箱体本身很高低差很大时，止损金额会跟着放大，所以另有一道 `max_box_ticks`：箱体最高-最低超过这个跳数就不开（默认 100，0 关闭）。觉得止损还是太宽，可以两头一起调小
