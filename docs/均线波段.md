# 均线波段操作说明

配置页下拉里选 **均线波段**，引擎名 `ema_swing`。  
旧配置写着 `macd_swing` 或「MACD波段」的，打开后自动当成这一套。

**不用 MACD 柱子，也不看 DIF/DEA。** 那是「日内浮盈飘单」里另一套东西。

建议：信号周期和止损周期都选 **15 分钟**（可再试 30 分钟）。手数用左边公共的每笔风险%（或凯利）。可以拿到隔夜。

5 分钟太碎：EMA120 在 5 分钟图上大约只覆盖一天多的交易时间，下影线很容易「触及」止损。换成 15 分钟后，同一根均线覆盖更长走势，假扫会少很多。开仓、止损规则没变，只是看的图变粗了。

---

## 一、你怎么用（操作）

1. 配置页策略引擎选 **均线波段**。
2. 左边公共项：信号周期、止损周期建议都填 `15`；止损触发选「触及」或「收盘确认」。
3. 右边「均线波段」里，出厂可以先不动：

| 你看到的名字 | 出厂 | 干什么 |
|--------------|------|--------|
| 方向选择器 | EMA 60 / EMA 120 | 两个输入框填根数。金叉后只做多，死叉后只做空 |
| 信号发生器 | EMA 5 / EMA 10 / EMA 30 | 三个输入框。三条快线按方向排好才开。前面要比后面小 |
| 多空分界线 | EMA 120 | 做多要收盘在它上面，做空要在下面 |
| 止损均线 | EMA 120 | 开仓后止损跟着它走 |
| 倾角均线 | EMA 120 | 只看这根斜不斜 |
| 最小倾角(度) | 3 | 不够斜当震荡。填 0 关掉 |
| 斜率回看根数 | 20 | 用最近几根算倾角 |
| 倾角不够就平仓 | 关 | 关=只拦新开；开=手里的仓也平 |
| 尾盘不开仓(分钟) | 30 | 空仓时收盘前这么多分钟不开。填 0 关掉 |

4. 先历史回测，再决定要不要常驻。对照「倾角不够就平仓」时：同一段行情关着跑一遍、开着跑一遍。
5. 改完要 **关掉程序再打开**，界面才是新版本。

换月（主力连续回测）：旧主力段末如果还拿着仓，下一交易日会在新主力按同一方向开仓，止损改挂新主力当时的止损均线，不再等三线重新排。新主力会用它自己更早的 K 线把均线算热，和同花顺打开这张合约一样。任何合约都不进入自己的交割月：fu2701 最晚做到 2026-12-31 日盘收盘，1 月起改下一手。实盘一次只盯一个合约：换月时请把关注品种改成新主力，并自己平旧开新。

风控仍是全软件那一套：每笔风险%、仓位上限%、日亏损熔断。止损离现价太远时，手数会算成 0，结果里记「止损过宽」，这根不开。

配置页「通用止损」如果不是关，会在这套自己的止损外面再加一层。对照这套本身时，请先把通用止损关掉。

## 二、完整交易链路（对照代码）

每一根信号周期 K 线来了，程序只问两件大事：**现在有没有仓**。

```
有仓 ──► 先管仓（平或不平），这根不再开新仓
无仓 ──► 过完闸门才决定开不开
```

止损周期和信号周期是同一根图。代码里传入的止损周期 K 线 **不用**。

### A. 还没开仓时（必须全部满足才开）

按下面顺序，**有一条不过就停在这一根**，等下一根再问。

1. **K 线够不够**  
   至少要能算出最长的那根均线，再加上倾角回看根数。不够就等。
2. **是不是交易时段**  
   看品种表的日盘/夜盘。日线、周线不看钟点。
3. **尾盘不开仓**  
   空仓时，日盘收盘（一般 15:00）或夜盘收盘（一般 23:00，白银黄金 02:30）前若干分钟不开（出厂 30，配置页可改，填 0 关掉）。  
   **上午 11:30 午休不算收盘**，还可以开。
4. **大方向**  
   从历史里找到 **最近一次** 方向选择器两根均线的金叉或死叉（出厂 EMA60 和 EMA120，括号里填别的数字也按那个根数算）。  
   金叉之后一直只做多，直到再死叉；死叉之后一直只做空，直到再金叉。  
   还从没叉过，不开。  
   **不要求抓住交叉发生的那一根**；叉过之后，后面只要别的条件齐了也可以开。
5. **多空分界线**  
   做多：这一根收盘必须 **高于** 多空分界线（贴着或在下面都不开）。  
   做空：收盘必须 **低于** 多空分界线。  
   大方向还是空、价格却在线上面：不做多，等跌破再开空。反过来也一样。
6. **信号三线已经排好（看现在的状态，不看刚交叉）**  
   做多：EMA5 > EMA10 > EMA30（出厂）。  
   做空：EMA5 < EMA10 < EMA30。  
   中间乱了就等排好。跳空把交叉那根吃掉也没关系。
7. **倾角**  
   看 **倾角均线自己** 近 20 根走了多少（用 ATR 换成角度，不是图上用量角器量）。  
   做多要往上够陡（出厂 ≥ 3°），做空要往下够陡（≤ −3°）。  
   走平、斜反了，当震荡不开。填 0 等于关掉这一条。
8. **开仓**  
   多或空开出去。这一根的止损价 = **当时的止损均线数值**。  
   同一根 K 线不会开两次。

**没有单独的止盈价。** 赚了靠止损均线跟着走，把利润锁住。

### B. 已经有仓时（按这个顺序检查）

1. 若你打开了这套自己的「收盘清仓」（出厂是关的，保存时也写成关）：到点强制平仓。  
   配置页总开关的收盘清仓，**这套不听**，所以默认可过夜。
2. **这一根方向均线叉反了**（多单碰上死叉，空单碰上金叉）→ 平仓，**不在这一根反手**。
3. **碰到止损均线** → 平仓。  
   「触及」看最高最低；「收盘确认」只看收盘，影线扫一下又收回来不算。
4. **倾角不够就平仓**（出厂关）  
   打开后：倾角均线走平或斜反，也把仓平掉，**不反手**。
5. 都没有 → 继续拿。止损价改成 **现在的止损均线**（跟着走）。

平掉之后，下一根又走「无仓」那一套。大方向没叉反、三线还排着、分界线也对、倾角也够，**可以再开同方向**。不会因为刚止损就强制空仓很多根。

## 三、名词用白话

**多空分界线**  
地上一条线。做多必须站上面，做空必须站下面。贴着或站反面就是站错边，这根不开。

**自己填根数**  
方向、信号、分界线、止损、倾角都是指数均线（EMA）。框里填数字，数字就是根数。想试 21 和 122，填进去就按 21、122 算。策略优化要试多档时，改 `config/优化参数.xlsx` 里均线波段那几行的取值（例如 `21/122,60/120`），不必改程序。

**倾角**  
不是 K 线画出来的斜，是倾角均线自己近 20 根走了多少倍 ATR。大约 3° ≈ 这 20 根里均线走了 1 倍 ATR；5° 更像有波段。

**三根均线为什么要拆开**  
出厂都是 EMA120，和绑在一起时一样。你可以改成「倾角看 120、止损看 60」。

## 四、这套明确不做的事

- 不做高抛低吸、碰轨反转。
- 没有赚够几个点就跑的止盈。
- 没有 ADX。横盘靠倾角拦。
- 不在平仓那一根立刻反手。

当前版本见项目根目录 `VERSION`。
