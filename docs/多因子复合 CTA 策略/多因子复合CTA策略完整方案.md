# 多因子复合CTA策略完整方案

# 多因子复合CTA策略完整讲解

先定基调：  
多因子CTA不是简单把双均线、海龟、布林、SAR几个策略“同时跑、信号取交集”，**核心是：对市场状态、多个独立预测因子做标准化打分、加权合成一个综合信号，再叠加波动率风控、动态仓位、绩效自反馈机制**。  
普通单策略是「一个指标决定开不开仓」；多因子是「多个独立信息源投票，票数足够才动手」。

适用：国内商品期货（燃油、纯碱、玉米、棉花等）；下面全部是可落地的CTA趋势体系（以趋势因子为主，少量量价辅助，不含套利、期权）  
免责：仅学习研究，不构成交易建议；多因子天然容易过拟合，回测一定要严格样本外测试。

## 一、底层设计思想（为什么做多因子，而不是单策略）

单趋势策略天生有“环境依赖性”：

- 双均线：流畅趋势赚钱，震荡反复交叉亏钱
- 海龟突破：大趋势暴利，震荡假突破连续亏
- SAR：趋势拿得住，横盘来回扫止损
- 布林突破：趋势扩张行情舒服，横盘反复刺破轨道挨打

市场不会一直是同一种状态；单一因子在某一段时期失效，其他相关性低的因子有可能还在有效。  
多因子的目标：

1. 分散信号来源，降低单一因子失效带来的资金回撤；
2. 区分信号强弱，而不是只有“有信号 / 无信号”二元选择；
3. 增加市场状态过滤器，在所有因子都不适合的环境直接关停；
4. 可以做动态权重：最近表现差的因子自动降权，表现好的因子提权（自适应版本）。

关键前提：**因子之间要低相关性**  
如果你放进去的因子都是同类型趋势因子（比如MA5/MA20、MA10/MA60），高度相关，信号经常同涨同跌，起不到分散效果，只是重复信息，复合之后改善很小。  
✅ 好搭配：趋势突破类（唐奇安）+ 均线趋势类（双均线）+ 轨道波动率类（布林）+ 转向跟踪类（SAR）+ 量价因子（持仓/成交）❌ 坏搭配：MA5MA20、MA10MA30、MA20MA60一堆均线堆在一起

## 二、整体架构拆解（5大模块）

完整多因子CTA =

1. 因子池（单因子计算 + 标准化打分）
2. 权重模块（固定权重 / 自适应动态权重）
3. 信号合成模块（总分计算、开仓阈值）
4. 风控&仓位模块（波动率仓位、单笔风险、总资金上限）
5. 市场状态开关（全局否决器：行情不匹配直接禁止开仓）

下面逐个模块拆开，附带计算公式、打分规则。

## 模块1：因子池设计（趋势CTA主流因子，每个因子独立输出 [-1,1]）

约定打分规则统一：  
+1 = 最强多头信号  
-1 = 最强空头信号  
0 = 无明确信号/震荡，不贡献方向

每个因子内部自带过滤，不满足条件直接输出0，而不是硬输出方向

### 因子1：均线趋势因子（双均线 MA20/MA60）权重示例0.3

逻辑：长均线定方向，短均线捕捉趋势启动

1. 基础条件：价格相对于MA60位置
- Close > MA60：多头候选区

- Close < MA60：空头候选区
2. 信号：
- 金叉（MA20上穿MA60）+ 价格在MA60上方 → score=+1

- 死叉（MA20下穿MA60）+ 价格在MA60下方 → score=-1

- 均线缠绕（MA20与MA60差值小于0.5倍ATR）→ score=0
3. 中间状态（已经在趋势里，没有交叉）：  
   价格在MA60上方、MA20在MA60上方，同向倾斜 → score=+0.5  
   价格在MA60下方、MA20在MA60下方，同向倾斜 → score=-0.5

作用：捕捉中长期趋势方向，偏慢、噪声少

### 因子2：唐奇安突破因子（海龟20/10通道）权重示例0.25

逻辑：突破N周期高低点代表新的价格区间打开  
参数：唐奇安20周期高低点，10周期离场高低点

1. 收盘价突破20周期新高 → score=+1
2. 收盘价突破20周期新低 → score=-1
3. 价格在通道内部，没有突破：  
   靠近上半区 + 趋势向上 → +0.5；靠近下半区 + 趋势向下 → -0.5
4. 价格在通道中间来回震荡，频繁触碰上下沿但不突破 → score=0

作用：抓趋势启动突破，信号爆发力强；缺点是假突破多

### 因子3：布林带趋势因子（MA20，2倍标准差）权重示例0.25

逻辑：只顺着中轨方向做突破，不做反转

1. 中轨MA20向上倾斜，价格>中轨：  
   收盘价突破上轨 → score=+1；价格在中轨上方平稳运行 → +0.5
2. 中轨MA20向下倾斜，价格<中轨：  
   收盘价跌破下轨 → score=-1；价格在中轨下方平稳运行 → -0.5
3. 中轨走平（倾斜角度阈值以内）→ score=0，不参与

作用：融合波动率信息，通道会随波动自动缩放

### 因子4：SAR转向因子 权重示例0.2

SAR参数：AF初始0.02，步长0.02，上限0.2  
叠加过滤：必须和MA60大方向一致，否则即使SAR翻转也给0

1. SAR翻多，且价格在MA60之上 → score=+1
2. SAR翻空，且价格在MA60之下 → score=-1
3. SAR频繁来回翻转（一定窗口内翻转次数超限）→ score=0
4. SAR方向和MA60大方向相反 → score=0

作用：趋势跟踪、移动止损，拿趋势中段；震荡期自动归零

### 可选增量因子（进阶，不要一次性加太多）

- 量价因子：放量突破（当前成交量 > 近20日均量1.5倍），同向加分；缩量突破降分
- ADX趋势强度因子：ADX>25正向加成，ADX<20直接给0
- 基差因子（基本面，适合产业品种）：基差持续走强/走弱，辅助打分

新手建议：先用上面4个趋势因子跑通，稳定后再加量价因子，不要一次性堆7、8个因子，极易过拟合。

### 重要：因子标准化

所有因子输出都压缩到 [-1,1]，保证每个因子量级统一，不会出现某个因子数值巨大，直接主导总分。  
如果不做标准化，布林标准差、ATR、价格偏离度单位不一样，加权毫无意义。

## 模块2：权重方案（两种路线：固定权重 / 自适应动态权重）

### 方案A：固定权重（入门首选，回测可控、不容易过拟合）

示例权重（总和=1）

- 均线趋势因子：0.30
- 唐奇安突破因子：0.25
- 布林趋势因子：0.25
- SAR趋势因子：0.20

优点：简单、稳定、可解释、回测不容易过拟合；  
缺点：市场风格切换时，权重不会自动适配，某一类因子持续失效时只能人工关停。

### 方案B：自适应动态权重（私募常用，难度更高）

思路：给每个因子单独开一个绩效窗口（最近15~20笔该因子发出的信号）  
对每个因子单独统计：盈亏、胜率、盈亏比、夏普  
规则：

1. 因子最近绩效达标 → 使用基础权重
2. 因子连续亏损、绩效大幅下滑 → 权重打折，甚至置0（临时禁用这个因子）
3. 因子近期表现优秀 → 权重小幅上浮（设置上限，比如最高不超过0.4）

示例：唐奇安最近连续假突破，5笔亏4笔 → 唐奇安权重从0.25降到0.05甚至0  
注意：自适应权重是双刃剑，参数设置不好会出现“追涨因子”，也就是刚涨完权重拉高，随即因子失效，进一步放大回撤。

✅ 新手路线：先固定权重跑半年仿真，稳定之后，再尝试动态权重。

## 模块3：信号合成 & 开仓/平仓规则

总分计算公式：

![](https://cdn.nlark.com/yuque/__latex/c25b8cb7d2e5e6d52193181c6bf076e8.svg)

总分范围：[-1, +1]

### 阈值设定（可以自己调，下面是经典参考）

- 总分 > 0.6：强多头信号 → 允许开多
- 总分 < -0.6：强空头信号 → 允许开空
- -0.6 ≤ 总分 ≤ 0.6：信号模糊，不新开仓；持有旧仓继续跟踪出场条件

为什么阈值设0.6而不是0？  
0相当于只要多头信号稍微多一点就开仓，大量杂信号进场；阈值拉高，相当于要求多个因子“投票一致”，降低噪声，代价是信号变少，错过一部分行情。阈值是胜率和机会数量的取舍。

### 开仓规则

1. 市场状态开关必须先通过（后面单独讲），开关关闭，直接禁止开新仓；
2. 当前无同方向持仓；
3. 总分突破阈值；
4. 单笔风险约束：这笔单子最大亏损不超过总资金1%（ATR动态仓位）。

### 平仓规则（二合一，推荐组合使用）

1. **信号反转平仓**：总分反向穿越阈值（比如多单，总分跌到-0.6以下，空头共识形成）
2. **移动止损平仓**：ATR跟踪止损（2ATR），或者SAR跟踪（也可以直接复用SAR因子的止损）

日内版本额外强制：收盘前固定时间全部平仓，不留隔夜。

### 加仓规则（可选，谨慎）

只有总分持续走高（比如>0.8），并且价格向盈利方向移动0.5ATR之后，才允许加仓；  
单品种总仓位设置上限，比如最多3个单位，防止单边重仓。

## 模块4：仓位与风控体系（多因子的生命线，很多人只做信号忽略这块）

### 1. 单位风险仓位（和海龟一致）

![](https://cdn.nlark.com/yuque/__latex/af06bdd8eb56c18a97126e311baa4211.svg)

N = 基础单位手数，这笔单子亏2ATR时，亏损≈总资金1%

多因子可以做【信号强度加权仓位】：  
总分越高，仓位越高：

- 0.6~0.8：0.5N

0.8：1N  
好处：强共识下适度加大仓位，弱信号轻仓甚至不做。

### 2. 多层风控硬约束（一票否决）

- 单品种最大仓位上限；
- 账户总风险上限：所有持仓合计风险不超过总资金3%；
- 单日最大亏损：单日亏损达到总资金2%，停止当日所有开仓；
- 账户总回撤上限：从高点回撤达到15%，全部清仓，暂停策略一段时间。

## 模块5：市场状态全局过滤器（就是你关心的：判断行情匹不匹配，全局开关）

这个是独立于因子之外的顶层否决器，**哪怕所有因子都给出高分，只要市场状态不匹配，直接禁止开新仓**。  
四个核心指标，程序化可编码：

1. **ADX趋势强度**  
   ADX < 20 → 趋势环境弱，关闭趋势类多因子；  
   ADX 20~25：降仓，只接受极高总分（>0.75）才开仓；  
   ADX >25：正常运行。

注意：ADX高≠好趋势，ADX高但是V型来回反转（无序高波动），同样要过滤。可以附加：连续同向K的占比。

2. **ATR波动率分位（近60日）**  
   ATR < 历史20%分位：低波动压缩，趋势策略容易反复扫损，关停；  
   20%~70%：舒适区间；

70%：高波动，允许交易，但提高止损空间、降低仓位上限，防范跳空滑点。

3. **因子一致性校验（因子分歧度）**  
   计算各个因子得分的标准差：  
   如果因子得分正负撕裂（一部分+1、一部分-1），标准差很大，说明因子互相打架，市场方向混乱，禁止开仓。

举例：均线看多、唐奇安假突破看空、SAR翻空 → 因子分歧大，总分哪怕勉强到0.6，也放弃。

4. **事件驱动过滤（针对燃油这类原油联动品种）**  
   隔夜大幅跳空、消息冲击日：  
   开盘半小时内不产生稳定的同向结构，直接标记为脉冲无序行情，当日暂停开新仓。

一句话理解这个模块：因子负责“有没有趋势信号”，状态过滤器负责“这个市场适不适合用趋势信号赚钱”。

# 三、回测流程与避坑（多因子最容易翻车的地方）

多因子最大敌人：**过拟合**  
很多人回测调权重、调阈值，在历史曲线完美，实盘直接拉胯。  
标准回测流程：

1. 样本划分：
- 训练集（用来调参数、权重）：前70%数据
- 验证集（不能用来调参）：后30%样本外
2. 禁止操作：不要反复微调权重、阈值去贴合历史行情曲线；
3. 成本必须计入：手续费、滑点，跳空行情的滑点单独模拟；
4. 绩效评估指标（不只看收益率）
- 夏普比率（优先，>1.5才算合格CTA）
- 最大回撤
- 盈亏比
- 连续亏损次数
- 因子胜率分化：单独看每个因子在样本外是否还保持正向期望

一个危险信号：训练集很漂亮，验证集直接负收益 → 100%过拟合。

## 常见坑清单

1. 因子相关性太高，多个因子本质是同一个信息；
2. 因子太多，自由度爆炸，参数随便调就能拟合历史；
3. 去掉了市场状态过滤器，震荡期持续发信号；
4. 自适应权重窗口太短，权重来回跳动；
5. 忽略跳空，燃油这类品种，外盘夜盘跳空会直接击穿ATR止损；
6. 只优化收益率，不控制最大回撤。

# 四、举一个完整示例（某一天，燃油FU，5分钟K）

假设固定权重：均线0.3，唐奇安0.25，布林0.25，SAR0.2

- 均线：价格在MA60上方，MA20上穿MA60 → +1
- 唐奇安：突破20根K新高 → +1
- 布林：中轨向上，突破上轨 → +1
- SAR：刚刚翻多，且价格在MA60上方 → +1  
  总分 = 1*0.3 +1*0.25 +1*0.25 +1*0.2 = 1.0  
  市场状态：ADX=32，ATR处于历史40%分位，因子全部同向，分歧很小 → 开关打开  
  ✅ 满足总分>0.6，开多，仓位按ATR计算1N，止损2ATR

另一个场景：  
均线+1，唐奇安-1（假突破），布林+0.5，SAR-0.5  
总分=0.3 -0.25 +0.125 -0.1 = 0.075  
总分在阈值以内 → 不交易。

再一个场景：  
所有因子打分都很好，但是ADX=17，ATR处于历史15%分位 → 全局开关关闭，不交易。

# 五、和你前面4个单策略的对比

- 单策略：单一信号源，行情一换直接失效，要么一直做要么一直停；
- 多因子：多个独立信号投票，可以区分信号强弱；可以单独关掉失效因子；顶层有市场状态总开关；收益曲线更平滑，但系统复杂度显著上升，监控、维护成本更高。

# 为了兼顾稳定可靠和效率，通常选择几个因子

先说直接结论：  
**兼顾稳定可靠、控制复杂度、减少过拟合，趋势CTA（你这套以均线/唐奇安/布林/SAR为主），最优区间：3～4个因子。**

- 保守稳妥：**3个**（新手首选，可控、好排查、不容易过拟合）
- 平衡收益/分散：**4个**（私募中小规模CTA最常用配置，就是咱们前面这套）
- 不推荐：≤2个、≥6个

下面拆开讲清楚背后逻辑、搭配原则、避坑，以及怎么选。

## 一、为什么不是越多越好？

多因子的收益提升，来自**因子之间低相关性**，不是堆数量。

- 每增加一个因子，系统自由度上升、参数变多，**过拟合风险非线性上涨**；
- 因子多了之后，因子之间互相冲突、抵消，信号变稀疏、解释难度飙升；
- 实盘监控成本成倍提高：你要持续跟踪每一个因子的衰减、胜率、盈亏比，因子越多越难定位是谁在拖后腿。

行业经验：  
中小型商品趋势CTA（不是头部几百因子的机器学习多因子），**4个是性价比天花板**。  
头部私募那种几十上百因子的，大多是股票多因子，或者是带机器学习、海量标的、有专门量化团队维护的，散户/小资金不适合照搬。

## 二、为什么不建议只用1～2个因子？

本质就是回到单策略的老问题：分散不足。

- 2个高度相关因子（比如MA20/60 + MA10/30）≈ 还是单因子，风格高度重合，起不到平滑曲线的作用；
- 就算是低相关两个因子，行情风格切换时，很容易两个同时失效，回撤和单策略差距不大。

## 三、3因子、4因子的推荐搭配（趋势CTA，适配国内商品）

核心原则：**因子属于不同信号类型，相关性尽量低**  
四类信号类型：  
A 均线趋势类（慢方向）  
B 突破类（唐奇安，抓启动）  
C 波动率轨道类（布林，带波动率自适应）  
D 跟踪转向类（SAR，拿中段、自带跟踪止损）

### ✅ 3因子方案（最稳，推荐新手起步）

方案示例：均线趋势 + 唐奇安突破 + 布林趋势

- 覆盖：大方向判断、突破启动、波动率通道
- 去掉SAR的好处：减少震荡期频繁翻转带来的噪声；系统更干净，信号更稳定
- 缺点：少了一个趋势跟踪维度，中段持仓跟踪能力弱一点

### ✅ 4因子方案（平衡版，就是我们前面讲的那套）

均线趋势 + 唐奇安突破 + 布林趋势 + SAR

- 四类完全不同的信号逻辑，相关性低；
- 同时覆盖：趋势方向、突破入场、波动率、跟踪离场；
- 代价：震荡环境下SAR会产生更多杂信号，需要靠打分+市场过滤器压制

不要这样搭配（高相关，无效堆叠）：  
MA5/MA20 + MA20/MA60 + EMA20 + 自适应均线 → 全是均线类，信息高度重叠，白加。

## 四、什么时候可以加到5个？

只满足下面全部条件再加第5个因子：

1. 前面4个已经样本外回测、仿真跑通，绩效稳定；
2. 新增因子**类型和前面4个完全不一样**（不能还是趋势类）；  
   可选新增：量价因子（放量确认）、基差/库存因子（基本面）、持仓变化因子；
3. 新增因子单独做测试，证明它和原有组合相关性低、独立正向期望；

5个已经是散户小资金的上限，**不建议超过6个**。

## 五、配套的权重管理规则（因子数量少的时候尤其重要）

因子少，权重不能乱分配：

1. 3因子：权重平均或者略倾斜，例如 0.4 / 0.3 / 0.3
2. 4因子：前面示例 0.3 / 0.25 / 0.25 / 0.2

不要给某一个因子权重压到0.5以上，否则又变回以单因子为主，失去分散意义。

# 多因子复合 CTA 策略通常适用于什么级别的周期上

# 核心结论

商品趋势多因子CTA（你这套：均线+唐奇安+布林+SAR，纯趋势因子），**机构主流是日线；散户做日内的话首选5分钟；15分钟是折中优选；不推荐1分钟、Tick高频**。

关键：**周期决定因子的噪声大小、信号稳定性、交易成本占比、策略生命周期**；多因子本身不绑定某一个周期，但不同周期下因子的表现、搭配逻辑、过滤规则完全不一样。

先分三大类场景，再对比优缺点、适配性、坑点，最后给你选型建议。

## 1. 日线周期（私募中型/大型趋势CTA最主流，最适合多因子）

✅ 适用：中长线波段，隔夜持仓，不日内清仓

- 为什么适合多因子：  
  日线K噪声低，每一根K信息信噪比高；唐奇安、均线、布林、SAR这些经典趋势因子，**原始设计就是日线级别**，因子本身正向期望最扎实；  
  因子之间相关性更低，投票的价值能真正发挥出来；  
  信号数量不多，交易摩擦（手续费、滑点、跳空冲击成本）占利润比例很低，策略寿命更长、衰减慢。
- 特点：  
  信号少，一年几十笔~一百多笔交易；  
  回撤偏大（天然属性），靠分散品种、多因子投票平滑；  
  对跳空有容忍度，但要单独做隔夜风控。
- 适合品种：燃油、纯碱、棉花、甲醇、橡胶等流动性好的商品。
- 短板：资金占用大，持仓周期长，对账户资金体量要求更高；机会密度低，小资金很难快速积累收益。

行业现状：绝大多数知名的商品CTA（管理期货）产品，底层都是**日线为主，辅以少量小时线**的多因子组合。

## 2. 小时周期：60min / 30min（折中路线，很多中小量化在用）

介于日线和日内短周期之间，属于波段日内/短隔夜混合

- 优势：信号数量比日线多，机会变多；滑点压力远小于5分钟；

- 注意：多因子在这里依然好用，但**ADX、ATR分位过滤器要调参**，不能直接照搬日线参数。

## 3. 5分钟周期（你当前的方向：日内、收盘强制清仓，散户最常用）

✅ 可以做多因子，但代价明显，是你重点关注的版本

- 可行性：可以做（均线+唐奇安+布林+SAR），但**短周期噪声会同步放大所有因子的假信号**；
