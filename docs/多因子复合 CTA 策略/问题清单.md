## 1. 因子之间的相关性如何计算？

**算什么：** 不是算均线和布林两个数字像不像，而是算「这两个因子给出的方向，长期是不是同涨同跌」。同涨同跌太高，等于把同一个消息投了两票，复合几乎没分散效果。

**推荐算法（按优先级）：**

1. **Spearman 秩相关（首选）**  
   把每个因子每天/每根已收盘 K 的得分排成序列，算秩相关。对 ±1/0/0.5 这种阶梯分数更稳，不怕极端值。
2. **Pearson 相关（辅助）**  
   直接对得分序列算线性相关。机构看 CTA 产品之间常用这个（2024 年 SG Trend 成分平均两两相关约 0.78），我们拿来看因子也行。
3. **滚动窗口**  
   用最近 60～120 根信号周期 K（或最近 20 笔有仓交易）算一次，不要用全历史一个数。相关性会随行情变。

**怎么用：**

| 相关程度 | 建议 |
|----------|------|
| \|ρ\| < 0.4 | 搭配合格，可以同时进池 |
| 0.4～0.7 | 能用，但权重不要都给高 |
| \|ρ\| > 0.7 | 信息高度重叠，应删掉一个，或把两个合成一个 |

**对本套 4 因子的经验预期：** 均线 / 唐奇安 / 布林 / SAR 都是趋势类，相关不会很低，日线大约 0.4～0.7，5 分钟会更高。所以「4 因子」的价值主要在**触发时机不同**（慢方向 vs 突破 vs 通道 vs 翻转），不是完全独立。日线过滤 + 5 分钟打分，等于再加一层「不同周期」，这才是真正能降相关的办法（行业里不同速度的趋势模型，相关会明显低于同一速度）。

**不要：** 拿价格序列相关来代替因子得分相关；也不要用随机打乱的 K 折交叉验证。

## 2. 因子如何进行标准化打分？

有两条路，本套资料选的是第一条，行业里还有第二条。

### 路线 A：离散档（你资料里的，本程序应继续用）

每个因子只输出：`-1 / -0.5 / 0 / +0.5 / +1`

- 量纲已经统一，**不必再做 Z-score**
- 好处：规则能讲清楚、好归因、不容易被一根极端 K 带飞
- 坏处：丢掉「强一点 / 弱一点」的连续强弱

这是国内散户 CTA、可解释趋势系统的主流做法。

### 路线 B：Z-score 连续分（机构多因子、机器学习常用）

对每个原始指标算  
`(当前值 − 近 N 根均值) / 近 N 根标准差`，再截断到 [-2, 2]，最后压到 [-1, 1]。

- 好处：仓位可以跟分数成比例
- 坏处：窗口一变分数就变，回测极易过拟合；本程序先不做

**统一约定（落地时写进代码）：**

- 无信号、缠绕、和大周期方向相反 → **必须输出 0**，不要输出反向分去「对冲」
- 值域锁死，禁止某个因子打出 3、-5 这种数
- 标准化是为了**能加权**，不是为了让回测更好看

## 3. 因子如何进行加权合成？

公式（固定权重）：

`总分 = w均线×s均线 + w唐奇安×s唐奇安 + w布林×s布林 + wSAR×sSAR`

权重先归一化，使 `w 之和 = 1`。总分范围约 [-1, +1]。

**开仓：** 总分 ≥ +阈值 只开多；≤ −阈值 只开空；中间不开新仓。  
**平仓：** 总分反向穿越阈值，或跟踪止损，或收盘清仓。

**5 分钟建议阈值 0.65～0.70**（日线可以用 0.60）。阈值是「票数门槛」：提高 = 更少交易、更高共识。

**自适应权重（后做，不要第一步就上）：**

- 只在**平仓之后**更新，绝不每根 K 改权重
- 回看最近 20 笔，按开仓时各因子 |得分| 占比，把这笔盈亏分摊到因子
- 单因子权重下限/上限（例如 0.05～0.40），再归一化
- 窗口累计为负的因子，当期得分截成 0
- 训练集变好、样本外变差 = 立刻停用自适应

行业提醒：趋势 CTA 产品彼此相关本来就高，动态加权重容易「追刚赚过钱的因子」，放大下一轮回撤。

## 4. 参数优化方法有哪些，尽量避免过拟合？

按「能用、且适合本程序」排序：

1. **先锁规则，少搜参数**  
   权重、均线 20/60、唐奇安 20、布林 20×2、SAR 0.02/0.2 先固定。只允许搜：阈值、ATR 止损倍数、是否启用 SAR、ADX 门槛。搜得越多越假。
2. **时间切分，禁止随机打乱**  
   前 70% 训练、后 30% 样本外；或按年份切开。
3. **滚动前进（本程序策略优化页已有「滚动前进」）**  
   用前面一段选参数，用紧接着的下一段评分，再往前滑。这是时间序列的最低合格线。
4. **衔接处要留空档（purging / embargo）**  
   均线 60 根、标签又看后面几根时，训练段末尾和测试段开头会「共用」同一段行情。交界处丢掉大约 1～2 个指标窗口的长度，避免偷看。
5. **因子消融**  
   去掉 SAR / 去掉布林 / … 各跑一遍样本外。某个因子去掉后样本外更好，说明它是累赘。
6. **成本加倍压力测试**  
   手续费+滑点按 1.5 倍、2 倍再跑。5 分钟日内这一项往往比改阈值更能决定策略死活。
7. **参数附近要平**  
   阈值 0.60 / 0.65 / 0.70 三条曲线应差不多。只有一个尖峰好用 = 过拟合。

**不要做：** 对着全样本把权重网格扫到曲线最美；用普通 K 折交叉验证；同时优化 8 个以上参数。

业界更严的做法叫 CPCV（把历史切成多段、打乱组合出很多条样本外路径，看夏普分布而不是看最好的一条）。本程序第一步用「滚动前进 + 样本外 + 消融」就够。

## 5. 如何评估多因子 CTA 策略的表现？

不要只看收益率。按你 Excel 模板 + 行业习惯，最少看这些：

| 指标 | 怎么用 |
|------|--------|
| 样本外净盈亏、盈利因子 | 样本外期望 ≤ 0 或保留率很低 → 不能实盘 |
| 夏普 | CTA 常看；你模板里 >1.5 算合格，那是偏严的目标，日内 5 分钟很难稳定达到 |
| 最大回撤、回撤期长度 | 比收益更重要 |
| 盈亏比、胜率 | 趋势策略胜率往往 35%～45%，靠盈亏比吃饭 |
| 交易次数 | 太少统计没意义；5 分钟又太多则摩擦会吃光 |
| 以 R 计的盈亏 | R = 盈亏 ÷ (开仓 ATR × 止损倍数 × 乘数 × 手数)，跨品种才能比 |
| 关停率 | 过滤器关掉的时间占比；>50% 说明品种/周期和这套趋势根本不合 |
| 成本敏感性 | 1.5×、2× 成本后是否仍为正期望 |

**关停规则（策略级，不是单笔）：** 最近 20 笔相对全样本均 R 掉到一半以下、连续亏损超过历史极值、或样本外期望转负 → 降仓或停用，不要当场改参数硬扛。

## 6. 如何对跨周期多因子 CTA 进行回测和优化？

**结构（资料里最重要的一条，本程序目前还没有）：**

- **日线：** 只在日线收盘更新一次方向。收盘价在日线 MA60 上方才允许做多，下方才允许做空。盘中不重算。
- **5 分钟（或 15/60 分钟）：** 四个因子打分、开平仓、跟踪止损。
- 因子方向和日线不一致 → 该因子得分置 0，不是拿来做空。

**回测注意：**

- 用 1 分钟聚合成 5 分钟和日线，避免直接喂 5 分钟造成换月/开盘失真（本程序已有周期拼接，日线过滤要另拉日线或从分钟合成）。
- 日线 bias 只能用「已经收盘的那一根」，不能用今天还在走的日线。
- 优化时：**日线参数尽量不动**（MA60），只优化小周期阈值和过滤器，减少自由度。
- 本程序「长线趋势加减仓」已经是「大周期定方向、小周期进出」；多因子应复用这套跨周期骨架，而不是再引一套 vnpy。

**周期选择（补齐资料）：**

| 周期 | 适配 |
|------|------|
| 日线 | 机构最主流，噪声低，但本程序以日内清仓为主，先当过滤器 |
| 15 / 60 分钟 | 折中，假信号比 5 分钟少 |
| 5 分钟 | 可用，必须抬高阈值、过滤器要严、收盘清仓 |
| 1 分钟 | 不适合这套趋势投票 |

## 7. 每个因子独立绩效记录（监控衰减）

**每笔开仓快照：** 当时 4 个因子得分、权重、总分、ATR、是否过过滤器。  
**平仓后：** 总盈亏按开仓时 |得分| 占比分摊到 4 个因子。  
**滚动监控：** 近 20 笔、近 30 天、全样本的分摊盈亏、胜率、均 R。  
**衰减度：** 近 30 天均 R ÷ 全样本均 R。

| 衰减度 | 处置（你 Excel 模板） |
|--------|------------------------|
| ≥ 0.8 | 正常 |
| 0.5～0.8 | 观察，权重 ×0.7 |
| < 0.5 | 衰减，×0.4 |
| ≤ 0 | 置 0 |
| 全样本均 R≤0 | 因子无效 |
| 近 30 天不足 3 笔 | 样本不足，不改权重 |

本程序现在**没有**这笔归因日志。回测/实盘事件里只有总分，看不出是 SAR 在拖后腿还是唐奇安在假突破。这是下一阶段必须加的。

2. 没有日线方向过滤，5 分钟容易逆大趋势开仓。  
3. 没有因子分歧校验 + 没有跟踪止损上移。

## 建议的落地顺序（还没改代码，等你点头）

**第一期（先变成「能当主推」的完整规则，固定权重）：**

1. 打分改成资料里的 5 档，SAR 加翻转过多归零。  
2. 加上日线 MA60 方向过滤（盘中不改）。  
3. 加上因子分歧度（标准差 > 0.7 不开新仓）。  
4. 多因子自己的止损改为 2ATR 只朝有利方向移。  
5. 5 分钟默认阈值提到 0.65；SAR 做成可关掉的开关（3 因子/4 因子可切换）。  
6. 每笔记录四因子得分，平仓后分摊盈亏，方便你用已有 Excel 监控衰减。

**第二期（验证，不改规则）：** 单品种样本外回测 + 因子消融 + 过滤器消融 + 成本加倍。

**第三期：** 才考虑自适应权重；先固定权重跑稳。
