# ATR动态仓位一共4组核心参数（适配你这套5分钟跨周期CTA）

公式回顾：

![](https://cdn.nlark.com/yuque/__latex/d915fc6473071d51d972af35fe93c144.svg)

目标：**开仓被止损时，这笔亏损固定等于【账户资金 × 单笔风险比例】，波动大自动降手数、波动小自动加手数**

## 1. ATR周期 `atr_len`（指标参数）

- 推荐默认：**14**（行业标准，你5分钟周期就用5分钟K的ATR14）

- 备选：

- 10：更灵敏，快速跟上波动变化，噪声更大，仓位跳动频繁

- 20：更平滑，仓位变化稳定，对突发波动反应慢（原版海龟是ATR20）

✅ 你的场景：5分钟日内，优先 **atr_len=14**  
注意：ATR周期必须和你K线周期一致（5分钟K → 5分钟ATR，不要混日线ATR算日内仓位）

## 2. 单笔风险比例 `risk_ratio`（最核心风控参数）

含义：这笔单子被止损打掉，最多亏账户净值的百分之多少

- 散户小资金（你3万本金）推荐：**0.01（1%）**，起步首选
- 保守：0.005（0.5%），回撤更柔和，信号机会利用率低
- 激进：0.015（1.5%），盈利弹性大，连续止损回撤会明显放大

重点：**这是单品种单笔风险，不是总账户总风险**  
进阶约束（一定要加）：多品种同时持仓，**全部持仓合计风险上限 ≤ 3%**，防止多品种共振爆亏

## 3. ATR止损倍数 `atr_stop_multiple`

既是止损距离，同时参与仓位计算，**这个参数和仓位强绑定，不能单独乱改**

- 1.5：止损偏紧，5分钟日内常用；止损容易被正常震荡扫掉，同风险下仓位更大
- 2.0：**标准默认值（海龟原版）**，适合你的5分钟跨周期趋势策略，平衡噪声和趋势空间
- 2.5~3.0：止损很宽，少被扫损，但单笔亏损幅度变大，同等risk_ratio下仓位会明显变小

⚠️ 坑：你跟踪止损也用同一个倍数；如果开仓用2倍ATR算仓位，跟踪止损也要用2倍，不要两套倍数！

## 4. 仓位边界限制参数（硬边界，防止算出0手/超大手）

两个边界，必须写进代码：

- `min_volume = 1`：最低1手，期货不能0手交易
- `max_volume`：单品种上限，防止极端低波动下ATR极小，算出来几十手重仓  
  举例：燃油FU、纯碱SA，小资金建议 `max_volume=3`；玉米C可以设5

# 参数调优原则（非常关键）

1. **优先固定risk_ratio，不要频繁改它**；想要改变策略弹性，优先调ATR倍数或者ATR周期
2. 不要为了多开几手，随意放大risk_ratio；1%是散户CTA行业经典安全基准
3. 回测调参：不要网格暴力搜索，优先看【最大回撤、连续亏损次数、胜率】；参数对夏普、回撤的影响远大于因子打分
4. 区分两个东西：
- ATR仓位计算：**开仓那一刻一次性计算手数，开仓后不再改手数**
- ATR移动跟踪止损：每根K刷新止损价，和仓位计算共用一套ATR倍数
