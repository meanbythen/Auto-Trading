# 多因子复合CTA（打分式跨周期）完整落地步骤

适配你前面这套：4因子打分、大周期过滤、小周期入场、自适应权重、因子盈亏监控；vnpy CTA框架，国内商品期货日内。  
核心范式：**因子独立计算 → 标准化打分 → 权重合成总分 → 市场状态过滤 → 开平仓+风控 → 绩效归因 → 迭代**  
分为【方案设计→代码实现→回测校验→仿真→实盘】5大阶段，每一步可落地，避开常见坑。

先区分：你这套是**打分加权型多因子**（不是机器学习多因子），每个因子输出[-1, 0, 0.5, 1]标准化信号，加权求和，和并行多策略、投票制多因子不一样。

## 阶段1：策略顶层方案设计（最容易跳过，决定会不会过拟合）

### Step1.1 确定周期架构（跨周期规则固化）

1. 选定**趋势过滤大周期**：日线（你当前方案：日线MA60判断多空bias，一票否决反向信号）

2. 选定**信号交易小周期**：5min（生成因子打分、开平仓、止损）

3. 周期对齐规则：
- 日线Bar只在收盘更新，盘中不重算日线bias；

- 小周期每根5minBar更新全部因子得分、总分；
4. 交易约束：日内策略，收盘强制清仓，不隔夜。

### Step1.2 因子定义、打分映射、方向约束（你前面4因子标准）

每个因子必须做到：**输出统一值域 [-1, -0.5, 0, 0.5, 1]**

- 正向多头信号：+0.5 / +1
- 反向空头信号：-0.5 / -1
- 无信号/缠绕/和大周期方向相反：0

重点：每个因子独立加**大周期bias过滤**，因子方向和日线bias冲突时直接置0，而不是参与负向加权。  
逐个写明：因子计算公式、触发条件、打分表、参数（MA20/60、唐奇安20、布林20-2σ、SAR AF0.02）

### Step1.3 权重方案二选一（二选一，不要混着写）

方案A：固定权重（基准版本）  
预先给定权重，总和=1，如ma=0.3, don=0.25, boll=0.25, sar=0.2；适合做基准、样本外对照。

方案B：自适应权重（你后面版本）

- 权重更新触发时机：**每平仓一笔交易后更新，不是每根K更新**（防止权重震荡）
- 绩效回看窗口：N笔历史成交（lookback_trades=20）
- 盈亏分摊规则：按该笔开仓时各因子得分绝对值占比分摊这笔交易PnL到各个因子
- 约束：min_weight / max_weight 上下限，权重归一化总和=1
- 亏损因子窗口累计盈亏为负 → 原始得分截断到0，不分配高权重

### Step1.4 市场状态过滤器（顶层开关，is_tradeable）

过滤器是多因子CTA的“降噪器”，**先过滤，再判断开仓信号**，不满足直接不交易：

1. ADX(14)过滤：ADX<20 → 趋势弱，禁止开仓
2. ATR波动率分位过滤：ATR处于近60日分位<0.2，波动率过低，不交易
3. 因子分歧度过滤：4因子得分标准差>阈值（0.7），因子打架，信号不可信

过滤器和因子打分是两层：过滤器决定“今天能不能做”；打分决定“要不要开多/空”

### Step1.5 交易规则、平仓规则、风控规则（逐条写死，不能模糊）

1. 开仓阈值：总分>0.6做多，总分<-0.6做空；无持仓才开仓
2. 平仓三类出口（并行生效）
- 跟踪止损：ATR*2移动跟踪止损（你当前方案）
- 信号反转平仓：总分反向突破阈值
- 收盘强制清仓
3. 仓位计算：单笔风险固定为总资金1%，ATR动态手数  
   ![](https://cdn.nlark.com/yuque/__latex/b994ff7d7652b4e494b8e4707f39974e.svg)
4. 禁止加仓、禁止锁仓（你当前框架）

### Step1.6 归因方案设计

每一笔开仓快照：记录当时4个因子得分；平仓后按得分绝对值分摊盈亏，统计每个因子独立PnL、胜率、交易次数。

目的：后期定位哪个因子失效、风格不匹配。

## 阶段2：代码实现（vnpy CtaTemplate标准流程，和你代码一一对应）

### Step2.1 数据层：BarGenerator + ArrayManager 跨周期缓存

1. 两个BarGenerator：一个聚合5minBar，一个聚合1440根分钟Bar生成日线Bar
2. 两个ArrayManager：am5（5min指标计算）、am_day（日线趋势过滤）
3. 注意：ArrayManager长度要足够容纳指标最大参数（sar、布林、唐奇安、ATR、ADX）
4. 数据时序约束：**必须等两个ArrayManager都inited之后，才开始计算指标**，避免前向数据泄露

### Step2.2 因子函数模块（独立计算每个因子score）

把4个因子写成独立计算逻辑，每个因子输出score，并且内置大周期bias校验：

```
calc_ma_score()
calc_donchian_score()
calc_boll_score()
calc_sar_score()
```

✅ 好处：后期单独注释某个因子，做因子消融测试（去掉SAR，看绩效变化）

### Step2.3 总分合成 + 自适应权重模块（可选）

- 固定权重：直接加权求和
- 自适应权重：单独写`update_adaptive_weight()`函数，**仅平仓成交回调on_trade中调用**
- 计算因子分歧度 np.std([score1,score2,score3,score4])

### Step2.4 市场状态过滤器计算，生成is_tradeable标记

顺序：先算ADX、ATR分位、分歧度 → 赋值is_tradeable

### Step2.5 信号判断、下单逻辑

顺序严格不能乱：

1. 先全部撤单 cancel_all()
2. 判断收盘时间，满足直接清仓return，不再执行后面开仓逻辑
3. 计算可开仓手数
4. 无持仓 + is_tradeable=True + 总分突破阈值 → 开仓，保存开仓快照（open_record）
5. 持仓状态下：更新ATR跟踪止损，检查止损触发、信号反转平仓

### Step2.6 成交回调 on_trade 归因模块（核心监控）

1. 区分开仓成交 / 平仓成交
2. 平仓成交时：计算这笔交易总盈亏
3. 按因子得分绝对值分摊盈亏到4个因子
4. 自适应版本：把分摊后的PnL压入每个因子deque队列，触发权重更新
5. 保存完整交易记录

### Step2.7 策略停止回调 on_stop：输出因子绩效报表

打印每个因子独立盈亏、次数、胜率；可扩展写入CSV。

编码避坑清单

- ❌ 不要用未来函数，指标全部用ArrayManager历史序列，不引用未来bar
- ❌ 不要盘中动态修改日线bias（日线只收盘更新）
- ❌ 不要每根K更新自适应权重（噪声巨大）
- ✅ 所有参数放在parameters，方便回测引擎调参
- ✅ 变量放入variables，vnpy回测时可以查看时序曲线（总分、各因子得分、权重）

## 阶段3：回测、校验、消融测试（最重要，决定策略能不能用）

### Step3.1 回测环境配置

- 品种：优先你常做的：FU燃油、SA纯碱、C玉米；单品种单独回测，不要多品种混在一起调参
- K线：1min原始K，由BarGenerator聚合5min、日线；
- 回测参数：手续费、滑点、合约乘数、保证金、涨跌停、换月逻辑（vnpy的连续合约）
- 样本切分：**时间序列切分，不能随机打乱**  
  例：2020-2024训练集，2024-2026样本外（OOS）

### Step3.2 基准回测（固定权重版本作为基准）

输出整套绩效：净值曲线、夏普比率、最大回撤、盈亏比、胜率、交易次数、盈亏分布。

### Step3.3 因子消融测试（多因子必做）

逐个剔除因子，对比基准绩效：

1. 去掉SAR，其余3因子
2. 去掉布林，其余3因子
3. 去掉唐奇安，其余3因子
4. 去掉均线，其余3因子  
   目的：判断**哪个因子是正向贡献、哪个是冗余/拖累因子**；很多时候SAR在震荡品种里是负贡献。

### Step3.4 过滤器消融测试

依次关闭ADX、ATR分位、分歧过滤器，看回撤、胜率变化，确认过滤器是否真的有效。

### Step3.5 自适应权重版本对照测试

同一份K线，跑固定权重 vs 自适应权重，对比样本外绩效：

- 自适应是否改善夏普/回撤？
- 是否出现过拟合：训练集大幅提升，样本外变差？

自适应权重天然容易过拟合，这一步是红线。

### Step3.6 因子衰减分析

导出每笔交易CSV，画出4个因子随时间的滚动盈亏曲线，观察：

- 某个因子在某一段持续亏钱（风格切换，因子失效）
- 自适应权重是否在失效阶段自动压低该因子权重

### Step3.7 参数敏感性测试

扫描关键参数：ADX阈值、ATR止损倍数、打分阈值、lookback_trades窗口长度  
看绩效是否在参数附近平稳；如果只有极窄参数区间绩效好 → 过拟合。

## 阶段4：仿真盘验证（SimNow）

回测通过≠可以实盘，回测存在滑点、跳空、撮合理想化偏差：

1. 部署到vnpy仿真，跑至少1~2个月

2. 对比仿真净值曲线 和 同周期回测曲线，看漂移（回测虚高）

3. 重点监控：
- 开盘跳空场景止损是否和回测一致

- 收盘清仓能否正常成交

- 自适应权重是否在实盘时序下稳定，不会频繁剧烈跳动
4. 日志持续观察：各因子得分、权重、过滤器触发次数

---

## 阶段5：实盘上线 & 持续监控

1. 小资金试跑，严格沿用仿真完全一致参数，不临时调参

2. 实盘监控指标（每日）
- 整体净值、回撤

- 4因子独立盈亏（实盘归因）

- 过滤器触发频率、权重变化区间
3. 下线规则：
- 因子集体持续亏损、风格漂移

- 实盘绩效和仿真持续大幅偏离
4. 迭代：重新回到阶段1，修改因子/过滤器，重新回测，**禁止实盘中直接改参数**

# 补充：和其他多因子CTA的区别（避免混淆）

1. 打分加权型（你这套）：适合趋势类因子，信号连续、可归因，上手可控，缺点是因子之间线性叠加；
2. 投票制多因子：每个因子独立策略，多数票开仓；
3. 机器学习多因子：LR/XGB输出开仓概率，复杂，归因困难，更容易过拟合；

你当前这套打分跨周期，是国内散户CTA最适合落地、可控、可归因的路线。
