# 所有“稳定盈利策略”共享的底层规则（比策略本身重要一万倍）

市面上所有能长期活下来的策略，都附带这几条，单独拿出来：

1. 策略有明确的【适用行情】，并且有开关：行情不匹配直接停手，而不是24小时一直跑
2. 固定止损，单笔亏损上限严格控制（通常单笔≤总资金1%）
3. 仓位管理：ATR动态仓位，而不是固定手数
4. 收益期望为正：盈利时赚的钱 > 亏损时亏的钱（高盈亏比，或者高胜率）
5. 交易成本纳入回测：手续费、滑点、冲击成本，很多回测好看的策略，扣完手续费直接变成负期望
6. 定期监控策略衰减：每个季度评估绩效，夏普、最大回撤、胜率，如果持续偏离历史，停止使用

# 避坑提醒

1. 不要去搜“稳定盈利期货策略源码”，99%是回测过拟合、没有考虑滑点手续费；
2. 没有任何策略可以永远稳定；**策略的生命周期，短则几个月，长则数年**；
3. 套利策略看着回撤小，一旦遇到逼仓、交割规则变化，会出现黑天鹅；
4. 均值回归策略是散户亏损重灾区，最常见的错误：在趋势里不断抄底加仓。

# 1. 双均线趋势策略

核心思想：用长均线定大方向，短均线抓趋势启动；只顺着大方向开仓，减少逆势假信号。

### 版本A：日线波段（适合隔夜波段）

参数：短均线MA20，长均线MA60

- 方向判定：价格在MA60之上 → 只做多；价格在MA60之下 → 只做空
- 开仓： 做多：MA20上穿MA60（金叉），且当前K线收盘价 > MA60； 做空：MA20下穿MA60（死叉），且当前K线收盘价 < MA60；
- 止损：2×ATR(20)，放在开仓反向一侧
- 出场二选一（二选一，不要混用） 方案1（均线出场）：反向交叉平仓； 方案2（移动ATR止盈止损）：盈利后用1.5ATR跟踪，不主动止盈，被扫就离场
- 仓位：账户资金 / (ATR × 合约乘数 × 价格)，单品种单笔风险控制在总资金1%以内
- 过滤（可选，很关键）：ATR(20) < 近60日ATR分位20% → **禁止开仓（低波动震荡）**

### 版本B：5分钟日内版（适合你日内、收盘清仓）

参数：MA5、MA20

- 方向：价格在MA20上方，只做多；价格在MA20下方，只做空
- 开仓：MA5上穿MA20做多；MA5下穿MA20做空
- 止损：1.5×ATR(14)
- 强制规则：收盘前N分钟全部平仓（你是收盘清仓，硬性离场）
- 过滤：ATR低于近20日20%分位，停止开仓

✅ 优势：简单、可程序化、逻辑稳定 ❌ 缺陷：震荡行情反复交叉，连续小亏

### 【双均线：行情不匹配，关停信号】

1. ATR持续压缩，波动率长期处于历史低位；
2. 均线频繁缠绕，一天内金叉死叉来回3次以上；
3. 价格在长均线上下快速来回穿，没有持续偏向；
4. 基本面突发强扰动（比如燃油隔夜连续大幅跳空，缺口不收敛、价格无序）。

# 2. 海龟交易法则（原版经典，重点：突破+ATR动态仓位，不是单纯突破）

原版海龟是日线中长线，不适合高频；日内海龟假突破爆炸，谨慎改成短周期 参数：

- 入场周期：20日突破（唐奇安通道）
- 离场周期：10日突破
- ATR周期：ATR(20)，止损：2ATR
- 单位仓位N = 账户总资金 × 1% ÷ (ATR × 合约乘数)

含义：每一个单位仓位，单笔最大亏损控制在总资金1%

- 加仓规则：盈利后，每向上移动0.5ATR，加一个单位；最多4个单位
- 减仓/风控：总账户最大回撤20%，全部清仓停止交易

### 日线原版完整规则

1. 做多：收盘价突破过去20日最高价 → 开多N手
2. 做空：收盘价突破过去20日最低价 → 开空N手
3. 初始止损：开仓价 - 2ATR（多单）；开仓价 + 2ATR（空单）
4. 离场： 多单：跌破近10日低点平仓； 空单：突破近10日高点平仓；
5. 加仓：盈利后，距离前一笔开仓价0.5ATR再加一单，最多4层；每一笔加仓都单独带2ATR止损
6. 硬性风控：单日/单品种亏损上限；总账户回撤达到阈值直接停手

### 5分钟日内海龟（简化版，不建议加仓，日内假突破太多）

5分钟：20根K高低点突破入场，10根K高低点出场；止损1.5ATR；**禁止加仓，收盘强制平仓**

✅ 优势：趋势行情爆发力极强，仓位随波动率自动调节 ❌ 缺陷：震荡里假突破密集，连续止损，回撤大

### 【海龟：行情不匹配，关停信号】

1. 长期区间震荡，价格反复触碰20高低点但是走不出趋势，突破后快速跌回通道内；
2. 波动率忽高忽低、跳空极多（燃油经常遇到），突破当天直接反向大阴线；
3. 品种流动性下滑，盘口滑点巨大；
4. 连续5笔以上突破信号全部亏损（趋势衰竭）。

海龟最怕：假突破行情，这是它最核心的失效环境。

# 3. 布林带突破策略（趋势版，**不要做轨道反转**，反转是均值回归）

布林公式： 中轨 = MA20；上轨 = MA20 + 2×STD(20)；下轨 = MA20 − 2×STD(20)

趋势版：只顺着中轨方向做突破，不碰逆势反转

### 日线波段版

参数：MA20，2倍标准差

1. 方向过滤：价格 > 中轨 → 只做多；价格 < 中轨 → 只做空
2. 开仓： 多头：收盘价向上突破上轨做多； 空头：收盘价向下跌破下轨做空；
3. 止损：2ATR，或者跌破中轨（二选一，ATR更稳）
4. 出场： 方案A：价格回落到中轨离场； 方案B：ATR移动跟踪止损，不主动止盈
5. 过滤：ATR低于近60日20%分位，不开仓

### 5分钟日内版

参数：MA20，2倍标准差

1. 价格在中轨之上，只做多；价格在中轨之下，只做空
2. 突破上轨做多、突破下轨做空
3. 止损：1.5ATR
4. 收盘强制清仓

✅ 优势：自带波动率自适应，通道随波动放大缩小 ❌ 缺陷：震荡市反复刺破上下轨，连续扫损；行情从趋势直接切换成震荡时，亏损集中出现

### 【布林突破：行情不匹配，关停信号】

1. 价格紧贴中轨来回小幅震荡，反复触碰上下轨但是无法走出趋势；
2. 通道持续收窄后，突破一根K立刻收回轨内（诱多诱空）；
3. 波动率快速暴涨暴跌，通道在几根K内剧烈变形（消息驱动无序行情）；
4. 中轨走平、横向运行，没有明显倾斜。

一个简单判断：中轨倾斜角度是趋势的核心；中轨走平=布林突破策略应该休息。

# 4. 波段SAR趋势策略（抛物转向，自带移动止损）

SAR公式：加速因子AF，初始0.02，最大0.2；价格创新高AF增加0.02

### 日线波段版

1. 方向：SAR在K线下方 → 多头趋势；SAR在K线上方 → 空头趋势
2. 开仓： 做多：SAR落到K线下方，翻多信号出现；叠加过滤：价格在MA60之上才允许做多 做空：SAR跑到K线上方，翻空信号出现；叠加过滤：价格在MA60之下才允许做空
3. 止损：SAR本身就是移动止损，不需要额外设置；K线触碰SAR自动离场
4. 可选出场：也可以叠加ATR止盈，或者固定盈亏比
5. 仓位：单笔风险控制总资金1%，用ATR换算手数

### 5分钟日内SAR版本

1. 过滤：MA20判定大方向，只顺MA20方向做SAR翻转信号
2. SAR翻转开仓；SAR反向触碰K线离场
3. 收盘强制清仓
4. 过滤：ATR过低，直接屏蔽SAR信号

✅ 优势：天然移动跟踪止损，趋势拿得住，不用主观设止盈 ❌ 缺陷：震荡行情SAR来回翻转，高频扫止损，是这个策略最大痛点

### 【SAR波段：行情不匹配，关停信号】

1. SAR在K线上下来回切换，翻转频率很高（震荡）；
2. K线实体很小、十字星密集，价格横盘；
3. 跳空开盘后，SAR位置断层，指标和价格脱节（燃油大幅跳空经常出现）；

重点：跳空会让SAR的计算基点错位，当天SAR信号可信度大幅下降，就是行情不匹配。

# 5. 多因子复合CTA策略（私募主流，不是简单叠加，是打分加权）

核心：不再单一指标决定开仓；多个独立因子打分，总分达标才开仓；同时给每个策略加开关，某个因子失效就降低权重或者关掉。 因子池（趋势类为主，你前面4个策略就是底层因子）

- 趋势因子1：双均线打分（MA20/MA60方向+偏离度）
- 趋势因子2：唐奇安突破打分（距离N周期高低点位置）
- 趋势因子3：布林轨道打分（相对布林上下轨位置）
- 趋势因子4：SAR方向打分
- 波动率因子：ATR、历史波动率分位（用来降权、关停）
- 量价因子：放量、持仓增减（可选）

## 完整规则示例（简化可落地版本）

1. 每个因子标准化到 [-1, +1]，+1多头最强，-1空头最强
- 例：双均线金叉+价格在长均线上方=+1；死叉+价格在长均线下方=-1；缠绕=0
- 唐奇安突破新高=+1，突破新低=-1，中间区间=0
- SAR翻多=+1，翻空=-1，震荡频繁翻转=0
2. 设置权重（可以动态，也可以固定） 双均线0.3，唐奇安0.25，布林0.25，SAR0.2
3. 总分 = 各因子得分 × 权重
- 总分 > 0.6：做多信号
- 总分 < -0.6：做空信号
4. 波动率风控因子（一票否决） 如果ATR落在近60日最低20%分位 → 所有因子权重归零，禁止开仓
5. 止损：2ATR；仓位：根据总分强弱分配仓位（分数越高仓位略高，上限锁死）
6. 出场：总分反向穿越阈值，或者被ATR止损打掉；日内版收盘清仓

进阶动态版本：给每个子策略单独算绩效，如果最近N笔信号亏损多，自动降低该因子权重（自适应）

✅ 优势：单一策略失效时，其他因子可以对冲，曲线更平滑；可以单独关停某一个子模块 ❌ 缺陷：参数多，极易过拟合；开发、回测、监控成本高

### 【多因子策略：行情不匹配，关停信号】

两种层级：

1. 局部关停：某一个子因子连续亏损，单独降低权重/关闭这个因子（比如震荡期关掉SAR）
2. 全局关停：
- 全部趋势因子得分来回拉扯，正负交替，总分一直在0附近来回震荡；
- 波动率持续低位；
- 基本面驱动无序跳空、消息冲击频繁，各个因子信号互相冲突；
- 整体策略最近20笔交易夏普显著下降、连续回撤。

# 第二大块：通用方法——怎么判断【行情和当前策略不匹配】（你最关心的部分）

核心逻辑：**每一类策略都有它依赖的“市场状态”，市场状态可以用4个维度量化：趋势强度、波动率、自相关性、资金驱动类型**。 下面是一套标准化判断流程，程序化可以写成代码，人工也可以每天开盘前评估。

## 维度1：趋势强度（趋势策略第一判断标准）

指标：

- ADX（平均趋向指数），非常好用

- ADX＞25：存在趋势，适合所有趋势类策略（双均线、海龟、布林、SAR）

- ADX＜20：趋势极弱，震荡环境 → **所有趋势策略应当降低仓位或者关停**

补充：ADX本身没有方向，只告诉你有没有趋势；还要搭配+DI/-DI看多空方向。

## 维度2：波动率水平（ATR/历史波动率分位）

拿近60日ATR做百分位：

- ATR ＞60日70%分位：高波动，趋势策略友好，但跳空、滑点风险上升；
- ATR 在20%~70%：最舒服区间；
- ATR ＜20%分位：低波动压缩，趋势策略天敌，直接关停趋势类策略。

## 维度3：价格自相关性（简单理解：上涨之后第二天继续涨的概率）

简单观测方式： 统计最近N根K，同向K占比； 趋势行情：同向K占比高；震荡：涨跌交替、来回反转。 程序化可以用：一阶自相关系数。

肉眼快速版：连续同向K很少，涨一根跌一根，就是震荡，趋势策略不匹配。

## 维度4：驱动类型（基本面/消息驱动，人工+量化结合）

分三类：

1. 资金趋势驱动（适合趋势策略）：库存、供需缓慢变化，行情稳步走，跳空少；
2. 消息脉冲驱动（不适合趋势策略）：隔夜外盘、地缘、政策，频繁大幅跳空，价格一次性定价，之后快速反转；燃油经常遇到这个；
3. 无驱动震荡（不适合趋势策略）：供需平衡、库存平稳，在区间来回磨。

## 维度5：策略自身绩效反馈（事后验证，非常重要，是策略的“自我体检”）

不要只看行情指标，还要看策略本身的交易记录： 设定监控窗口：最近15~20笔该策略信号

- 胜率明显低于历史正常区间；
- 盈亏比大幅下滑；
- 连续亏损次数超过历史极值； → 判定：当前市场状态和这个策略不匹配，暂停。

## ✅ 给你一个可以直接用的【每日开关检查表（趋势策略通用）】

满足任意一条 → 当日不开仓趋势策略：

1. ADX＜20；
2. ATR处于近60日20%分位以下；
3. 近20根K，涨跌交替频繁，没有连续同向K；
4. 隔夜大幅跳空，且开盘半小时快速回补缺口（脉冲消息驱动，容易反转）；
5. 该策略最近20笔绩效显著变差，连续亏损。

补充一个关键误区： ADX高≠一定适合趋势策略；如果ADX很高，但是是暴涨暴跌来回V型反转（高波动无序），同样不适合趋势跟踪，这种行情下突破策略会被来回扫。 ADX高 + 价格有序沿一个方向推进，才是完美匹配。

## 补充：不同策略适配的市场状态对照表

| 策略     | 喜欢的状态               | 不匹配（要关停）的状态           |
| ------ | ------------------- | --------------------- |
| 双均线    | ADX>25，波动率中等，均线有序倾斜 | ADX低、均线缠绕、频繁交叉        |
| 海龟突破   | ADX抬升，流畅趋势，突破后持续延伸  | 区间震荡、假突破多、突破快速回落      |
