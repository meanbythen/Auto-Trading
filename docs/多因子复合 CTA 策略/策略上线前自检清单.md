# 一、策略上线前自检清单（打分式多因子CTA，适配你的vnpy日内跨周期4因子策略）

使用方式：每一项核对，打√，有问题标记，全部通过再进仿真/实盘  
分类：【逻辑与未来函数】【数据与周期】【因子打分&权重】【交易&平仓规则】【风控】【回测校验】【仿真前置】【日志归因】

## 1. 逻辑 & 未来函数（最高优先级）

- [ ] 所有指标仅用历史Bar，**没有取当前未闭合Bar的未来数据**，不用`[-0]`在bar内部偷未来值
- [ ] 日线趋势信号只在日线Bar收盘更新，盘中不刷新日线多空bias
- [ ] 因子打分：因子方向和大周期bias相反时直接置0，不会反向加权
- [ ] 没有在`on_bar`内部修改历史队列、历史成交记录
- [ ] 自适应权重仅在**平仓成交回调on_trade**更新，不是每根K更新
- [ ] 不存在价格预判、跳空预填充、偷看后面K线的写法
- [ ] 止损、开仓信号全部基于已闭合Bar指标（如果是收盘触发型）

## 2. 数据 & 周期聚合

- [ ] BarGenerator、ArrayManager长度足够容纳指标最大参数（SAR、布林、ADX、ATR、唐奇安）
- [ ] 原始数据是1min K线，由框架聚合5min、日线，不是直接导入5min线（避免换月/跳空失真）
- [ ] 跨周期初始化判断：`am5.inited and am_day.inited`，指标未预热完成不产生任何信号
- [ ] 连续合约换月逻辑在回测引擎配置，策略内部不自己处理换月价差
- [ ] 时区、时间对齐：收盘清仓时间和交易所时间匹配，区分日盘/夜盘收盘
- [ ] 回测参数：手续费、滑点、合约乘数、保证金比例和真实交易所一致

## 3. 因子打分 & 权重逻辑

- [ ] 每个因子输出值域固定：`[-1, -0.5, 0, 0.5, 1]`，打分表文档留存
- [ ] 因子独立开关可单独注释，支持消融测试
- [ ] 自适应权重：设置min_weight / max_weight，权重总和强制归一=1
- [ ] 权重更新依赖成交队列deque，队列长度等于lookback_trades
- [ ] 分母保护：求和除以权重/得分总和时，全部加极小值防除0报错 `+1e-6`
- [ ] 因子分歧度计算正常，分歧过滤器（标准差阈值）生效

## 4. 开仓、平仓、信号规则

- [ ] 开仓前置判断：`is_tradeable=True`（ADX+ATR波动率+分歧过滤）+ 无持仓
- [ ] 开仓阈值：总分 > long_threshold / 总分 < short_threshold，阈值写死在参数
- [ ] 三类平仓出口并行：ATR跟踪止损、反向信号平仓、收盘强制清仓
- [ ] 禁止加仓、禁止锁仓；同一时间只允许1个方向持仓
- [ ] 收盘清仓逻辑：到达收盘时间，优先清仓，不再执行开仓判断
- [ ] 下单前先`cancel_all()`，防止残留挂单
- [ ] 手数计算公式：固定单笔风险1%，ATR动态计算，手数≥1，向下取整

## 5. 风控规则

- [ ] 单笔风险上限：单仓最大亏损控制在总资金1%
- [ ] ATR止损倍数参数可配置，跟踪止损只会向有利方向移动，不会回撤
- [ ] 品种熔断开关（可选）：品种日内最大回撤阈值，触发后停止开新仓
- [ ] 总资金回撤熔断（可选）：账户回撤达到阈值，冻结开仓，只允许平仓
- [ ] 涨跌停判断：涨停不开多、跌停不开空（回测+实盘都要考虑）

## 6. 回测校验项（必须做完）

- [ ] 数据集时间切分：训练集、样本外OOS严格时间分割，**没有随机打乱**
- [ ] 基准：固定权重版本作为基准，自适应版本和基准对比
- [ ] 因子消融测试：逐个剔除因子，确认每个因子贡献
- [ ] 过滤器消融测试：关闭ADX/ATR/分歧过滤器，确认过滤器降低回撤
- [ ] 参数敏感性扫描：关键参数附近绩效平稳，不存在“窄峰过拟合”
- [ ] 绩效指标：夏普、最大回撤、盈亏比、胜率、交易次数、盈亏分布导出
- [ ] 样本外绩效不显著崩塌，训练集高收益、样本外大幅缩水标记为过拟合

## 7. 仿真前置检查（SimNow上线前）

- [ ] 回测代码和仿真代码完全一致，没有临时改参数
- [ ] 日志输出开启：每笔开仓记录因子得分、当前权重、总分、过滤器状态
- [ ] 检查跳空场景：开盘跳空时止损触发逻辑是否符合预期
- [ ] 收盘清仓：夜盘、日盘收盘的清仓订单可正常成交
- [ ] 自适应权重变化幅度合理，不会单笔平仓后权重剧烈跳变

## 8. 归因 & 日志监控

- [ ] 每笔开仓快照保存4个因子得分，平仓后按得分绝对值分摊PnL
- [ ] 策略停止时自动打印因子绩效报表（盈亏、次数、胜率）
- [ ] 支持导出交易明细CSV，用于pandas绘图分析衰减
- [ ] 日志字段齐全：时间、方向、开仓价、平仓价、各因子score、权重、总分、pnl

# 二、Pandas 因子衰减绘图代码

本程序 **11.7.0** 已按这一节做成按钮和命令，不必单独开 Jupyter：

- 界面：历史回测页 →「画出因子衰减图」
- 命令：`python -m src.export.factor_decay_plot`
- 字段：本程序用 `score_turtle`（不是下面示例里的 `don_score`）；资料那种 CSV 也能读

下面示例仍可对照原理。

用途：读取策略导出的交易CSV，绘制**4个因子滚动盈亏曲线**，看因子什么时候开始失效（衰减）  
适配前面策略输出的交易记录格式；可以在jupyter / py脚本里运行  
依赖：`pandas, matplotlib`  
说明：

- 窗口：滚动20笔交易滚动盈亏（和你自适应lookback窗口对齐）
- 图：4张子图，每个因子独立滚动盈亏曲线
- 同时输出因子累计总盈亏曲线

```
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# ====================== 配置区 ======================
CSV_PATH = "factor_trade_log.csv"  # 策略导出的交易csv路径
ROLL_WINDOW = 20  # 和自适应lookback_trades保持一致
# ====================================================

def load_and_preprocess(csv_path):
    df = pd.read_csv(csv_path, parse_dates=["datetime"])
    # 按时间排序
    df = df.sort_values("datetime").reset_index(drop=True)

    # 盈亏分摊公式，和策略内保持一致
    def calc_factor_pnl(row):
        s_ma = abs(row["ma_score"])
        s_don = abs(row["don_score"])
        s_boll = abs(row["boll_score"])
        s_sar = abs(row["sar_score"])
        total_s = s_ma + s_don + s_boll + s_sar
        if total_s < 1e-6:
            return pd.Series([0, 0, 0, 0])
        p_ma = row["pnl"] * s_ma / total_s
        p_don = row["pnl"] * s_don / total_s
        p_boll = row["pnl"] * s_boll / total_s
        p_sar = row["pnl"] * s_sar / total_s
        return pd.Series([p_ma, p_don, p_boll, p_sar])

    df[["pnl_ma", "pnl_don", "pnl_boll", "pnl_sar"]] = df.apply(calc_factor_pnl, axis=1)
    return df

def plot_factor_decay(df):
    fig, axes = plt.subplots(4, 1, figsize=(14, 12), sharex=True)
    fig.suptitle("多因子CTA 因子滚动盈亏衰减曲线（滚动窗口={}笔）".format(ROLL_WINDOW), fontsize=14)

    factor_names = ["ma", "don", "boll", "sar"]
    col_names = ["pnl_ma", "pnl_don", "pnl_boll", "pnl_sar"]
    colors = ["#1f77b4", "#ff7f0e", "#2ca02c", "#d62728"]

    for i, (fname, cname, c) in enumerate(zip(factor_names, col_names, colors)):
        # 滚动窗口盈亏
        roll_pnl = df[cname].rolling(window=ROLL_WINDOW).sum()
        # 累计盈亏
        cum_pnl = df[cname].cumsum()

        ax = axes[i]
        ax.plot(df["datetime"], roll_pnl, label=f"{fname} 滚动{ROLL_WINDOW}笔盈亏", color=c, lw=1.5)
        ax.plot(df["datetime"], cum_pnl, label=f"{fname} 累计盈亏", color=c, linestyle="--", lw=1.2)
        ax.axhline(y=0, color="k", lw=0.8, alpha=0.6)
        ax.set_ylabel(f"{fname} 盈亏")
        ax.legend(loc="upper left")
        ax.grid(alpha=0.3)

    plt.xlabel("时间")
    plt.tight_layout()
    plt.savefig("factor_decay_plot.png", dpi=300, bbox_inches="tight")
    plt.show()

    # 打印汇总表
    summary = pd.DataFrame({
        "总盈亏": [df["pnl_ma"].sum(), df["pnl_don"].sum(), df["pnl_boll"].sum(), df["pnl_sar"].sum()],
        "交易次数": [
            (df["pnl_ma"] != 0).sum(),
            (df["pnl_don"] != 0).sum(),
            (df["pnl_boll"] != 0).sum(),
            (df["pnl_sar"] != 0).sum()
        ],
        "盈利次数": [
            (df["pnl_ma"] > 0).sum(),
            (df["pnl_don"] > 0).sum(),
            (df["pnl_boll"] > 0).sum(),
            (df["pnl_sar"] > 0).sum()
        ]
    }, index=factor_names)
    summary["胜率"] = summary["盈利次数"] / summary["交易次数"]
    print("====因子绩效汇总====")
    print(summary.round(2))

if __name__ == "__main__":
    df_data = load_and_preprocess(CSV_PATH)
    plot_factor_decay(df_data)
```

## CSV字段说明（你的策略需要导出这些字段到csv）

```
# 在策略on_stop里追加，导出交易明细
import csv
def export_trade_csv(self):
    with open("factor_trade_log.csv", "w", encoding="utf-8-sig", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=[
            "trade_id", "datetime", "direction",
            "ma_score", "don_score", "boll_score", "sar_score",
            "entry_price", "exit_price", "volume", "pnl"
        ])
        writer.writeheader()
        for r in self.trade_records:
            writer.writerow({
                "trade_id": r.trade_id,
                "datetime": r.datetime,
                "direction": r.direction,
                "ma_score": r.ma_score,
                "don_score": r.don_score,
                "boll_score": r.boll_score,
                "sar_score": r.sar_score,
                "entry_price": r.entry_price,
                "exit_price": r.exit_price,
                "volume": r.volume,
                "pnl": r.pnl
            })
```

## 看图解读要点（快速判断衰减）

1. 滚动盈亏持续在0轴下方：这个因子当前市场环境失效，自适应权重理应压低它
2. 累计盈亏曲线由上行转为持续走平/下行：因子风格漂移，开始衰减
3. 多个因子同步向下：整体市场不适合这套趋势策略（震荡市）
4. 滚动盈亏剧烈上下跳：信号噪声大，考虑调高分歧过滤器阈值
