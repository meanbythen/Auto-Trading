三、仓位管理（适配你3万本金、日内期货，ATR动态仓位，vnpy可直接写）
核心：单笔最大风险固定，用ATR和止损区间自动算手数，而不是固定手数
单笔风险上限：总资金 1%~1.5%（日内不建议超过2%）
公式：
单笔允许亏损金额 = 账户资金 × 风险比例
每手亏损点数 = 开仓价 - 止损价
交易手数 = 单笔允许亏损金额 ÷（每手亏损点数 × 合约乘数）
举例：纯碱，止损距离是20点，合约乘数20；账户3万，单笔风险1%=300元
每手最大亏损=20×20=400元 → 本次只能开0手，说明波动太大，放弃；
这就是天然过滤高波动跳空风险。
硬性规则：同一个品种，同一个周期，同时只持有1笔该策略单子，不叠加加仓；加仓会叠加流动性风险。

六、策略底层逻辑复盘（对齐你说的市场存续理论）
期货市场需要持续流动性，流动性来源有两块：
1. 主动流动性：主动吃盘的单子（主力、做市商市价单）
2. 被动流动性：挂单，其中最大一块就是散户预埋止损单
做市商/大资金的一个稳定盈利模式：去触碰被动流动性池（公共止损区），吃掉止损单获得对手盘，完成成交。
但主力不可能无限持续推：止损单是有限的，一个区间内的止损单被吃完之后，短期被动流动性枯竭。
● 如果是趋势行情：流动性吃完之后，原来趋势方向的力量重新主导，价格回流，就是我们的进场窗口；
● 如果是震荡行情：吃完止损之后反向又有另一批止损，来回收割，没有回流，也就是我们ADX过滤要砍掉的场景。
你的原始想法的问题：直接在止损区上方挂单，等于你预判主力扫完止损就拉。但主力经常是：扫止损→小幅拉一下→再二次砸，把在止损区上方抄底的人一起打掉，这就是“诱多二次收割”，所以我们增加【击穿+衰竭确认】，把预判开仓改成确认流动性已经释放之后再进场，降低被二次收割概率。
