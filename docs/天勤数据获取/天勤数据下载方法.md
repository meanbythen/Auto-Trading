# ✅ 一句话：**不需要单独下载客户端软件！**
天勤Tick历史下载是 **TqSdk（Python库）里面的 `DataDownloader`**，纯Python接口，**没有GUI可视化下载面板**，全部靠代码跑；
快期软件（快期PC客户端）和TqSdk是两套东西，**快期客户端本身不能一键批量导出历史Tick**，只能用Python代码下载。

> 区分两个东西：
> - TqSdk：Python SDK，就是我们前面一直在用的，**专业版权限在这里生效，DataDownloader在这里**
> - 快期PC客户端（快期、快期专业版）：交易看盘软件，它的历史数据导出能力有限，不适合批量拉多年Tick

## 一、前置准备（4步）
1. **注册快期账号**（手机号），去官网申请【天勤专业版15天试用】，开通权限；权限绑定在你的账号上，**不是装软件**
2. 本地Python环境，安装包：
```bash
pip install tqsdk pandas python-dotenv
```
3. 登录鉴权：代码里用 `TqAuth("手机号","密码")`，**账号有专业版权限，接口就自动解锁Tick下载；免费账号跑同样代码会报错**
4. 核心参数：`dur_sec=0` = Tick快照（固定），只能下载真实合约，**不能直接下KQ.m@xxx主连**，所以要用前面给你的脚本自动查历史主力、分段下载、拼接

## 二、完整使用流程
1. 开通专业版试用/付费权限（账号层面）
2. 准备Python环境 + tqsdk
3. 运行脚本（就是上一条给你的燃油/纯碱/玉米批量主力Tick下载脚本）
   - 脚本内部调用 `DataDownloader`，向云端请求历史Tick，直接输出csv到本地
4. 下载完成 → 用【tick清洗脚本】去重、剔除脏数据
5. 清洗后 → 转vnpy格式，或者合成1min K线给CTA回测

## 三、重要限制（再强调一遍）
1. 拿到的是**快照Tick（一档买卖盘）**，**没有逐笔成交、逐笔委托**
2. 国内商品Tick起始：**2016年起**
3. 不支持主连Tick直接下载，必须自己按历史主力映射、分段下载真实合约再拼接（脚本已经帮你写好这个逻辑）
4. 下载输出只有csv，没有数据库格式；下载到本地之后，就算试用期到期，**本地文件永久保留**
5. 没有网页后台、没有客户端面板可以点选日期下载Tick，只能代码

## 五、极简最小Demo（单合约Tick下载，方便你测试权限是否生效）
```python
from datetime import datetime
from contextlib import closing
from tqsdk import TqApi, TqAuth
from tqsdk.tools import DataDownloader

api = TqApi(auth=TqAuth("你的快期手机号", "你的密码"))

# dur_sec=0 → Tick
dl = DataDownloader(
    api=api,
    symbol_list="SHFE.fu2601",
    dur_sec=0,
    start_dt=datetime(2025,1,1),
    end_dt=datetime(2025,1,5),
    csv_file_name="fu2601_tick.csv"
)

with closing(api):
    while not dl.is_finished():
        api.wait_update()
        print(f"进度：{dl.get_progress():.2%}")
print("完成")
```
> 如果这个代码报权限报错，说明账号专业版权限还没开通；如果正常跑，代表权限生效，可以跑批量主力脚本。
