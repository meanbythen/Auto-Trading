# 原创学习路线：从现金流到模型与风险

这份路线是对已经阅读并编校的笔记所作的学习组织建议，不是原书新增章节，不表示做完了原书习题。可在目录中点击各章，亦可先按下列依赖关系学习；不设置强制进度或时间承诺。

## 先建立共同语言

先掌握百分比小数换算、年分数、指数/对数、现值、条件期望、标准正态CDF和协方差矩阵。每遇公式固定写下五件事：**现金流方向、名义/乘数、发生与支付时点、测度/曲线、单位/假设**。不认识的术语可回到书尾分组笔记；查表插值只是近似，验证代码采用数值CDF。

## 一轮学习的可执行动作

1. 先不看答案，复述本章核心问题并画现金流时间线。
2. 抄写少量关键公式到自己的符号表，标出单位、正负方向及适用前提，不抄整章。
3. 用笔记自编数例手算；再运行包内复算脚本或查看复算JSON的未舍入数值，解释差异来自舍入还是口径。
4. 对每个模型至少改一次“边界”：零波动、零期限、负利率、股息、相关±边界、部分已fixing、付款错位或非交易风险。不要将未满足前提的公式硬套。
5. 再做笔记自编自测。原书推荐阅读/思考/练习目前均未读未作，若另行学习应单独记录，不能把本包自测当官方解答。

## 应反复比较的几组概念

- 合约价格F与合约价值V；到期收益与扣期权费/融资后的净利润。
- 现实概率P与定价概率Q；风险中性估值并非预测真实收益。
- 年化相对vol、绝对利率vol与累计对数标准差；1个百分点不是1基点。
- 贴现曲线、投影曲线、抵押品币种；单曲线零息比恒等式不自动适用于多曲线。
- 波动率、相关系数、有符号Brownian载荷、协方差；负载荷不是负标准差。
- 精确复制/恒等式、某模型的精确解、冻结参数近似、历史经验与当前制度。
- 某章知识已读，不等于推荐/习题、前言或全站487个阅读页面都已读。
