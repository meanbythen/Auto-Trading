# 第29.2.9节 RFR 回望利率来源复核

来源：QQ阅读《期权、期货及其他衍生产品（原书第11版）》[29.2 利率上限和下限，页403](https://book.qq.com/book-read/47684131/403)，其中“29.2.9 回望性参考利率”。公式基准见同页29.2.4的式(29-7)。本条只复核短公式，不延伸阅读范围。

## 原书的 caplet 公式与变量

对在 \(t_k\) 观察、覆盖 \([t_k,t_{k+1}]\)、在 \(t_{k+1}\) 支付的普通利率上限单元，式(29-7)为
\[
C_k=L\delta_kP(0,t_{k+1})[F_kN(d_1)-R_KN(d_2)],
\]
\[
d_1=\frac{\ln(F_k/R_K)+\tfrac12\sigma_k^2t_k}{\sigma_k\sqrt{t_k}},\qquad
 d_2=\frac{\ln(F_k/R_K)-\tfrac12\sigma_k^2t_k}{\sigma_k\sqrt{t_k}}
=d_1-\sigma_k\sqrt{t_k}.
\]
\(L\) 是名义本金；\(\delta_k=t_{k+1}-t_k\)（按合同日计数的年分数）；\(R_K\) 为cap执行利率；\(F_k\) 为时刻0对 \([t_k,t_{k+1}]\) 的远期参考利率；\(\sigma_k\) 为该远期利率的Black波动率；\(P(0,t_{k+1})\) 是支付日零息折现因子；\(N\) 为标准正态CDF。\(t_k\) 是从估值时点0到普通利率 fixing 日的期限（年）。波动率为年化Black波动，累计log标准差为 \(\sigma_k\sqrt{t_k}\)。

## 29.2.9 原文的RFR近似修改

对基于隔夜利率、在期内回望并复利的参考率，原文明确建议一种“粗略”修改：

1. \(F_k\) 取自OIS零息曲线，作为 \([t_k,t_{k+1}]\) 期间的远期利率；
2. **只在 \(d_1,d_2\) 的定义中**，把普通公式的 fixing horizon \(t_k\) 换成
\[
 t_k^{\mathrm{eff}}=\tfrac12(t_k+t_{k+1})=t_k+\tfrac12\delta_k.
\]

所以RFR近似的有效总波动为 \(\sigma_k\sqrt{t_k^{\mathrm{eff}}}\)；价格仍按式(29-7)的形式，用OIS曲线给出的 \(F_k\)、支付日OIS折现因子与修正后的 \(d_1,d_2\)。这是把期内大量隔夜 fixing 的平均观察时点近似放在计息期中点，不是重新推导日复利现金流的精确公式。普通公式原先默认参考利率在期初设定，RFR在期内逐日观察、期末回望确定，故平均 fixing 时间较晚，有效波动期限缩短。

若估值时距下一重置日已不足一个完整计息期，原文补充：已经观察到的隔夜利率应先反映到 \(F_k\)；有效时间应改为剩余尚未观察隔夜利率的平均观察时点（页403未给这一残余时段的单独闭式公式）。

## 对“期间中点”归属的核定

原书明确写的是 \(\tfrac12(t_k+t_{k+1})\)，即整段 \([t_k,t_{k+1}]\) 的**算术中点**；它不是 \(T+\delta/3\)。页403没有把 \(T+\delta/3\) 写作本书的RFR公式，也没有在29.2.9中作“线性平均”推导。若独立分析在不同权重/协方差设定下得到 \(T+\delta/3\)，那是另一项模型推导，不应说成此处原书公式。上下文也限定该中点是粗略替换到Black caplet的 \(d_1,d_2\) horizon，而非普遍适用的RFR精确方差公式。
