# 自动交易系统蓝图（对照《AI交易思想》）

当前版本 **44.9.1**（2026-11-15）。这是规划说明书，不是马上全部做完的清单。怎么做有监督的进化，操作说明在 [策略迭代进化说明.md](策略迭代进化说明.md)。

文章把东西分成三层：**EA 脚本**、**个人交易系统**、**机构量化生产体系**。你构想的「基座 + 策略当驾驶员 + 上面再叠研究/风控/进化」，和这三层是对齐的。本程序现在大致站在「个人交易系统 + 一条能跑的执行基座」，还不是机构级生产体系。

## 一、三层分别是什么（用大白话）

| 层 | 文章怎么说 | 你的构想 | 本程序现在 |
|----|------------|----------|------------|
| EA / 脚本 | 把开平仓条件写成代码，平台去下单 | 策略 yaml + 参数表指挥基座 | **已有**：多套策略引擎，完整规则写在各自配置框和 yaml |
| 个人交易系统 | 逻辑、止损、仓位、风险边界、复盘 | 基座负责入场/出场/止损/仓位；策略当驾驶员 | **大半有**：风控、复盘、账户、回测。缺：外部值班告警刚起步、GUI 成交不等于柜台成交 |
| 机构生产体系 | 数据清洗、研究环境、模型管理、组合、限额、OMS、监控报警、规律研究、自我进化 | 多策略研究部署执行风控完整生产 | **大部分没有**：一次只跑一套策略、一个合约；没有组合、没有自动换策略、没有「价格如何随因子组合变化」的统计研究层 |

文章还强调：**不要让 AI 直接写一段 EA 就当量化系统**。AI 该放在你已经定好的框架里，做挖掘、迭代、执行，并且每一步都有你定的过滤和风控牢笼。

## 二、回测能不能信（文章四条，本程序对得上吗）

| 检验 | 本程序 | 还缺什么 |
|------|--------|----------|
| 1. 没有未来函数 / 数据泄露 | 回测默认「这根收盘确认、下一根开盘成交」；未收线那根会丢掉 | 没有自动扫描「用了未来数据」的静态检查 |
| 2. 样本外，而不是同一段又训练又验收 | 策略优化有一次切断、滚动前进、多品种再验一遍 | 交叉测试本身仍是对照筛选，不是样本外；没有强制「影子盘跑够笔数才能换参数」 |
| 3. 计入交易成本 | 回测有手续费、滑点跳数；实盘滑点记在 `data/slippage_log.csv` | 账户分析页还不扣滑点手续费；GUI 假定成交滑点记 0 |
| 4. 过拟合测试 | 优化网格故意很小；前一段赚、检验段亏一半不准写入 | 没有蒙特卡洛打乱成交顺序；没有参数扰动敏感度全自动报告（滑点敏感度扫描是有的） |

任何一条没过，漂亮曲线都不能直接上实盘。这四条已经写进优化页和回测页的说明里，以后加功能不能绕开。

## 三、你构想的基座 vs 驾驶员

**基座（已经有，继续加固）**

- 执行通道：`sim` / `gui`（同花顺）/ `ctp`（华泰柜台）
- 操作：开仓、平仓、止损（策略止损 + 通用止损）、ATR/风险%仓位、日亏损熔断；人手停机用运行页「停止」+ 同花顺手平 +「手工单录入」
- 数据：新浪 / 东方财富 / 天勤 K 线；「数据管理」页还可按周期和时段读同花顺图（`@ths`）补本地库；清洗库存 `market.sqlite`，接口原样 `raw.sqlite`；点一下出各家并排质量报告
- 状态：持仓、当日盈亏、事件日志

**驾驶员（已经有，按策略各自一套规则）**

- 选引擎 + 参数表 → 基座去执行
- 主推多因子 CTA（固定权重）；另有日内实体、海龟、均线等
- 行情过滤、收盘清仓、时段，都是驾驶员告诉基座「现在能不能开」

**基座还要补的（近处）**

1. 成交质量：点击成功 ≠ 交易所成交（GUI 短板）。CTP 配好前置后走这条。
2. 告警值班：熔断、窗口丢失、柜台掉线要留下案底（**11.2.0 已做文件告警**）。下一步才是微信/邮件。
3. 连续回撤减仓、波动突然放大缩敞口：**11.6.0 已做，13.0.0 改成账户最高点回撤**。日亏熔断、回撤降仓、波动缩仓三层分开。不再按连亏笔数停手。2 手及以上可按回撤减到一半。1 手不强平。
4. 策略衰减自动停手：有复盘、衰减 Excel、四个因子滚动盈亏图（11.7.0）；还没有「连续偏离历史就禁止开新仓」的总闸。

## 四、机构层缺什么（按优先级，不要一次做完）

### 第一期（现在到下几周）：把「人能盯住的生产」补齐

- 告警落盘 + 运行台能看见（11.2.0）
- 把实盘滑点建议填回回测滑点：历史回测页按钮「用实盘滑点建议填入」，人点确认才改框，不自动改（11.4.0）
- 策略健康分数：近 20 笔账本 vs 最近一次历史回测，胜率低超过 20 个百分点或盈利因子不到一半只报警，默认不停手（11.4.0）
- 继续把 CTP 当前置配上后当主执行，GUI 降为备用（仍待华泰前置）

### 第二期：研究流水线（AI 第一层级：因子挖掘与规律发现）（11.5.0 已落地）

传统做策略是先想一个逻辑再去回测，又慢，又只能测你已经想到的东西。这一期让程序在一份**预先写清经济学逻辑**的因子清单（以及说得通的双因子组合）上扫描历史行情，自动找出人眼不容易注意到的统计规律——尤其是**价格后面怎么变**，和**因子组合**之间稳不稳、有没有非线性关系（高低组差距，不只看直线相关）。

产出是「规律说明书 + 统计证据」，**不是**「下一根该买还是该卖」。挖掘找的是市场怎么运行，不是下一笔交易机会。界面在「规律候选」页，结果在 `data/规律候选池.json`。

AI / 程序负责发现；你负责判断。跑出来的规律**不能直接拿去交易**，必须先过过滤：

- 要有说得通的经济学逻辑（它在量什么、为什么价格可能跟它有关），不是黑箱碰运气
- 必须在不同时间段里都有统计显著性，不能只是某一段暴涨或极端行情里的巧合
- 最好再跨几个品种看一眼，避免只对一个合约有效

通过的结果进入「规律候选池」。只有你勾选、并且另外写成完整开平仓规则之后，才能进策略驾驶员（例如多因子权重）。扫描层自己不下单。

不做：无约束全市场乱挖、扫到什么就当买卖点；也不做「专门去找下一次开仓时机」的机会扫描。

### 第三期：有监督的进化（AI 第二层级）

人怎么按周、按月做，见 [策略迭代进化说明.md](策略迭代进化说明.md)。要点：发现可以自动，调参可以自动，换实盘驾驶员必须人点。

- **11.12.0 曾做过多因子自适应权重对照**；**24.0.0 已从程序里删掉**。**25.0.0 又删掉多因子混合**。**26.0.0 又删掉多因子投票**。加权打分还在。
- 衰减后打开「对照正在用的参数」再优化：只出对照，默认不切实盘。还没有「连续偏离就自动弹出这一轮」的触发器
- 新参数必须样本外 + 多品种验收 + 模拟盘跑够笔数（请你自己用主推对照这一套）
- 全面优于旧策略（回撤、夏普、稳定性）才允许你点「切换」
- **默认不自动切换实盘策略**。自动切换是最后才打开的开关
- 不做：对着全样本把权重网格扫到曲线最美；每根 K 线改权重

### 第四期：组合与限额（机构骨架）— 现在不适合做

前置还不齐，硬做会变成假机构：

- 多策略、多品种并行：同花顺一次盯一个；本程序一次也只跑一套策略、一个合约
- 组合权重、总风险 3%、单品种限额：没有同时拿着的一篮子仓，限额没有对象
- 订单状态机（报出/部成/全成/撤单）：主要走 CTP，华泰前置还没配上；GUI 点击成功 ≠ 成交

等 CTP 当前置成为主通道、并且真能同时管多笔订单之后再做。不要用同花顺点击去假装组合。

### 第五期：全自动执行 + 动态风控（AI 第三层级）（11.6.0 先落地减仓）

- 单日最大亏损已有
- 连续回撤减仓、波动放大缩敞口：**已做**（配置页「动态减仓」：账户最高点回撤 + 波动；可关）
- 滑点、成交质量、信号偏移回流到第一、二期（还没做完：滑点建议已有，成交质量仍受 GUI 限制）
- 人的角色：定边界、看逻辑、关总闸。AI 不改风控牢笼

## 五、明确不做或很晚才做

- 用 ChatGPT 现写一段 EA 当实盘策略
- 震荡行情专用策略（高抛低吸、碰轨反转、均值回归）。震荡日的正确动作是少开或停手，不再加一套反向引擎
- 无约束全市场乱挖，把统计规律直接当成买卖点下单
- 参数优化越狠越好（网格必须小）
- 多账户并行挂机（短期；18.1.0 起可在实盘账/模拟账之间切换，仍一次只跑一本）
- 把 GUI 点击伪装成柜台成交确认

## 六、怎么验收每一期

做完只能多「看得见的安全」，不能偷偷改变哪根 K 线会开仓。改变开仓规则必须升「大更新」。第一期告警、第二期规律扫描都不改变下单。第五期动态减仓只改手数和「还开不开」，信号仍由原来的策略给出；关掉开关即回到原来的手数。

## 七、对照 `docs/量化交易系统.png`（机构量化交易系统）

图中间写的是：**承托多策略从研究到实盘**，要求稳定、可控、可追踪。图底下还写：**它不是某一段策略代码**。本程序已经有策略和一条能下单的基座，缺的是图上那些「生产车间」。

不要等图上每一格都绿了再优化。有的格子（组合、OMS、多策略并行）要等 CTP 当前置成主通道之后才有对象；现在硬补会做成假机构。下面「现在可优化」的，随时可以逐项做。

| 图上的块 | 它在干什么 | 本程序 | 缺什么 |
|----------|------------|--------|--------|
| **市场数据接入** | 行情、成交、基本面 | 有分钟/小时/日线（新浪/东财/天勤，一次一家）；天勤周线用日线合成；没有逐笔成交、没有基本面 | 逐笔/盘口、基本面；实盘扫描仍只问一家 |
| **清洗与质量检查** | 缺失、重复、异常值 | 有：对齐时间戳、丢掉脏小数、跨休市假影线、过期 K 线不开仓；原样/清洗分库；点「检查行情质量」三家并排比开高低收、跳数、对交易影响 | 没有自动把缺口标进研究表；扫描路径上仍不做完整质检；不自动换源 |
| **研究环境** | 数据、代码、实验记录 | 有规律候选页、因子清单、候选池 JSON | 没有笔记本式实验台；实验记录还散在回测 JSON / Excel |
| **回测与样本外验证** | 成本、滑点、流动性 | 有历史回测、优化检验段、交叉测试、滑点扫描、实盘滑点建议 | 交叉测试不是样本外；没有强制影子盘跑够笔数；没有流动性冲击模型 |
| **版本与参数** | 变更可记录、可比较 | 有配置存档、优化参数版本、Excel 导入导出 | 没有「这一笔单用的是哪一版参数」的逐笔标签 |
| **部署与回滚** | 异常时恢复旧版本 | 配置存档可一键应用（常驻时不能切） | 没有异常自动回滚；没有影子盘通过才允许切 |
| **策略组合** | 趋势、套利、多空一起跑 | **没有**。一次一套策略、一个合约 | 同花顺一次盯一个；现在不适合做 |
| **资金分配** | 相关性、敞口、权重 | **没有**。仓位只按单笔风险%和仓位上限% | 要等真能同时持有一篮子仓 |
| **敞口与杠杆** | 品种、方向、杠杆 | 有单品种保证金、仓位上限%、日亏损 | 没有组合总敞口、方向净敞口、品种限额 |
| **回撤与停机线** | 触发后降仓或暂停 | 有日亏熔断、动态减仓、健康只报警；人手停机用停止+同花顺手平 | 没有独立「紧急清仓」按钮；没有「连续偏离历史就禁止开新仓」的总闸；没有组合回撤停机 |
| **OMS / EMS** | 订单状态与路由 | CTP 有报单/等待/超时撤；GUI 只有点击 | GUI 点击≠成交；没有统一订单状态机、没有智能路由 |
| **券商 / 交易所接口** | 连通真实成交 | CTP 代码已通，待华泰前置；现用同花顺点击 | 正式盘应切 CTP；GUI 只能当备用 |
| **运行日志** | 事件、订单、错误 | 有 loguru、运行台、bot_state、账本、滑点 CSV、告警 jsonl | 没有按「订单生命周期」一条线把信号→发单→成交串起来给人点开看 |
| **报警与故障恢复** | 告警、降级、重启 | 有文件告警、运行台三行、窗口丢失跳过扫描 | 没有微信/邮件值班；没有自动降级通道（CTP 挂了改 GUI）；没有进程守护自动拉起 |
| **实时监控**（图下方） | 持仓、资金、策略状态 | 有状态卡、账户分析、健康/动态减仓行 | 没有组合级仪表；没有收益回撤实时曲线挂在运行台 |

**已经够用、以后是优化不是从零做：** 策略引擎、单合约扫描、回测/优化/复盘、日亏与动态减仓、告警落盘、规律候选（不下单）。

**现在就能逐项优化（不改开平仓规则）：**

1. 运行日志做成「这一笔从信号到成交」一条时间线（可追踪）
2. ~~数据质量：扫描缺口、过期、异常值，写成给人看的一页~~（11.8.0 单源；11.9.0 三家并排；**11.11.0 加上同花顺图**）
3. 参数版本打到每一笔成交上，回滚仍要人点确认
4. 健康偏差连续若干天后，只加「建议停手」开关（默认仍不停）
5. CTP 当前置就绪后：成交回报进账本，GUI 降为备用

**必须等 CTP、不要现在做：** 多策略组合、资金分配、OMS 路由、总敞口限额。
