# CTP 上线四步

手工点单和策略自动下单走**同一套柜台接口**（`CtpTrader`）。四步只换两件事：人点还是程序点，仿真账还是真实账。

**交易台只给人调试。** 买开、卖开、买平、卖平、平仓、反手、撤单都在这里点，用来确认柜台回报。  
**挂机下单请用运行页「启动常驻」。** 选好③或④之后，策略自动出信号，再调用和交易台相同的报单。程序不会在交易台里自己扫 K 线、自己点按钮。运行页「暂停报单」只停开新仓，止损和清仓仍发；「停止常驻」才结束扫描。

策略会发的动作，交易台都能先点一遍：

| 策略会做的 | 交易台怎么测 |
|---|---|
| 买开 / 卖开 | 「买开」「卖开」 |
| 止损平仓、收盘清仓 | 「买平」「卖平」或「平仓」（锁仓会平两边；沥青/玉米自动拆平今平昨） |
| 反手（先平再反向开） | 「反手」 |
| 撤未成交、超时不要的单 | 「撤选中委托」「全撤未成交」。交易台挂单不自动撤，方便华泰手撤；常驻仍超时撤 |
| 暂停开新仓 | 「暂停报单」 |

常驻已经用 CTP 连上时，不要再在交易台点「连接登录」，同一账号会被踢下线。要对照持仓，先点运行页「停止」。

截图要求见华泰指引：带时间戳，或电脑全屏（能看到右下角时间）。正式报告模板在 `docs/测试报告/华泰期货程序化外接测试指引及测试报告.docx`。逐步填写说明见 `docs/测试报告/华泰程序化外接测试操作说明.md`。

## ① 手工仿真（华泰程序化外接测试）

1. 运行页上线阶段选「① 手工仿真」。
2. 点「打开交易台」，操作账是仿真账号，点「连接登录」。
3. 按华泰必测做完：连通、开平撤、断线重连、报撤单笔数、阈值提醒、错误合约/价位/手数拦截、柜台退回错误、暂停报单、日志、连续运行 10 分钟、看穿式 IP/MAC。
4. 在交易台「华泰必测」页勾上必测项，回到运行页点「本阶段完成」。

这一步策略**不会**自动向柜台发单。

## ② 手工真实账户

1. 配置页「资金账号」填华泰真实资金（同花顺登录那一号）。再填实盘交易前置、实盘行情前置。密码默认就是上面的交易密码；若柜台密码不同，再在本地密钥文件写 `ctp_live_password`。
2. 上线阶段选「② 手工真实账户」，打开同一套交易台，连真实账号，手工开平撤一笔确认回报正常。
3. 点「本阶段完成」。

## ③ 策略自动仿真

1. 上线阶段选「③ 策略自动仿真」。执行通道会改成 CTP，操作账是仿真。
2. 关掉模拟模式，点「启动常驻」。策略用和交易台相同的报单、撤单、持仓、成交回报。
3. 确认策略开平仓与柜台一致后，点「本阶段完成」。

## ④ 策略自动真实账户

必须先完成 ①②③。再选「④ 策略自动真实账户」并启动常驻。策略对真实资金账户下单，接口与前面三步相同。

未完成前一步时，程序会拦住，不会直接把策略接到真实资金。
