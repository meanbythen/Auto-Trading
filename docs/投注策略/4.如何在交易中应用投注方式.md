# 核心总纲
投注方式**不是一个公式算完手数就完事**，它是一套贯穿【信号触发前→开仓瞬间→持仓加仓→亏损回撤阶段→新高之后】的动态规则，和你的入场、止损、加仓、减仓、暂停交易绑定在一起。
> 记住顺序：先定**风险预算** → 再算**可下手数** → 校验**全局风险上限** → 开仓；中途加仓/减仓也要走同一套投注规则；回撤超标自动降投注额度；创新高再上调额度。

下面用可落地流程，分【前置配置、单笔开仓流程、加仓投注、回撤时投注收缩、新高后投注恢复、凯利动态投注实操、程序化落地校验清单、常见踩坑】，适配你国内商品日内、vnpy、3w本金。

> 先统一术语：
> R = 单笔预设最大亏损（止损对应的风险）；
> 投注比例 = 单笔R / 当前有效权益；
> 有效权益：绝大多数专业做法 = **账户历史新高净值（高水位线 High Water Mark，HWM）**，不是实时权益。
> ✅ 用HWM：锁定利润，盈利膨胀时仓位放大、亏了之后仓位自动收缩，是CTA标准做法。
> ❌ 用实时权益：回撤时仓位被动变小，但连续盈利后风险会快速堆高，很多散户的坑。

# 一、第一步：前置配置（在出信号之前就写死，盘中不许改）
先选定你的投注模型（二选一，新手优先固定风险），并且写死全部硬约束，这是“应用投注规则”的前提，**不能盘中临时改参数**。
## 方案1：固定风险投注（推荐起步）
预设参数（示例，适配3w日内）
1. 基准投注比例：`risk_pct = 0.005`（0.5% HWM风险/笔）
2. 单品种同时在途最大笔数：1（日内突破一般不叠同品种多笔）
3. 全账户总在途风险上限：`total_risk_limit = 0.015`（所有持仓R加起来不超过HWM的1.5%）
4. 回撤档位熔断规则（投注收缩规则，重中之重）
    - 从HWM回撤≥5%：risk_pct → 0.0025（减半投注）
    - 从HWM回撤≥10%：**禁止新开仓，只持有、按原止损出场，不加仓**
    - 从HWM回撤≥15%：全部清仓、当日停止一切交易
5. 品种硬上限：高相关性品种（燃油/沥青）同时持仓时，风险权重合并计算，不重复累加

## 方案2：分数凯利投注（策略统计稳定后再启用）
前置参数多一层统计层：
1. 滚动统计窗口：最近N笔（推荐60~80笔，只统计**已经了结的单子**，持仓不算），输出滚动胜率P、盈亏比R
2. 原始凯利：$f^* = \frac{P(R+1)-1}{R}$
3. 凯利系数（分数）：`kelly_coeff = 0.3`（3成凯利，禁止>0.5）
4. 凯利盖帽硬限制：**单笔风险永远不超过1% HWM**（防止行情参数漂移算出超大仓位）
5. 回撤熔断和上面完全一样

> ⚠️ 凯利不是“有信号就算一次凯利”：**必须用滚动实盘成交样本，不能拿回测的P、R永久固定**；当样本不足60笔，强制降级为固定风险模式。

# 二、单笔信号触发时：标准投注计算流程（最常用环节）
**每一次入场信号，强制按这个5步走，这就是投注方式的实际应用**
> 输入：当前HWM、品种、入场价、止损价、合约乘数
1. 计算单笔止损空间（价格风险）
$$stop\_range = abs(entry\_price - stop\_price)$$
2. 计算【本信号允许的最大风险金额】
$$risk\_allow = HWM \times \(risk\_allow = HWM \times 单笔投注比例\)$$
3. 理论手数
$$theory\_volume = risk\_allow \div (stop\_range \times contract\_multiplier)$$
4. 取整：期货只能整数手，向下取整；如果theory_volume < 1手 → **放弃这笔信号，不交易**
> 举例：HWM=30000，0.5%风险=150元；纯碱乘数20；止损10点
> theory_volume = 150 / (10*20) = 0.75手 → 不足1手，直接放弃，哪怕信号再漂亮
> 👉 投注规则在这里自动帮你过滤掉“止损太宽、风险超标”的机会，这是投注体系非常重要的功能

5. 全局风险校验（很多人漏掉）
    把这笔新增R，加到当前所有持仓的已占用风险总和；
    如果 `当前总风险 + 这笔R > 总风险上限` → 拒绝开仓。

✅ 输出：最终下单手数，交给下单模块；止损不变，**止损是定义R，投注是分配资本到这个R上**

> 误区纠正：
> 不是“先随便下1手，再看亏多少”；而是**先预算我愿意亏多少钱，反推我能下几手**。顺序反了，等于没有投注管理。

# 三、加仓的投注应用：加仓属于投注，不是新入场信号
加仓是追加投注，必须纳入总风险预算，不能随性加仓。
两种主流加仓投注范式：
### 1. 金字塔加仓（推荐）
规则示例：
- 加仓触发：行情朝有利方向移动，形成新的结构信号
- 每一笔加仓，**单独设置新的止损，单独计算这笔加仓的R**
- 后续每一笔加仓的允许R，小于前一笔（投注额度递减）
- 硬性：加仓后，整单组合的**总R依然不能突破单笔+全局风险上限**
> 例：第一笔R=0.5%HWM；加仓一笔最多R=0.25%HWM；合计这一组头寸总R≤0.75%，不能无限堆

### 2. 禁止的做法
倒金字塔加仓（越赚加越大）：会让一个小幅回调直接吃掉全部利润，投注风险快速失控。

> 重点：加仓不能把止损直接平移很远去“腾空间加仓”，平移止损等于偷偷放大R、篡改投注预算。

# 四、持仓过程：盈亏浮动的时候，投注规则管什么？
持仓浮盈/浮亏，**不修改当前这笔单子的投注、不修改手数**。
- 浮盈：只是账面利润，这笔交易的原始R不变；
- 浮亏：只要没打到止损，投注预算不变；
只有两种情况会改变投注体系：
1. 单子平仓了结，释放占用的风险额度，总风险额度回收，可以留给下一笔信号；
2. 账户净值创出新高 → 更新HWM，重新上调基准投注额度。

# 五、回撤阶段：投注收缩（投注体系的保命功能）
投注不是一成不变的固定比例，**亏损周期里，投注要主动降低**，这是区分普通仓位管理和专业投注体系的关键点。
举一套可直接写进代码的联动逻辑：
- 账户从HWM回撤 0~5%：正常投注比例
- 回撤 5%~10%：投注比例减半（同样的信号，能下的手数直接变少）
- 回撤10%~15%：暂停新开仓，只处理老单子止损出场
- 回撤≥15%：清仓，当日停止所有投注，不再接收任何信号

> 底层逻辑：连续亏损的时候，系统短期优势可能消失，投注降档=减少弹药供给，防止连续亏损把账户打穿。
> 很多固定风险玩家的巨大漏洞：回撤20%了，还在用原来的比例下注。

# 六、净值创新高：投注额度上调
只有**收盘后（或者单子全部了结后）**更新HWM，盘中浮盈新高不更新。
示例：
HWM原来30000，收盘后权益31200，新高；
新HWM=31200，下一笔0.5%风险从150元变成156元，同等止损条件下，可以下更多手。
✅ 效果：利润滚动复利，赚的时候可以慢慢放大规模；亏的时候自动收缩，利润被高水位线锁住。

> 重要约束：HWM只涨不跌，一旦确定新高，后续回撤不会把HWM降回去。

# 七、凯利投注实操的特殊应用要点（如果你后续切换）
凯利和固定风险的差异，在于【\(risk\_allow = HWM \times 单笔投注比例\)不是固定值，由滚动P、R动态算出】，其他流程（手数计算、全局上限、回撤熔断、HWM）完全一致：
1. 每平仓一笔，就把这笔的盈亏样本扔进滚动队列；队列满了剔除最老一笔；
2. 每次信号来，实时计算f*，乘以分数系数；
3. 强制盖帽：算出的比例超过1% → 强行压到1%；
4. 样本不足60笔：强制切换为固定风险，避免小样本统计失真；
5. 当滚动凯利f*算出来≤0：**直接放弃开仓**，代表当前统计上没有优势，不投注。

> 凯利的“应用”精髓：优势大就多投、优势消失就少投甚至不投，而不是一直固定下注。

# 八、程序化（vnpy）落地：模块拆分，避免逻辑耦合
不要把投注逻辑写在策略on_tick里面，单独写一个RiskManager（投注管理器），对外只暴露一个接口：
`get_allow_volume(signal, entry, stop, symbol)`
管理器内部维护状态：
- self.hwm：高水位线
- self.total_used_risk：当前已经占用的总风险
- self.risk_pct：当前生效的\(risk\_allow = HWM \times 单笔投注比例\)（随回撤档位动态变化）
- self.limit：全局风险上限
- 滚动统计队列（凯利模式才用）

返回结果：允许手数 / 0（禁止开仓）
策略只管：输出信号、入场价、止损价；**无权决定下单手数**，手数由投注管理器分配。
这就是机构标准的解耦应用方式，信号和资金投注完全隔离。

# 十、最容易出现的错误应用方式
1. 用固定手数，美其名曰仓位管理：本金缩水后，实际风险占比被动飙升；
2. 止损定了之后，感觉仓位太小，主动放大止损来多下单；
3. 凯利公式只拿历史回测P/R算一次，永久不变；
4. 加仓不统计总风险，越加越重；
5. 浮盈的时候立刻提高HWM放大投注（盘中动态HWM，极其危险）；
6. 熔断规则只写在纸上，亏上头直接无视。
