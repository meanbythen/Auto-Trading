# 一、vnpy RiskManager 伪代码：固定风险 + 分数凯利二合一风控管理器
> 说明：适配 vnpy 2.x/3.x，独立于策略（Strategy），策略发开仓请求前先调用这个风控管理器，返回允许手数；内置：权益新高跟踪、回撤熔断、单笔风险硬盖帽、固定风险/分数凯利切换开关
> 前置依赖：需要你在回测/实盘里持续滚动统计最近N笔交易的胜率、盈亏比；实盘注意：凯利参数窗口不能太短，日内建议窗口 60~100 笔
> 变量约定：
> - equity：当前账户权益
> - peak_equity：历史最高权益（高点跟踪基数，只创新高才更新，利润锁定）
> - drawdown_pct：当前回撤 = (peak_equity - equity) / peak_equity
> - p_win：滚动胜率
> - rr：滚动盈亏比（平均盈利 / 平均亏损）
> - stop_loss_value：这笔单子计划单笔亏损（止损价差 * 乘数），即1R对应的亏损金额
> - max_single_risk_cap：凯利模式单笔风险硬上限（防止凯利算出来爆炸，例如1%）

```python
"""
vnpy 独立风控管理器 RiskManager
功能：二合一 固定风险 / 分数凯利，权益高点跟踪 + 多级回撤熔断
使用方式：策略内部不计算仓位，开仓前调用 risk_manager.calc_volume(...)
"""
from dataclasses import dataclass


@dataclass
class RiskConfig:
    # 模式选择: "fixed_risk" / "fractional_kelly"
    mode: str = "fixed_risk"

    # ========== 固定风险参数 ==========
    fixed_risk_pct: float = 0.005  # 默认0.5%单笔风险

    # ========== 分数凯利参数 ==========
    kelly_fraction: float = 0.3    # 分数凯利系数 0.3 ~ 0.5
    kelly_single_cap: float = 0.01 # 凯利模式单笔风险硬封顶 1%

    # ========== 全局熔断规则（基于高点权益的回撤） ==========
    drawdown_level1: float = 0.08   # 回撤8%：风险减半
    drawdown_level2: float = 0.12   # 回撤12%：禁止新开仓
    drawdown_level3: float = 0.18   # 备用强停，可不用

    # ========== 全局总暴露上限 ==========
    total_risk_limit: float = 0.015 # 全账户同时在途风险总和上限 1.5%


class RiskManager:
    def __init__(self, cfg: RiskConfig):
        self.cfg = cfg
        self.peak_equity = 0.0
        self.current_equity = 0.0
        self.total_outstanding_risk = 0.0  # 当前所有持仓合计风险

    def update_equity(self, equity: float):
        """更新权益 + 更新历史高点peak，高点只上不下"""
        self.current_equity = equity
        if equity > self.peak_equity:
            self.peak_equity = equity

    def get_current_dd(self) -> float:
        if self.peak_equity <= 0:
            return 0.0
        return (self.peak_equity - self.current_equity) / self.peak_equity

    def kelly_formula(self, p_win: float, rr: float) -> float:
        """原始凯利 f* = (p*(rr+1)-1)/rr"""
        if rr <= 0:
            return 0.0
        f_star = (p_win * (rr + 1) - 1) / rr
        return max(f_star, 0.0)  # 负凯利直接返回0，不参与

    def calc_volume(
            self,
            stop_loss_price: float,
            entry_price: float,
            contract_multiplier: int,
            p_win: float = 0.4,
            rr: float = 2.0
    ) -> int:
        """
        核心函数：计算允许下单手数
        :param stop_loss_price: 止损价
        :param entry_price: 入场价
        :param contract_multiplier: 合约乘数（纯碱20，燃油10等）
        :param p_win: 滚动胜率
        :param rr: 滚动盈亏比
        :return: 允许手数，0=禁止开仓
        """
        dd = self.get_current_dd()

        # 熔断判断1：回撤超过level2，直接禁止新开仓
        if dd >= self.cfg.drawdown_level2:
            return 0

        # 计算单笔1R亏损金额（每一手亏多少）
        risk_per_lot = abs(entry_price - stop_loss_price) * contract_multiplier
        if risk_per_lot <= 0:
            return 0

        # 基础风险比例
        if self.cfg.mode == "fixed_risk":
            base_risk_pct = self.cfg.fixed_risk_pct
        else:
            f_star = self.kelly_formula(p_win, rr)
            f_frac = f_star * self.cfg.kelly_fraction
            base_risk_pct = min(f_frac, self.cfg.kelly_single_cap)

        # 回撤降级：达到level1，风险比例减半
        if dd >= self.cfg.drawdown_level1:
            base_risk_pct *= 0.5

        # 本次允许最大风险金额（基于高点权益！不是当前权益，锁定利润）
        allow_risk_amount = self.peak_equity * base_risk_pct

        # 校验全局总风险上限
        remain_risk = self.peak_equity * self.cfg.total_risk_limit - self.total_outstanding_risk
        allow_risk_amount = min(allow_risk_amount, remain_risk)

        # 计算理论手数，向下取整到整数手
        theory_lots = allow_risk_amount / risk_per_lot
        lots = int(theory_lots)

        return max(lots, 0)

    def add_outstanding_risk(self, risk_amt: float):
        """开仓成功后，登记这笔风险，用于全局总风险控制"""
        self.total_outstanding_risk += risk_amt

    def remove_outstanding_risk(self, risk_amt: float):
        """平仓后释放风险额度"""
        self.total_outstanding_risk = max(self.total_outstanding_risk - risk_amt, 0.0)
```

## 使用要点（vnpy内集成）
1. 在 `engine` / 策略模板里全局实例化一个 RiskManager，不要每个策略单独实例；
2. 每一笔成交回报，调用 `risk_manager.update_equity(equity)`；
3. 策略 `on_signal` 产生开仓信号时，先调用 `calc_volume`；返回0直接跳过下单；
4. 成交回调里 add/remove 风险，实现全局总风险管控；
5. 凯利模式：`p_win, rr` 需要你自己维护滚动窗口统计（可以单独写一个TradeRecorder统计最近N笔盈亏）；
6. ⚠️ 回测和实盘差异：回测没有跳空滑点带来的超损，实盘一定要再降低一档风险比例。

# 二、回测评估对比表模板（同信号，对比不同投注方案）
> 用途：同一套DualThrust/R-Breaker信号，只换RiskManager模式，批量跑出来填这个表，对比固定风险0.5% / 固定风险1% / 0.3凯利 / 0.5凯利，挑选卡尔玛最优的投注参数
> 指标说明：
> - CAGR：年化净值增长率
> - MaxDD：最大回撤（基于高点权益）
> - Calmar比率 = CAGR / MaxDD（核心，越高越好，优先选>1.5）
> - Expectancy：每1R期望收益
> - Profit Factor：盈利总和 / 亏损总和
> - Win Count / Lose Count：盈利、亏损笔数
> - Avg R / Avg Loss R：平均盈利R、平均亏损R

| 投注方案名称 | 单笔风险规则 | 总风险上限 | CAGR | MaxDD | Calmar比率 | 每R期望E | 盈亏因子PF | 总交易笔数 | 胜率 | 盈亏比 | 最终净值 | 备注 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 固定风险0.5% | 固定0.5%，回撤8%减半 | 1.5% |  |  |  |  |  |  |  |  |  | 保守基准 |
| 固定风险1.0% | 固定1.0%，回撤8%减半 | 1.5% |  |  |  |  |  |  |  |  |  | 中性 |
| 0.3分数凯利（盖帽1%） | 0.3*f*，上限1%，回撤8%减半 | 1.5% |  |  |  |  |  |  |  |  |  | 凯利轻量 |
| 0.5分数凯利（盖帽1%） | 0.5*f*，上限1%，回撤8%减半 | 1.5% |  |  |  |  |  |  |  |  |  | 凯利激进 |
| 固定手数（对照组） | 固定N手，无权益跟踪 | 无 |  |  |  |  |  |  |  |  |  | 反面对照，一般很差 |

## 评估筛选标准（你3w日内账户适用）
1. 优先卡尔玛比率最高；
2. MaxDD尽量控制在12%以内；
3. 同卡尔玛下，选交易曲线更平滑、连续亏损段更短的；
4. 凯利方案如果卡尔玛不如简单固定风险，直接放弃凯利，不要迷信。

## 配套回测注意事项
- 所有方案**使用完全一样的入场、止损、出场信号**，唯一变量：投注规则；
- 回测必须统一加上手续费+滑点（国内商品日内：纯碱、燃油建议每手固定滑点假设）；
- 样本周期尽量跨2个以上行情环境：震荡 + 趋势，避免单一行情过拟合；
- 凯利的滚动窗口参数本身也是超参数，也要做网格搜索，不要直接拍脑袋60笔。

# 三、补充 TradeRecorder 简易统计器（配套凯利，给你直接接上面RiskManager）
```python
class TradeRecorder:
    def __init__(self, window=80):
        self.window = window
        self.trade_r_list = []  # 保存每一笔交易的R收益，盈利为正，亏损为负

    def record_trade(self, r: float):
        self.trade_r_list.append(r)
        if len(self.trade_r_list) > self.window:
            self.trade_r_list.pop(0)

    def get_stats(self):
        if len(self.trade_r_list) < 20:
            return 0.4, 2.0  # 样本不足返回默认值
        win_r = [x for x in self.trade_r_list if x>0]
        lose_r = [abs(x) for x in self.trade_r_list if x<0]
        p_win = len(win_r) / len(self.trade_r_list)
        if not lose_r:
            rr = 99
        else:
            avg_win = sum(win_r)/len(win_r) if win_r else 0
            avg_lose = sum(lose_r)/len(lose_r)
            rr = avg_win / avg_lose
        return p_win, rr
```
策略每平仓一笔，调用 `recorder.record_trade(trade_r)`，开仓时拿 `p_win, rr = recorder.get_stats()` 传给风控。
