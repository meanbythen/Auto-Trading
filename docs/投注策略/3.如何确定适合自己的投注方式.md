# 核心总纲
**不存在“最好”的投注方式，只存在和这4件事匹配的投注方式：你的策略统计特性、资金属性、心理承受阈值、交易约束（你是3w、国内期货日内、程序化）。**
顺序不能乱：先收集客观数据，再测边界，最后实盘小仓校准，而不是上来直接选凯利或者固定风险。
整个流程是：**摸底 → 初选模型 → 回测压力测试 → 模拟盘验证心理 → 实盘梯度上线 + 动态复查**

> 一个很常见误区：看到凯利复利高就想用，但凯利要求你能扛住25%、35%回撤；如果你晚上睡不着、盘中容易改规则，凯利对你就是错的。投注方式第一约束是【你能不能严格执行它】，其次才是收益效率。

下面按步骤拆解，每一步都有可落地的判断标准，最后给你一个自检清单。

## 第一步：先把三个客观基础数据拿到手（选投注模型的前提）
投注模型的输入，全部来自你的策略，脱离策略参数谈投注都是空谈。
针对你CTA突破类（DualThrust/R-Breaker）日内策略，你需要统计**不含未来函数、扣除手续费滑点**的样本：
> 样本要求：至少80~150笔独立交易（同一策略，不同品种分开统计，化工和农产品不要混在一起算P、R）
1. 胜率 Pwin
2. 平均盈亏比 R（总盈利总和 / 总亏损总和，不要用单笔平均）
3. 最大连续亏损次数 MaxDDseq（非常关键！比最大回撤还容易被忽略，决定你投注上限）

举例子：
- 你的策略：P=0.42，R=2.1，历史最大连亏7笔
- 如果你单笔风险2%：连亏7笔，权益理论亏损：$1-(0.98)^7≈13.1\%$
- 如果你单笔风险3%：连亏7笔，$1-(0.97)^7≈19.2\%$

👉 这里就直接筛掉激进方案：如果你主观接受的账户回撤上限是12%，那单笔2%就是红线，不能更高。

额外两个必须统计的特征：
- 盈亏分布：盈利是均匀分布，还是少数大盈利+大量小亏（趋势突破策略大多是后者，凯利会天然倾向放大仓位）；
- 参数漂移度：换一段行情（震荡市、波动放大、低波动），P、R会不会大幅下滑？漂移大 → 不适合凯利；漂移稳定 → 才适合分数凯利。

简单判断：
✅ 震荡+趋势来回切换、日内短突破、参数容易变 → 优先【固定风险】
✅ 策略逻辑很硬、样本稳定、跨行情下P/R波动很小 → 可以尝试【分数凯利+盖帽上限】

## 第二步：定义你的两条硬红线（资金与心理，属于你的个人参数，无法回测替代）
两条线，先写下来，不能模糊：
### 红线A：账户可接受的【硬最大回撤】
是**你绝对不允许突破的回撤**，到线直接降仓/停开新仓，不是“感觉难受的回撤”。
给散户参考区间（你3w本金日内）：
- 保守型：最大可接受回撤 8%
- 中性：12%
- 激进、可以长期扛回撤、程序化全自动不手动干预：15%
> 不建议个人散户把红线放到20%以上：回撤20%之后，需要赚25%才能回本；回撤30%要赚43%，心理极容易崩盘，开始乱改投注规则、扛单、马丁加仓。

> 公式联动：用【历史最大连亏次数 × 单笔风险】去预估极限回撤，这个预估值必须 ≤ 你的硬回撤红线。
> 例：最大连亏6笔，可接受回撤12% → 单笔风险上限≈2%。

### 红线B：执行韧性阈值（心理层面，很多人直接跳过，最后翻车）
问自己3个问题，诚实回答：
1. 当连续亏4~6笔，净值稳步往下走的时候，你会不会：手动缩小仓位、提前止损、放弃信号、逆势加仓？
    - 会：你不适合凯利。凯利在连续亏损期仓位会持续缩小，但中间回撤曲线波动大，很容易打破心态；固定风险回撤曲线更平滑，更适合你。
    - 不会，策略全自动，你只看收盘报表，盘中不看盈亏：凯利才具备落地条件。
2. 能不能接受：同样的信号，这次仓位大、下次仓位小（凯利的动态仓位特性）？
    固定风险：每一笔风险额度一致，每一次的“代价”一样，对心态更友好。
3. 你的交易是手动还是纯程序化？
    - 手动日内：强烈优先固定风险。动态凯利的仓位计算、随权益变动，手动很容易算错、变形。
    - vnpy全自动：凯利才有稳定执行的基础。

还有一个资金属性：这笔3w是不是生活备用金？
- 是生活费/短期要用的钱：选更低风险、固定0.3~0.5%单笔风险，回撤红线压到5%以内；
- 纯闲置、3年内不会取出的风险资金：可以放宽到中性档位。

## 第三步：候选模型初筛（对照上面数据，直接排除不匹配的）
### 候选1：固定风险模型（1R模型）
适合人群（满足任意多条）
1. 策略P、R漂移明显，震荡趋势切换时性能起伏大（绝大多数日内突破策略）
2. 手动交易，或者不想系统太复杂
3. 历史连亏序列长、你对回撤敏感
4. 同时跑多个低相关性品种，希望风险简单可控

优点：预期回撤稳定、规则简单、复盘容易找问题；缺点：长期复利增速上限低于凯利。

### 候选2：分数凯利 + 单笔盖帽 + 全局回撤熔断
适合人群（必须全部满足，缺一不可）
1. 策略样本充足，跨行情下胜率盈亏比相对稳定
2. 全自动程序化，盘中绝不干预仓位
3. 你设定的最大回撤红线≥10%，能接受阶段性较大回撤
4. 你会滚动更新P/R，并且给凯利设置**单笔风险硬上限盖帽**（比如无论凯利算出来多大，单笔风险永远不超过1%）

⚠️ 只要有一条不满足，凯利对你就是错配。

### 直接排除的投注方式（散户绝大多数情况）
马丁、倍投、固定手数、倒金字塔无上限加仓。
固定手数只适合策略测试阶段，不能做实盘投注方案。

## 第四步：压力回测，检验匹配度（最重要的筛选环节）
不要只用正常回测净值曲线，你要做**压力情景测试**，同一个信号，套不同投注规则跑3组对比：
> 三组：0.5%固定风险 / 1%固定风险 / 0.3凯利+1%盖帽
对比指标不是只看年化收益，优先顺序：
1. 最大回撤（是否突破你的红线）
2. 最长回撤持续时间（从高点再创新高要多少根K线/多少交易日）
3. 卡尔玛比率（年化收益/最大回撤，越高越好，代表收益性价比）
4. 连亏阶段的权益下滑曲线（是平滑缓跌，还是陡峭跳水）
5. 极端情景：叠加滑点放大2倍、手续费提高，看看会不会直接崩盘

举个典型对比结果：
- 凯利组：年化高20%，但最大回撤14%，回撤周期长；
- 0.5%固定风险：年化低一点，回撤7%，曲线平稳，卡尔玛更高。
如果你红线是8%，那凯利直接淘汰，不要被更高年化诱惑。

> 重点：回测里的回撤是【理论数学回撤】，实盘会因为跳空、滑点、流动性，回撤比回测更大，必须预留20%~30%冗余。
> 比如回测算出来极限回撤10%，你实盘红线就要设成7~8%。

## 第五步：模拟盘试运行，检验【执行一致性】
回测是纸上的，模拟盘用来测“你能不能从头到尾按规则执行”，周期至少2~4周，不是两三天。
重点观察两件事：
1. 当策略进入回撤期，你会不会主观修改投注参数（比如本来0.5%风险，亏几笔改成0.2%，赚几笔又放大到1.5%）——一旦频繁改参数，说明这个投注模型和你的心理不匹配，降一档，换成更保守的。
2. 动态仓位（凯利）会不会给你的系统带来额外麻烦：比如权益盘中浮动，仓位频繁变化、手数碎片化、合约最小手数限制导致风险失真（纯碱、燃油都有最小1手限制，小本金很容易遇到）。
> 你的3w本金是一个强约束：很多时候凯利算出来的风险额度，买不到1手，策略直接无法开仓；固定风险更容易控制这个边界。

## 第六步：实盘梯度上线 + 定期复核机制（投注方式不是一选定终身）
投注方案不是永久绑定，是定期复核迭代的：
1. 上线第一阶段：用你初选方案的 **50%档位** 先跑1~2个月。
比如你目标定单笔0.8%固定风险，先按0.4%跑，验证实盘P/R和回测是否一致；
2. 复核周期：每新增30~50笔交易，重新统计胜率、盈亏比、连亏记录；
3. 触发调整信号（满足任意一条，就要修改投注方案，而不是硬扛）：
    - 实盘P/R显著差于历史回测，策略优势衰减；
    - 连续两次触及你的回撤红线；
    - 品种流动性变差、跳空风险上升；
    - 你的资金状态变了（需要取钱，或者追加本金）。

## 补充一个很多人踩的误区
不要用“收益高低”选投注方式。投注方式的核心功能是**把策略的数学期望安全兑现**，而不是凭空创造收益。
一个高收益投注方案，如果它的回撤是你根本扛不住的，对你来说就是最差的方案；一个增速慢一点、但你可以稳定执行、永远不爆仓的投注规则，才是适合你的。
