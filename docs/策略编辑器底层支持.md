常见正期望收益策略

## 1. vnpy/vnpy_ctastrategy（首选，国内CTA标杆）
🔗 [https://github.com/vnpy/vnpy_ctastrategy](https://github.com/vnpy/vnpy_ctastrategy)
- 内置成熟策略：**海龟唐奇安通道、DualThrust日内突破、布林突破、Keltner通道（ATR通道）、Aberration**，全部原生支持vnpy CTP实盘、自带ATR动态仓位模块（《海龟交易法则》原版仓位公式：1ATR波动单位）
- 特点：社区最成熟、回测引擎和实盘引擎一致；就是你之前研究的vnpy原生策略库，支持多品种组合、多周期过滤；很多国内私募起步就是这套
- 适合：日线/短周期趋势、日内突破（DualThrust非常适合商品日内）
- 缺陷：是**模板**，默认参数不能直接上，必须做品种筛选、滑点手续费校准、参数鲁棒性检验

## 2. je-suis-tm/quant-trading（经典策略合集，包含R-Breaker、伦敦突破）
🔗 [https://github.com/je-suis-tm/quant-trading](https://github.com/je-suis-tm/quant-trading)
- 包含：**R-Breaker（趋势+反转双模式，生命周期极长的日内经典）、DualThrust、配对套利、海龟、布林**，附带完整回测+图表、详细原理文档
- 特点：Python原生、不绑定特定框架，可以迁移到vnpy、tqsdk、backtrader；R-Breaker是国内期货日内圈非常主流的基准策略
- 适合：学习逻辑、迁移到你自己的日内CTA系统

## 3. ringoshinnytech/tqsdk-strategies（天勤TqSdk，国内商品期货友好）
🔗 [https://github.com/ringoshinnytech/tqsdk-strategies](https://github.com/ringoshinnytech/tqsdk-strategies)
- 内置：ADX+ATR波动率突破、多因子截面动量、唐奇安、双均线、跨期套利；tick级回测，支持国内全品种主力合约自动换月移仓
- 特点：天勤自带免费历史K线/tick，回测门槛低；代码干净，方便提取ATR过滤、波动率过滤器模块，移植进你的vnpy策略
- 适合：快速验证燃油、纯碱、玉米这类中小品种

## 4. mementum/backtrader + backtradercn CTP示例（可自定义CIS/简化Casper风格）
🔗 [https://github.com/mementum/backtrader](https://github.com/mementum/backtrader)
🔗 国内CTP示例：[https://github.com/backtradercn/backtrader_cn_api_example](https://github.com/backtradercn/backtrader_cn_api_example)
- backtrader是事件驱动回测标杆；社区大量移植：唐奇安、多周期CTA、ATR跟踪止盈、ADX趋势过滤；你想要的**CIS、Casper简化版**没有官方开源，但很多人基于backtrader复现，这个仓库是最好的基底
- 适合：你自己组装多因子CTA、自定义VA成交量分布、多周期过滤组合策略

## 5. songshuquant/ssquant（轻量CTP框架+成套策略包）
🔗 [https://github.com/songshuquant/ssquant](https://github.com/songshuquant/ssquant)
- 打包：海龟、双均线、Aberration布林、日内突破、强弱截面轮动、跨期/跨品种套利，自带自动移仓、事前风控、多品种并行引擎

# 策略优先级（按你的需求：国内商品、日内、vnpy、3w本金）
1. DualThrust（vnpy_ctastrategy）：国内商品日内基准，最容易做出稳定盈亏比，适合燃油、纯碱这类波动品种
2. R-Breaker（je-suis-tm）：日内趋势+反转，行情震荡时比纯突破策略回撤更小
3. 海龟唐奇安+ATR仓位（vnpy_ctastrategy）：波段趋势，适合玉米这类低波动品种，**一定要加ADX过滤剔除震荡期**
4. ADX+ATR波动率突破（tqsdk-strategies）：你之前想要的ADX+ATR过滤器原生实现

# 避坑清单（非常关键）
1. 凡是标题写“稳定盈利、年化XX%、无回撤”的开源期货策略，**一律是过拟合**
2. 开源代码普遍回测时**不充分估算滑点、手续费、涨跌停无法成交、夜盘跳空**；商品期货日内滑点对期望杀伤力极大
3. 正期望本质来源：**趋势溢价、波动率溢价**，不是指标本身；震荡市所有突破策略都会持续亏钱
4. 3w本金小资金优先：**单品种低仓位、多品种分散、限制同时开仓数量，ATR动态仓位，禁止固定手数马丁**
