### 4.3 建议的优化顺序

#### P0：重建同口径基准

先固定当前参数，在统一数据区间重新运行日内实体回测，并保存新版评估结果。基准必须包含：

- 明确策略、品种、周期和起止时间；
- ADX 入场快照及趋势/震荡分组；
- 额外 1 跳滑点压力；
- 数值参数 ±10% 扰动；
- 训练段、检验段和滚动前进结果；
- 多品种验收明细。

只有建立该基准，后续每次改参数才能判断是改善还是过拟合。

#### P1：只针对过滤条件做受控对照

建议按以下顺序单独实验，每轮只改变一个条件：

1. **ADX 上限对照：** 当前 `filter_adx_upper=30.0`，与相邻候选值比较，观察被拦截信号在样本外的净盈亏、PF、最大回撤和趋势/震荡分组，而不只观察交易次数是否增加。
2. **ATR 极端波动过滤对照：** 当前 `filter_atr_high_pct=0.8`，比较不同阈值下新增交易的 MAE/MFE、亏损集中度和回撤变化。
3. **过滤开关对照：** 仅作为风险归因实验保留 `filter_enabled=false` 组，用于计算过滤模块到底避免了多少亏损、错过了多少利润；若样本外回撤或滑点后 PF 恶化，不进入候选配置。

**不建议现在直接放宽过滤。** 放宽的验收重点不是“信号更多”，而是新增信号在样本外和加压后仍有正期望，并且不使回撤、连续亏损或震荡组表现越线。

#### P1：复核旧最优参数与当前配置差异

旧优化最优参数包含 `generic_stop.kind=prior_extreme`，当前配置却为 `off`。其他主要参数虽然相近，但止损结构不同，不能把旧训练/检验成绩直接套到当前配置上。

建议分别回测以下两组，不混用结果：

- A 组：当前配置，通用止损 `off`；
- B 组：旧优化结构，`prior_extreme`，其余条件与旧结果一致。

比较止损触发频率、平均亏损、盈亏比、最大回撤和检验段 PF。若 B 组只在训练段改善、样本外无改善，则不替换当前配置。

#### P2：扩大样本并验证跨品种稳定性

至少覆盖趋势、震荡、高波动和低波动阶段。多品种验收应重点查看 `CF2701` 等旧结果中的弱品种，而不是只汇报汇总盈利。若某个品种持续大亏，应判断是个体流动性/合约规格问题，还是参数依赖特定行情；不要通过删除弱品种来美化结论。

## 五、凯利突破最近回测的独立诊断

### 5.1 当前结果对照

回测区间：2026-01-30 21:15 至 2026-11-13 23:00；周期 5 分钟；起始权益口径 27,868.48。

| 指标 | 当前结果 | 当前门槛/参考 | 判断 |
|---|---:|---:|---|
| 成交笔数 | 110 | 100 笔观察、150 笔交付 | 仅达到观察样本量 |
| 胜率 | 35.45% | 结合盈亏比判断 | 低胜率本身不是否决项 |
| 净盈亏 | +5,926.28 | >0 | 有账面盈利，但不足以单独通过 |
| 盈利因子 PF | 1.1282 | ≥1.30 | 未达标 |
| 盈亏比 | 2.054 | 结合 PF 和期望判断 | 符合“赚大亏小”的方向 |
| 每笔 R 期望 | 0.0828 | ≥0.12 | 盈利缓冲偏薄 |
| 最大回撤 | 12,977.15 | 结合权益和利润判断 | 回撤绝对额超过净利润 |
| 最大回撤比例 | 29.08% | ≤15% | 明显越线 |
| 盈利覆盖 | -7,050.87 | ≥0 | 净利润不能覆盖最大回撤 |
| 综合得分 | 0.2412 | 仅作辅助 | 不支持交付 |

**核心判断：** 盈亏比 2.054 表明策略已有“盈利单大于亏损单”的结构，但 35.45% 的胜率尚不足以形成足够利润缓冲。当前主要矛盾是回撤过大、期望偏薄，而不是单纯胜率低。

按当前门槛对照，PF、回撤比例和盈利覆盖已经足以阻止交付；样本量和期望也尚不充分。即使净盈亏为正，也不能据此进入放大仓位阶段。

### 5.2 优先排查收盘强平

110 笔成交中，“收盘清仓时间到，凯利突破强制平仓”出现 27 次，约占 24.5%。这类交易占比较高，应首先判断收盘规则是否截断了本可继续发展的趋势利润，或是否在弱势持仓上提供了必要的风险控制。

建议将成交拆成两组：

- 收盘强平组；
- 非收盘强平组。

分别统计笔数、净盈亏、PF、平均盈利/亏损、持仓时长、MAE/MFE 和后续行情。随后做受控对照：

- 基准组：保留当前收盘强平；
- 实验组：仅在规则允许的持仓上调整退出方式，保持入场、止损和仓位规则不变。

若取消或放宽强平只增加浮盈回吐、隔夜风险或最大回撤，应保留强平；若样本外显示利润捕获率持续改善且压力测试仍通过，才可把退出调整列为候选。

### 5.3 优化方向应围绕“利润捕获”而非加仓摊薄

当前 PF 和期望偏薄，直接提高凯利仓位只会同步放大权益波动，不能修复策略边际。优化顺序建议为：

1. 先识别利润来自哪些行情和退出类型；
2. 再检查止损是否过宽、过窄或集中在噪声区；
3. 再评估退出规则对平均盈利和回撤的影响；
4. 最后才讨论仓位参数。

在 PF、滑点后 PF、回撤和扰动测试通过前，不建议提高风险预算或用加仓改善账面收益。

### 5.4 必须补齐的可信度测试

- **滑点：** 当前为 0 跳，应增加 1 跳并检查 PF 是否仍达到 1.20，同时观察净盈亏和期望是否由正转负。
- **参数扰动：** 对数值参数做 ±10% 扰动；若相邻参数出现净亏损、PF 低于门槛或相对基准明显断崖，应放弃尖峰最优值，选择平台区参数。
- **ADX 分组：** 重新回测以记录入场 ADX，重点检查震荡组交易占比和 PF。若震荡组大量交易且 PF 异常偏高，需要排查数据、分组或回测逻辑，而不是直接视为优势。
- **样本外：** 保留最近区间作为不参与调参的检验段，并执行滚动前进，避免反复在同一区间优化。

## 六、统一验收标准

任何日内实体或凯利突破候选参数，建议按以下顺序验收；前一层未通过时，不用后一层的高分抵消红线。

| 层级 | 必查内容 | 通过原则 |
|---|---|---|
| 基础有效性 | PF、R 期望、净盈亏、盈亏比 | PF≥1.30，R 期望≥0.12，净盈亏为正 |
| 风险 | 最大回撤、盈利覆盖、连续亏损 | 回撤≤15%，盈利覆盖≥0，连续亏损不超过 8 笔 |
| 样本 | 总成交笔数、行情阶段覆盖 | 100 笔仅观察，150 笔以上才进入交付评估 |
| 滑点压力 | 额外 1 跳后的 PF、期望和回撤 | 滑点后 PF≥1.20，且不能依赖零滑点才盈利 |
| 参数鲁棒性 | ±10% 数值参数扰动 | 不出现净亏损或 PF 断崖，优先选择稳定平台区 |
| 样本外 | 保留检验段、滚动前进 | 检验段同样满足核心红线，滚动效率不低于现有 0.30 门槛 |
| 多品种 | 逐品种结果及弱品种归因 | 不由少数品种掩盖大亏，迁移表现有合理一致性 |
| 行情分组 | ADX 趋势/震荡组 | 利润来源可解释，震荡组无异常交易集中或失真 |

补充原则：

- 单日复盘用于发现行为问题，不用于直接判定参数通过。
- 训练段高分不能抵消检验段红线。
- 综合得分不能抵消 PF、回撤、盈利覆盖、滑点或扰动红线。
- 优化结果未通过时应保持不写入；普通回测和交叉测试可以保留结果用于研究，但必须明确标红。

## 七、执行优先级清单

### P0：先完成，期间不建议据此放大实盘

1. 分别用 44.4.0 重跑 `daily_body/fu2701` 当前配置和 `kelly_break/sh主力连续` 基准。
2. 保存 ADX、权益时间轴、滑点和参数扰动结果。
3. 将旧 `accepted=true` 仅保留为历史记录，不作为当前参数通过证明。
4. 核对回测页实际策略与品种，避免后续报告再次混用不同实验对象。

### P1：完成基准后进行

1. 日内实体：依次测试 ADX 上限、ATR 极端波动阈值和过滤开关，每次只改一个条件。
2. 日内实体：对照 `generic_stop.kind=off` 与 `prior_extreme`，重点看样本外而不是训练段。
3. 凯利突破：拆解 27 笔收盘强平成交，评估利润捕获和回撤贡献。
4. 对所有候选参数执行相同的保留段、滚动前进和多品种验证。

### P2：有稳定候选后再进行

1. 扩展到不同市场阶段和更多有效样本，达到至少 150 笔交付观察基础。
2. 连续积累多日复盘，比较重放信号、事件日志和实际成交的一致性。
3. 仅在完整评估通过后讨论仿真到实盘的推进；仓位调整独立评估，不替代策略有效性验证。

## 八、最终建议

当前最合理的动作是**保留两套策略作为研究候选，暂不根据旧结果直接改写或放大实盘参数**。

- 日内实体需要证明：过滤条件不是只在某一段行情有效，旧最优参数不是小样本和样本内高分造成的假象。
- 凯利突破需要证明：在计入滑点、控制回撤并处理收盘强平影响后，仍能保留足够的 R 期望和利润覆盖。
- 后续每次优化都应回答三个问题：**样本外是否仍赚钱、压力后是否仍赚钱、相邻参数是否也赚钱。** 只有三者同时成立，才把结果从“观察”推进到“可交付”。
