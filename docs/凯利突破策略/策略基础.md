# 一、策略核心思路（无复杂指标、纯凯利+赚大亏小）
先对齐你的目标：**不靠复杂指标、不预判行情方向，只靠固定盈亏比+历史胜率，用凯利公式动态控仓；开平仓规则极简，硬性保证：盈利单平均收益 > 亏损单平均亏损，长期期望为正**
> 本质：正期望是前提，凯利只是资金分配工具；凯利不能把负期望策略做成盈利，这点是第一底线。

## 1）先定义凯利公式（简化版，适合日内/趋势CTA，国内期货可用）
经典凯利：
$$f^* = \frac{bp - q}{b}$$
- $f^*$：单次投入资金占总资金最优比例
- $b$：盈亏比（平均盈利 / 平均亏损，不含手续费滑点）
- $p$：开仓后盈利的概率
- $q=1-p$：亏损概率

⚠️ 期货是杠杆交易，这里有大坑：
公式里的 $f^*$ 是**风险资金比例**，不是直接保证金比例！
> 举例：你一笔最多愿意亏总资金的2%，这个2%才是凯利里的“下注单位”；不是直接拿总资金×f*去开仓。

行业通用改良：**半凯利 / 1/3凯利**
原始凯利波动极大，连续回撤非常猛，散户（3w本金）几乎扛不住，\(f_{实}=0.188/3≈0.0627\)操一律用：
$$f_{\(f_{\(f_{实}=0.188/3≈0.0627\)盘}=f^* \times 0.3 \sim 0.5\)}=f^* \times 0.3 \sim 0.5$$
推荐：**1/3凯利**，兼顾增长和回撤控制。

## 2）极简开平仓规则（满足你：不依赖特定指标）
方案：**突破固定ATR止损的价格区间（纯价格行为，不看MACD、RSI、均线共振）**
> 判定标准只有两条，没有复杂过滤：
1. 开仓
   - 做多：价格向上突破最近N根K线的最高价
   - 做空：价格向下突破最近N根K线的最低价
   > N建议固定：20或者40，不要动态调；你可以选20，最简单。
2. 止损（硬性，决定单笔最大亏损）
   进场后，止损放在进场价 ± ATR×K
   - ATR用20周期ATR，只用来算止损距离，**不做开仓信号**
   - K固定取1.0 ~ 1.5，一旦触发止损，无条件离场
3. 止盈（固定盈亏比，强制赚大亏小）
   设定目标盈亏比，比如固定 2:1 / 2.5:1 / 3:1
   > 例：止损空间是10个点，止盈就设20/25/30个点；到价就平仓，不拿浮动利润飘单。
✅ 这套规则，信号只来自：K线高低点 + ATR（仅用来算止损距离，不是预测指标），符合你“不依赖复杂指标”的要求。

> 备选极简版本（连ATR都不用，极致简单）：
固定点数止损止盈，比如纯碱：止损10点，止盈25点，盈亏比2.5:1；突破高低点开仓。缺点：波动率大的时候容易被扫，适合波动率稳定品种（玉米）。

## 3）完整单笔仓位计算流程（重点，可直接写进vnpy代码）
参数示例（你可以回测后替换）：
假设回测得到：胜率p=0.42，盈亏比b=2.5
1. 计算原始凯利：
$f^* = (2.5 \times 0.42 - 0.58) / 2.5 = (1.05 - 0.58)/2.5 = 0.188$
2. 取1/3凯利：$f_{\(f_{实}=0.188/3≈0.0627\)}=0.188/3≈0.0627$
含义：**这笔交易最多允许亏损总资金的6.27%**
3. 计算止损点数：$stop\_tick$
4. 每手单点亏损金额：$tick\_value$（合约乘数×最小变动价位）
5. 可开手数：
$$lots = \frac{总资金 \times f_{\(f_{实}=0.188/3≈0.0627\)}}{stop\_tick \times tick\_value}$$
> 向下取整，不能小数手；同时加硬上限：单笔最大亏损不超过总资金8%，防止凯利在参数漂移时仓位爆炸。

> 重要：**胜率p、盈亏比b不能拍脑袋写**，必须用历史回测统计；每过一段时间滚动更新（滚动窗口，比如最近200笔成交），不要固定不变。

## 4）风控附加规则（凯利的配套安全阀，散户必加）
凯利本身只解决“期望为正下最优增长”，不防连续黑天鹅：
1. 最大总回撤：账户权益回撤20%，停止开新仓，只平仓，等回撤修复到10%以内再恢复；
2. 同时持仓上限：最多同时2个品种，避免多品种相关性叠加；
3. 单日最大亏损：单日亏损达到总资金5%，当日停止交易；
4. 参数边界保护：当凯利算出f*≤0 → 期望为负，**禁止开仓**，这是自动过滤坏参数的关键；
5. 手续费+滑点：回测和\(f_{\(f_{实}=0.188/3≈0.0627\)盘}=f^* \times 0.3 \sim 0.5\)统计盈亏比、胜率时，每一笔都扣手续费+预估滑点，否则回测期望虚高。

# 凯利参数
win_rate = 盈利笔数 / 总笔数

avg_loss = abs(亏损单平均亏损)
b = avg_win / avg_loss

f_kelly = (b * win_rate - q) / b
f_used = f_kelly * (1/3)  # 1/3凯利

if f_kelly <= 0:
    return 0  # 期望为负，不开仓

stop_distance = atr_value * 1.2

# 每手风险金额
risk_per_lot = stop_distance * contract_multiplier

lots = max(1, lots)
# 硬上限

    lots = int(max_risk_limit / risk_per_lot)

# 二、回测重点（这个策略成败就在这里）
回测只看3个指标：
1. 数学期望 $E = p\times b - (1-p)$，E必须>0，否则凯利没用；
2. 最大回撤；
3. 夏普比率。

测试品种建议：玉米、燃油、纯碱这类流动性好的国内期货；不要去冷门远月合约。
> 你要做的是：固定开平仓规则，在历史数据上跑，统计p、b，再喂给凯利；而不是调指标去美化曲线。

# 三、常见坑（很多人凯利策略翻车的地方）
1. 把凯利当成“预测行情工具”：凯利只是资金分配，不提高胜率；
2. 直接用原始凯利：高波动期货连续亏损时仓位急剧放大，快速爆仓；
3. 用固定不变的p、b：市场结构变了，原来的正期望消失，凯利还在加仓；
4. 混淆保证金比例和风险比例：凯利算的是风险，不是保证金；
5. 止盈用移动止盈、不固定盈亏比：盈亏比不再稳定，凯利公式的前提被破坏。
