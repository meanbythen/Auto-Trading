# 为什么一定要有两个周期
日线图告诉你是大涨，赶紧进。四小时图却说现在是震荡，再打开十五分钟图，好家伙，又是一段下跌趋势。一个盘面三种声音，多也不是，空也不是，到底该怎么办？
如果你不懂时间周期，想要看懂行情的真相，就只能一次又一次错过大行情。接下来我用两个步骤，彻底帮你捋顺周期概念。

第一步，给周期问题做减法：**只看两个周期**
大周期 = 趋势周期，用来定方向；
小周期 = 交易周期，用来找入场点。

首先讲怎么确定【交易周期】：
交易周期，就是你设置止损、入场、出场、管理订单的周期。一定要结合自己的持仓心态、现实条件量力而行。
举例子：
- 心态很好、本金是闲钱、持仓过夜睡得着，交易周期可以选4小时、日线；
- 接受不了持仓过夜，就选5分钟、15分钟；
- 白天要上班，没法盯盘，硬做5分钟周期，就是自我折磨。5分钟信号转瞬即逝，离开一会儿行情就走完、止损直接被打掉，不是系统不行，是你没有条件执行。
- 全职交易、时间充足，却硬做日线，每天只等一根K线收盘，闲置的时间会催生焦虑，忍不住乱干预，本来计划拿半个月的单子，两小时就提前平掉。

交易周期不是越大越稳、越小越刺激，它必须匹配你的心态、本金性质、资金体量、生活节奏。
一句话标准：**能睡得着觉的周期，才是适合你的周期；可以稳定执行的周期，才是你的周期。**

再讲【趋势周期】：
遵循**四倍原则**：趋势周期 = 你的交易周期 × 4
- 交易周期5分钟 → 趋势周期20分钟
- 交易周期15分钟 → 趋势周期1小时

只保留两个周期，是清除市场噪音的第一步。

第二步，双周期的用法：顺大逆小
拿【1小时（趋势周期）+15分钟（交易周期）】举例：
1小时图只做一件事：判断趋势方向，确定当前是上涨还是下跌；
确定大趋势向上之后，只逢低做多；价格回调，只要没有跌破关键防守位，多头逻辑不变。这就是**顺大**。
然后切换到15分钟小周期，找这一段回调什么时候结束，也就是**逆小**（在大趋势里抓反向回调的终结点进场），这就是职业交易者稳定盈利的核心思路。

判断回调下跌终结，有两套模型（基于密集成交区）：
模型1：
1. 标记这段回调的密集成交区（蓝框A）
2. 对比进入密集区之前的下跌段a，和离开密集区之后的下跌段b
3. 如果 a ＞ b，下跌动能衰竭，可以判定这段回调终结。

模型2（一段回调里面嵌套多层密集成交区时用）：
1. 先标记整个回调最大的密集成交区A
2. 如果离开段b＞进入段a，就继续在b里面，找b内部最大的密集区（b中a）
3. 对比b中a 和 b中b；如果 b中a ＞ b中b，下跌动能衰竭，判定回调终结，等待转折K线进场。

案例：1小时定多头方向，15分钟识别回调终结进场，这笔单子盈亏比接近1:4。

最后总结：
很多人周期混乱，根源就是没有给周期分工。
分工清晰之后逻辑就简单了：**大周期只负责给方向，小周期只负责给入场信号。**

---
### 结合你做长线CTA的补充对照（适配你的策略）
这套“四倍原则、顺大逆小”，放到你之前的长线体系里就是：
- 趋势周期：周线（定大方向）
- 交易周期：日线（执行突破、开仓止损），刚好符合4倍关系，和视频逻辑完全对齐。
- 而纯单日线唐奇安，就是放弃了这套“顺大逆小”的择时，牺牲一部分入场精度，换取逻辑更简单、信号更少、更容易回测。
