# 《我的交易系统，价格行为＋缠论》文字整理（熊猫教练说技术）
这套系统依然是**双周期框架：趋势周期（大周期）+交易周期（小周期）**，价格行为用来识别结构、支撑阻力、动能；缠论用来定义中枢、背驰、买卖点，二者结合。
> 日内推荐搭配：**30分钟（趋势周期） + 5分钟（交易周期）**

核心：两个周期，每一个周期都要回答一模一样的7个问题。
这7个问题：
1. 大趋势的起点在哪里
2. 大趋势方向
3. 大趋势所处阶段
4. 大趋势动能
5. 大趋势级别
6. 大趋势防守位
7. 是否出现次级别的小趋势

## 一、趋势周期（大周期，用来定方向）
趋势周期的任务：找到你要跟随的“大势”，判断这个趋势是否健康、有没有走完，我们只顺着这个大趋势去做回调行情。
打开大周期图，先回答上面7个问题：
- 趋势起点：理清这一段行情启动的位置；
- 方向：明确上涨/下跌；
- 阶段：是趋势初期、中继，还是末期；
- 动能：趋势力度是增强还是衰竭；
- 级别：这是多大级别的走势；
- 防守位：这个趋势被破坏的关键位置；
- 次级小趋势：有没有出现反向回调段（也就是我们要等的机会）。

> 所有趋势的标准结构：主趋势推进 → 走出反向回调段（次级别走势），我们的机会就出现在回调段里面。

## 二、交易周期（小周期，用来找精准入场，缠论+价格行为结合）
大周期确定是上涨趋势、正在走回调之后，切换到小周期，用缠论拆解这段回调：
1. 回调在小周期上，是一段反向下跌走势；
2. 观察这段下跌走势，有没有出现**背驰（缠论动力学）**；
3. 背驰之后，等待一买、二买、类二买；
4. 最后用**强底分型（价格行为+缠论分型）**确认承接，才进场。

### 分型规则（这套系统里的核心入场信号）
缠论里不看K线阴阳、影线，只看价格区间和位置：
- 底分型：三根K线，中间一根高低点都是三根里面最低；**强底分型：第三根K线向上突破第一根K线高点**，才是合格入场信号；
- 顶分型：三根K线，中间一根高低点都是三根里面最高；**强顶分型：第三根K线跌破第一根K线低点**，作为离场信号。

## 三、完整闭环流程（做多举例）
1. 趋势周期（30min）：上涨趋势，走出回调，回调没有跌破大周期防守位；
2. 交易周期（5min）：这段回调是下跌走势，出现下跌背驰；
3. 小周期出现一买，之后走出二买/类二买；
4. 出现强底分型 → 进场；
5. 止盈减仓规则：
    - 交易周期（小周期）出现顶背驰 → 减仓；
    - 趋势周期（大周期）出现顶背驰 → 全部清仓离场。

做空逻辑反过来：大周期下跌，小周期反弹+顶背驰，强顶分型进场；小周期底背驰减仓，大周期底背驰清仓。

## 四、价格行为在这套系统里的作用
缠论负责：**走势递归、中枢、背驰、买卖点定位**；
价格行为负责：**关键支撑阻力、K线承接、强弱分型、动能判断**，过滤掉缠论里结构好看但是没有承接的假信号。

## 五、补充要点
1. 四倍原则依然适用：趋势周期≈交易周期 ×4；
2. 这套是顺势回调系统，不是抄底摸顶；不做逆大周期的信号；
3. 防守位是生命线：一旦大周期防守位被突破，直接放弃原有趋势思路；
4. 适配：短线合约、黄金、外汇，平移到国内期货也可以用（比如日线+15min）。

## 和上一条视频（双周期）的区别
上一条视频：双周期 + 密集成交区动能衰竭（纯价格行为）；
这一条：**双周期 + 缠论（中枢/背驰/分型）+价格行为**，用缠论的走势结构替代密集成交区做动能判断。

---
### 适配你长线CTA的对照
如果你想把这套逻辑用到白糖、尿素这类长线品种：
- 趋势周期：周线
- 交易周期：日线
- 周线定上涨趋势，日线回调段找背驰、二买、强底分型做多；
- 周线定下跌趋势，日线反弹段找顶背驰、强顶分型做空。
