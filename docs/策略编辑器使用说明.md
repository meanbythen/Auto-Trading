# 策略编辑器使用说明：从零新建一套策略

策略编辑器让你**不写 Python**，只用一份 YAML 文件描述「指标 + 条件」，就能在程序里新增一套可回测、可实盘的策略。本文按「打开界面 → 新建 → 写规则 → 校验保存 → 使用」的顺序，从零讲一遍。

---

## 1. 它能做什么、不能做什么

**支持**

- 开仓条件（做多 / 做空，可分别写，也可以只写一边）
- 离场条件（持仓时按条件平仓）
- 全局过滤（比如 ADX 太低就不开仓）
- 高周期过滤（`filters_htf`，用「止损周期」的 K 线确认大方向）
- 止损：ATR 倍数、百分比、摆动点（前 N 根高低点），或不止损
- 移动止损 `trail`、保本止损 `breakeven`、限持仓根数 `max_hold_bars`
- 38 种常用指标 + 算术表达式（含滚动统计），能复刻 DualThrust、R-Breaker、海龟、Keltner 这类带公式的策略

**暂不支持**（写了会直接报错，不会静默忽略）

- 加减仓、反手、分批止盈
- 订单流 / 盘口类信号（程序没有逐笔和 Level-2 数据）
- 截面动量、跨期套利（需要同时处理多合约的横截面数据）
- 自定义手数（`sizing` 只能写 `inherit`，手数沿用配置页的「每笔风险%」等仓位设置）

**防未来函数**：条件只按**已收盘**的 K 线判断；成交价由回测/实盘引擎决定（回测按下一根开盘），规则本身不参与定价。

---

## 2. 打开编辑器

1. 打开程序，点顶部 **策略编辑器** 页签（在「配置」右边）。
2. 左侧「规则文件」列出 `config/rules/` 下所有 YAML，分「程序内置」和「我的规则」两组，点一下就载入到中间编辑框。

> 编辑器是独立页签，不依赖当前选的是哪套策略；配置页的「自定义规则（DSL）」面板只剩一句摘要和「打开策略编辑器 →」按钮。

### 界面说明

| 控件 | 作用 |
| --- | --- |
| 左侧 **规则文件** 列表 | 列出 `config/rules/` 下所有 YAML。带 `[内置]` 的是程序自带模板，不能删改；当前编辑的那条会高亮 |
| **文件名** 输入框 | 保存/重命名时用的文件名。只允许小写字母、数字、下划线、短横线，且以字母或数字开头（如 `my_rule_1`） |
| **新建规则** | 清空文件名，编辑框填入一份最小可用模板（不写盘，放弃也不会留垃圾文件） |
| **保存** | 先编译校验，通过才写盘并注册成 `rule_dsl:<文件名>`；**不会自动切换当前运行策略** |
| **仅校验** | 只编译、不写盘，用来确认语法对不对 |
| **重命名** | 把当前加载的用户规则改成「文件名」框里的新名字（内置规则拒绝） |
| **删除** | 删除当前加载的用户规则（内置规则拒绝），并从策略下拉里移除 |
| 标题行 | 显示当前文件名、是否 `[内置]`；有未保存修改时末尾带 `*` |
| 状态行 | 显示校验结果、保存/删除是否成功、报错原因 |
| 编辑框 | YAML 正文，支持 `Ctrl+C / Ctrl+V`，`Ctrl+S` 直接保存；等宽字体、不自动换行 |
| 右侧 **▸ 指标库与计算公式** | 可视化配置区：选指标类型、填参数，实时显示代入参数后的计算公式和 YAML 片段，点「插入到 indicators」直接写进编辑框 |

## 3. 从零新建：六步

### 第 1 步：打开编辑器
点顶部 **策略编辑器** 页签。左侧点一条模板（如 `turtle_adx`）可以先看看写法，不点也行。

### 第 2 步：点「新建规则」
编辑框会填进一份最小模板：

```yaml
# 新建规则：改完点「保存」，程序会把它注册成一个策略。
schema: 1
name: "我的规则"

indicators:
  ma20: { kind: ema, period: 20 }

entry:
  long: { gt: { left: close, right: ma20 } }
  short: { lt: { left: close, right: ma20 } }

stop: { kind: percent, pct: 2 }

sizing:
  mode: inherit
```

### 第 3 步：起名字、填文件名
- `name:` 是给人看的策略名，会显示在策略下拉里（「自定义：我的规则」）。
- 「文件名」框填 `my_rule_1` —— 决定 `config/rules/my_rule_1.yaml` 和引擎代号 `rule_dsl:my_rule_1`。
- 文件名不能和已有文件重名：保存时会提示换名，「重命名」也要求新名字未被占用。

### 第 4 步：写规则
- 在 `indicators:` 下定义指标，自己起名（不能和 `open/high/low/close/volume` 重名）。
- 在 `entry:` / `exit:` 下用指标名和行情字段拼条件。
- 不想手写指标行？在右侧 **指标库与计算公式** 面板按第 5 节用鼠标点出来，自动写进编辑框。

### 第 5 步：点「保存」（想先验语法就点「仅校验」）
- **校验通过**：状态行显示「已保存：my_rule_1.yaml（我的规则）」。文件写盘并注册进策略下拉。
- **保存不会切换当前运行策略**：要让新策略跑起来，去「配置」页的策略引擎下拉里选「自定义：我的规则」。
- **校验失败**：状态行显示具体字段和原因，**不会写盘**，原文件一个字节都不动。按提示改完再保存。
- 「仅校验」只编译不写盘，适合边改边确认语法。

### 第 6 步：开始用
- 直接运行：到 **配置** 页把策略引擎切换成新策略，再点保存配置。
- 历史回测：到 **历史回测** 页，策略下拉同样能选到「自定义：我的规则」。
- 编辑器内回测：在 **策略编辑器** 点「回测当前规则」，直接跑当前编辑的规则。
  品种、周期、日期、行情来源、滑点和开仓限制都沿用 **历史回测** 页的设置，
  报告显示在编辑框下方，并照旧写入 `data/backtest_last.json`。规则有未保存修改时会先提示保存。
- 策略优化 / 交叉测试：同样在下拉里选。

## 4. YAML 结构详解

一份规则文件由下面这些顶层键组成，**不认识的键会直接报错**，避免拼错后静默失效。

| 顶层键 | 必填 | 说明 |
| --- | --- | --- |
| `schema` | 否 | 目前只支持 `1`，不写默认 1 |
| `name` | 否 | 策略显示名，不写就用文件名 |
| `note` | 否 | 备注，纯注释用，不参与运行 |
| `builtin` | 否 | `true` 表示程序自带，界面禁止删改。**自己的规则不要写** |
| `timeframe` | 否 | 固定周期（如 `"60"`、`"D"`）；不写跟随 `config.yaml` 的 `strategy.timeframe` |
| `indicators` | 否 | 指标定义，可省略；只靠行情字段和 `break_high` / `time` 也能写规则 |
| `filters` | 否 | 全局过滤，可写成列表或单个条件；不成立则这一根多空都不开 |
| `filters_htf` | 否 | 高周期过滤，写法同 `filters`，但用引擎传入的「止损周期」K 线计算；K 线不够时不开仓 |
| `entry` | **是** | 开仓条件，只能写 `long` / `short`，至少写一组 |
| `exit` | 否 | 离场条件，同样只写 `long` / `short`；不写就只靠止损 |
| `stop` | **是** | 初始止损方式，见下 |
| `trail` | 否 | 移动止损，算法同 `stop`（不能写 `none`），只朝有利方向收紧 |
| `breakeven` | 否 | 保本：`{ atr: 1.0, atr_ref: atr14 }`，浮盈达 N 倍 ATR 后把止损抬到开仓价 |
| `max_hold_bars` | 否 | 最长持仓根数（1~5000），到点按规则离场 |
| `sizing` | 否 | 只能写 `mode: inherit` |

### 4.1 indicators：指标定义

```yaml
indicators:
  ma20: { kind: ema, period: 20 }
  hh20: { kind: highest, period: 20 }
  atr14: { kind: atr, period: 14 }
```

| kind | 参数 | 说明 |
| --- | --- | --- |
| `ema` | `period`(20)、`source`(close) | 指数均线，α = 2/(period+1)；`source` 可换 `open/high/low/volume` |
| `sma` | `period`(20)、`source`(close) | 简单均线，同样支持 `source` |
| `stddev` | `period`(20)、`source`(close) | 滚动标准差 |
| `atr` | `period`(14) | 平均真实波幅，可被 `stop.kind: atr` 引用 |
| `atr_pct` | `period`(14) | ATR ÷ 收盘 × 100，跨品种比较波动用 |
| `adx` | `period`(14) | 趋势强度，常用于过滤 |
| `plus_di` / `minus_di` | `period`(14) | 正向 / 负向动向指标，配 ADX 判方向 |
| `highest` | `period`、`field`(high) | 窗口最高，`field` 可换 `open/close/low` |
| `lowest` | `period`、`field`(low) | 窗口最低 |
| `donchian_mid` | `period`(20) | 唐奇安通道中轨 =（N 根最高 + N 根最低）÷ 2 |
| `rsi` | `period`(14) | 相对强弱，0~100 |
| `macd_hist` / `macd_dif` / `macd_dea` | `fast`(12) / `slow`(26) / `signal`(9) | MACD 柱（DIF−DEA）、快线 DIF、慢线 DEA，`fast` 必须小于 `slow` |
| `boll_upper` / `boll_lower` / `boll_mid` | `period`(20) / `std`(2.0) | 布林上轨 / 下轨 / 中轨 |
| `boll_width` | `period`(20) / `std`(2.0) | 带宽百分比 =（上轨−下轨）÷ 中轨 × 100，判收口/开口 |
| `keltner_upper` / `keltner_lower` | `period`(20) / `atr_period`(20) / `mult`(2.0) | 肯特纳通道 |
| `stoch_k` / `stoch_d` | `period`(14) / `smooth`(3) / `d`(3) | 随机指标 K / D，0~100 |
| `cci` | `period`(14) | 顺势指标，约 ±100 为超买超卖 |
| `williams_r` | `period`(14) | 威廉指标，−100~0 |
| `roc` | `period`(12)、`source`(close) | 变动率百分比 |
| `obv` | 无 | 能量潮，累积涨跌量 |
| `vol_sma` | `period`(20) | 成交量均线，过滤异常放量/缩量 |
| `supertrend` | `period`(10)、`mult`(3.0) | 趋势通道线，收盘在上下方即多空翻转 |
| `psar` | `af_start`(0.02) / `af_step`(0.02) / `af_max`(0.2) | 抛物线 SAR |
| `vwap` | 无 | 当日成交量加权均价（按交易日重置） |
| `day_open` | 无 | 当日开盘价（按交易日重置，夜盘 18:00 后算下一交易日） |
| `prev_day_high` / `prev_day_low` / `prev_day_close` | 无 | 前一交易日最高 / 最低 / 收盘 |
| `opening_range_high` / `opening_range_low` | `period`(30) | 当日开盘前 N 根 K 线的高 / 低点，之后固定 |
| `expr` | `formula` | 算术表达式，见 4.6 |

> `vwap`、`day_open`、`prev_day_*`、`opening_range_*` 需要 K 线带时间索引；没有时间索引时算这类指标会直接报错，而不是悄悄给空值。

### 4.2 条件写法（判断只有一种，组合用 all / any / not）

| 写法 | 含义 |
| --- | --- |
| `{ gt: { left: A, right: B } }` | A > B（`gte` ≥、`lt` <、`lte` ≤、`eq` 等于） |
| `{ cross_above: { left: A, right: B } }` | 上一根 A ≤ B 且这一根 A > B |
| `{ cross_below: { left: A, right: B } }` | 上一根 A ≥ B 且这一根 A < B |
| `{ between: { value: A, low: 1, high: 9 } }` | A 落在闭区间 [1, 9] |
| `{ rising: { ref: A, bars: 2 } }` | A 连续 2 根上涨（`falling` 连续下跌，`bars` 1~50） |
| `{ break_high: { period: 20 } }` | 当根 high 突破**前** 20 根最高（不含当根）；也可以写 `{ break_high: { ref: 参照值 } }`，`break_low` 同理 |
| `{ sustained: { cond: 条件, bars: 3 } }` | 条件连续 3 根成立（含当根） |
| `{ bars_since: { cond: 条件, within: 3 } }` | 最近 3 根内至少有一根成立 |
| `{ time: { from: "09:05", to: "14:45" } }` | 当根时间在时段内；`from > to` 时按跨零点处理（夜盘） |
| `{ all: [条件1, 条件2] }` | 全部成立 |
| `{ any: [条件1, 条件2] }` | 任一成立 |
| `{ not: 条件 }` | 取反 |

**操作数 A / B 只能是**：

- 行情字段：`open` / `high` / `low` / `close` / `volume`
- `indicators` 里定义过的指标名
- 数字常量
- `{ prev: 指标名或字段, n: 2 }` —— 往前数 n 根的值（`n` 必须 ≥ 1）

> 关键习惯：判断「突破 20 根最高价」必须用 `{ prev: hh20, n: 1 }`（或直接用 `break_high: { period: 20 }`）。直接用 `hh20` 会和当根 high 比较，永远不成立。

一个条件节点里**只能写一个判断**；要组合请嵌套 `all` / `any`。嵌套最多 8 层。

### 4.3 常用形态的写法

```yaml
# 海龟式突破：不需要写 prev，break_high 自带「前 N 根、不含当根」
entry:
  long:  { break_high: { period: 20 } }
  short: { break_low: { period: 20 } }

# 连续两根收在均线上方才追
entry:
  long: { sustained: { cond: { gt: { left: close, right: ma20 } }, bars: 2 } }

# 刚突破过 20 日高点，3 根内都可以进场
entry:
  long:
    all:
      - { bars_since: { cond: { break_high: { period: 20 } }, within: 3 } }
      - { gt: { left: adx14, right: 20 } }

# 只做日盘上午和尾盘，避开午休与开盘第一根
entry:
  long:
    all:
      - { cross_above: { left: close, right: ma20 } }
      - { time: { from: "09:05", to: "14:45" } }
```

`time` 用 K 线**收盘时间**判断，所以 `from: "09:05"` 会把 09:00 那根排除在外。

### 4.4 filters / filters_htf：过滤

```yaml
filters:
  - { gt: { left: adx14, right: 20 } }
  - { lt: { left: atr14, right: 100 } }
```

列表里的条件必须**全部**成立才允许开仓（等价于外层 `all`）。不想要过滤就整段删掉。

`filters_htf` 语法完全一样，但计算用的是引擎传进来的**高周期 K 线**（配置页「止损周期」那一档）：

```yaml
filters_htf:
  - { gt: { left: close, right: ma20 } }
```

- 高周期 K 线数量不足 `required_bars` 时不开仓，状态行会写「高周期 K 线不足」。
- 高周期条件不成立时状态行会写「高周期过滤没通过（filters_htf）」。
- 回测时要确认「止损周期」已经选了比策略周期更大的档位，否则过滤等于没加。

### 4.5 stop / trail / breakeven / max_hold_bars

```yaml
stop: { kind: atr, mult: 2.0, atr_ref: atr14 }   # 开仓价外侧 2 倍 ATR
stop: { kind: percent, pct: 2 }                  # 2% 固定止损，必须小于 50
stop: { kind: swing, lookback: 10 }              # 前 10 根摆动点外侧
stop: { kind: none }                             # 不设止损，只靠离场条件
```

- `kind: atr` 时，`atr_ref` 必须指向 `indicators` 里一条 `kind: atr` 的指标，`mult` 为正数。
- 止损触发口径（触及即止 / 收盘确认）跟全策略共用的 `strategy.stop_mode` 一致，回测、实盘、优化都生效。
- `kind: none` 时算不出止损价，**这一根不会开仓**；想不设固定止损又要能开仓，请用 `percent` 给一个宽一点的止损。

可选的三个持仓管理键：

```yaml
trail: { kind: percent, pct: 2 }                  # 移动止损：每根按最新收盘重算，只朝有利方向收紧
trail: { kind: atr, mult: 1.5, atr_ref: atr14 }   # ATR 跟踪
trail: { kind: swing, lookback: 10 }              # 摆动点跟踪

breakeven: { atr: 1.0, atr_ref: atr14 }           # 浮盈 ≥ 1 倍 ATR 后，止损抬到开仓价（只抬不放）

max_hold_bars: 8                                  # 最多持有 8 根，到点平仓
```

`trail` 用和 `stop` 相同的三种算法（不能写 `none`）；`breakeven` 不写 `atr_ref` 时自动找第一条 `kind: atr` 的指标。

### 4.6 expr：算术表达式

```yaml
indicators:
  hh20:  { kind: highest, period: 20 }
  lc20:  { kind: lowest, period: 20, field: close }
  dt_range: { kind: expr, formula: "max(hh20 - lc20, hc20 - ll20)" }
  up:    { kind: expr, formula: "open + 0.7 * dt_range" }
```

- 支持 `+ - * /`、括号、一元负号，以及 `max / min / abs / sqrt / log / sign / pow / clip`。
- 滚动统计：`avg(序列, N)`、`std(序列, N)`、`hhv(序列, N)`、`llv(序列, N)`、`sum(序列, N)`；`N` 必须是 ≥ 2 的整数常量。
- 只能引用行情字段和**前面**已经定义过的指标（不支持前向引用）。
- 除数为 0 时结果为「空值」，所有空值参与的条件一律按**不成立**处理。

## 5. 指标库与计算公式（可视化配置）

不想背语法时，用编辑框右侧的 **「▸ 指标库与计算公式」** 面板点出来（默认收起，点标题展开）。

1. 点标题展开面板，在 **指标类型** 下拉里选指标（`指数均线 EMA（ema）`、`ATR（atr）`、`布林上轨（boll_upper）`……）。
2. 面板自动带出该类指标的参数输入框，按需改数字：

   | 指标类型 | 可填参数 |
   | --- | --- |
   | ema / sma / stddev | `period` 周期、`source` 取值字段 |
   | atr / atr_pct / adx / plus_di / minus_di / rsi / cci / williams_r / roc | `period` 周期 |
   | highest / lowest | `period` 周期、`field` 取值字段（open/high/low/close） |
   | macd_hist / macd_dif / macd_dea | `fast` / `slow` / `signal` |
   | boll_upper / boll_lower / boll_mid / boll_width | `period` 周期、`std` 标准差倍数 |
   | keltner_upper / keltner_lower | `period` 周期、`atr_period` ATR 周期、`mult` ATR 倍数 |
   | stoch_k / stoch_d | `period` 周期、`smooth` 平滑根数、`d` D 周期 |
   | supertrend | `period` ATR 周期、`mult` ATR 倍数 |
   | psar | `af_start` 起始 AF、`af_step` AF 步长、`af_max` AF 上限 |
   | donchian_mid / vol_sma | `period` 周期 |
   | opening_range_high / opening_range_low | `period` 开盘前 N 根 |
   | obv / vwap / day_open / prev_day_high / prev_day_low / prev_day_close | 无参数 |
   | expr | `formula` 公式（下方还有「快捷插入」按钮：行情字段、`max(` `min(` `abs(` `avg(` `std(` `sqrt(` `clip(`、已有指标名） |

3. **计算公式** 区实时显示代入当前参数后的式子，例如周期填 20 会显示
   `EMA(20) = α×收盘 + (1−α)×前一根 EMA，α = 2÷(20+1) = 0.0952 …`；参数改一下数字，式子立刻跟着变。
4. **写入 indicators: 的内容** 区实时显示将要插入的那一行，例如 `  ema20: { kind: ema, period: 20 }`。
5. 指标名默认按「缩写+周期」生成（如 `ema20`、`hh20`、`atr14`）。改完周期后可点 **自动起名**，它会避开编辑框里已用的名字生成 `ma20_2` 这种不重复的名字。
6. 点 **校验**：参数越界、名字和行情字段重名、公式引用了不存在的指标，都会在按钮右边直接说明原因。
7. 点 **插入到 indicators**：这一行会插到 `indicators:` 段的末尾；如果规则里还没有 `indicators:` 段，会自动在 `entry:` 前面补一段，语法不会乱。

插入只负责「定义指标」，**条件还要自己写**：在 `entry` / `exit` 里引用刚插入的指标名，例如
`long: { gt: { left: close, right: ema20 } }`。

> expr 类型引用别的指标时，只能引用**插入位置之前**已定义的指标；面板插入到段末，所以先定义基础指标、再插 expr 即可。

## 6. 四个可直接复制的完整示例

新建后把编辑框内容整体替换成下面任一份，改好文件名点「保存」即可。

### 示例 A：20 日区间突破

```yaml
schema: 1
name: "20日区间突破"
note: "收盘突破前 20 根最高/最低，ATR 止损"

indicators:
  hh20: { kind: highest, period: 20 }
  ll20: { kind: lowest, period: 20 }
  atr14: { kind: atr, period: 14 }

entry:
  long:  { gt: { left: close, right: { prev: hh20, n: 1 } } }
  short: { lt: { left: close, right: { prev: ll20, n: 1 } } }

stop: { kind: atr, mult: 2.0, atr_ref: atr14 }

sizing:
  mode: inherit
```

### 示例 B：RSI 超卖反弹（带 ADX 过滤）

```yaml
schema: 1
name: "RSI 超卖反弹"

indicators:
  rsi14: { kind: rsi, period: 14 }
  adx14: { kind: adx, period: 14 }
  atr14: { kind: atr, period: 14 }

# 没有趋势就不做反弹
filters:
  - { gt: { left: adx14, right: 20 } }

entry:
  long: { lt: { left: rsi14, right: 30 } }

exit:
  long: { gt: { left: rsi14, right: 55 } }

stop: { kind: atr, mult: 1.5, atr_ref: atr14 }
```

### 示例 C：布林带均值回归

```yaml
schema: 1
name: "布林带均值回归"

indicators:
  mid:   { kind: sma, period: 20 }
  up:    { kind: boll_upper, period: 20, std: 2.0 }
  lo:    { kind: boll_lower, period: 20, std: 2.0 }
  atr14: { kind: atr, period: 14 }

entry:
  long:  { cross_above: { left: close, right: lo } }
  short: { cross_below: { left: close, right: up } }

exit:
  long:  { gte: { left: close, right: mid } }
  short: { lte: { left: close, right: mid } }

stop: { kind: atr, mult: 2.0, atr_ref: atr14 }
```

### 示例 D：开盘区间突破 + 移动止损（DualThrust 思路）

```yaml
schema: 1
name: "开盘区间突破"
note: "用当日开盘前 30 根的高低点做上下轨，突破进场；移动止损 + 限持仓根数"

indicators:
  orh:   { kind: opening_range_high, period: 30 }
  orl:   { kind: opening_range_low, period: 30 }
  dopen: { kind: day_open }
  atr14: { kind: atr, period: 14 }
  adx14: { kind: adx, period: 14 }

# 高周期（配置页「止损周期」那一档）收盘比上一根高才做多，过滤逆势
filters_htf:
  - { gt: { left: close, right: { prev: close, n: 1 } } }

entry:
  long:
    all:
      - { gt: { left: close, right: orh } }
      - { gt: { left: adx14, right: 18 } }
      - { time: { from: "09:05", to: "14:45" } }
  short:
    all:
      - { lt: { left: close, right: orl } }
      - { gt: { left: adx14, right: 18 } }
      - { time: { from: "09:05", to: "14:45" } }

exit:
  long:  { lt: { left: close, right: dopen } }
  short: { gt: { left: close, right: dopen } }

stop: { kind: atr, mult: 2.0, atr_ref: atr14 }
trail: { kind: atr, mult: 1.5, atr_ref: atr14 }
breakeven: { atr: 1.0, atr_ref: atr14 }
max_hold_bars: 8
```

- `opening_range_*`、`day_open` 每根重新按「当前交易日」算，跨日自动归零，不需要手写日期。
- `trail`、`breakeven` 只会把止损往有利方向抬；`max_hold_bars` 到点直接平仓，避免日内单过夜。

## 7. 修改、另存、重命名、删除

### 修改已有策略
左侧列表点选文件 → 直接改编辑框 → 「保存」。校验失败不会覆盖原文件。修改后标题会带 `*`，切换文件或点「新建规则」时会先问要不要放弃。

> 改了规则内容后，策略**名字**（`name:`）可以改，但**文件名**不变，引擎代号也不变。

### 另存为一份新策略（改内置模板的唯一正确姿势）
1. 左侧点一个 `[内置]` 模板（如 `dualthrust`）。
2. 在「文件名」框填一个全新名字，比如 `my_dualthrust`。
3. 点「保存」。
4. 得到 `config/rules/my_dualthrust.yaml`，原来的内置文件一字未动。

### 重命名用户规则
1. 左侧点选自己的规则（确认不是 `[内置]`）。
2. 在「文件名」框填新名字。
3. 点「重命名」。若当前运行策略正指向这条规则，会自动切到新名字。

### 删除用户规则
选中后点「删除」。文件会被移除，策略下拉里立即少一项；若当前正在用这条策略，引擎自动回退到「日内实体」。

## 8. 权限边界：内置规则不可删改

| 操作 | 内置（`builtin: true`） | 自己的规则 |
| --- | --- | --- |
| 打开查看 / 复制内容 | ✅ | ✅ |
| 直接覆盖保存 | ❌ 提示「改个文件名另存为自己的规则」 | ✅ |
| 重命名 | ❌ | ✅ |
| 删除 | ❌ | ✅ |

内置模板共 5 个：`dual_ma_equiv`、`dualthrust`、`r_breaker`、`turtle_adx`、`adx_atr_break`。它们是你学习写法的参考，改了也没关系——另存为新文件即可，程序自带的始终干净可用。

## 9. 常见报错对照

| 状态行提示 | 原因 / 改法 |
| --- | --- |
| `未知指标 'xxx'` | `kind` 拼错，对照第 4.1 节的 kind 列 |
| `指标名不能和行情字段重名` | 把指标改名，别叫 `close` / `open` 等 |
| `未知字段 'xxx'；只能是 open/high/low/close/volume，或 indicators 里定义过的名字` | 指标名拼错，或引用了定义在后面的指标（expr 不支持前向引用） |
| `一个条件只能写一个判断` | 一个 `{}` 里塞了两个判断，拆成 `all: [...]` |
| `必须且只能写 left 和 right` | 比较条件写成了 `min` / `max` 之类 |
| `条件嵌套超过 8 层` | 拆成多个 `filters` 或简化条件 |
| `stop.atr_ref 必须指向 indicators 里一条 kind=atr 的指标` | `atr_ref` 写错，或对应指标不是 `atr` |
| `trail.kind 移动止损不能写 none` | 不想用移动止损就把整个 `trail` 段删掉 |
| `breakeven.atr_ref 必须指向 indicators 里一条 kind=atr 的指标` | `breakeven` 需要的 ATR 指标没定义，补一条 `kind: atr` |
| `百分比止损不能超过 50%` | `pct` 太大 |
| `time 必须且只能写 from 和 to` | 时段写成 `09:05-14:45` 了，改成 `{ from: "09:05", to: "14:45" }` |
| `break_high 写 period（自动取前 N 根高低点）或 ref（显式给参照值）` | 只写 `period` 或只写 `ref`，别混着写 |
| `第一档只支持 inherit` | `sizing.mode` 写了别的值 |
| `不认识的顶层键 [...]` | 键名拼错，对照第 4 节的表格 |
| `规则文件不存在：xxx.yaml` | 删除/重命名时文件已不在，刷新左侧列表重选 |
| `程序自带规则，不能删除 / 改名 / 覆盖` | 见第 8 节，另存为新文件名 |

> `kind: none` 的规则能编译、能回测，但算不出止损价时不会开仓——这是刻意设计，避免无风控裸奔。

## 10. 写规则的小贴士

1. **先窄后宽**：先用一个指标、一个条件跑通，再加过滤和离场，报错更容易定位。
2. **注意预热根数**：指标需要足够的历史 K 线才出值，前几十根不会开仓，这是正常的。
3. **突破类两种写法**：直接 `break_high: { period: N }` 最省事；手写比较时右侧用 `{ prev: 指标名, n: 1 }`。
4. **写 `exit` 更可控**：只靠止损容易把利润坐回去，建议加一条反向条件离场。
5. **空值一律不成立**：指标还没热起来、除零、数据缺口都不会误触发信号。
6. **改完回测再上实盘**：先在「历史回测」页用同一策略跑一段，确认信号符合预期。
7. **文件名即引擎代号**：`my_rule_1.yaml` ↔ `rule_dsl:my_rule_1`，两者一一对应，改名会改代号。
