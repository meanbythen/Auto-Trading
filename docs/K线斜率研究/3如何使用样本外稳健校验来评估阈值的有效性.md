# 核心思想
样本外校验的本质：**不用未来数据，不在同一批数据上既选参数又评估效果**。
你现在的对象：`(N_slope, T)` 这一组参数（回归窗口+EMA120斜率阈值），目标验证：这个斜率过滤器是不是真的能稳定区分【趋势/震荡】，而不是在历史曲线里碰巧切出来一段盈利行情。

> 区分两个概念
> - **样本内（训练集 In-sample）**：用来网格搜索、选出最优阈值T、N_slope
> - **样本外（测试集 Out-of-sample）**：模型/阈值**从来没见过**的数据，只用来打分，**绝对不能用来调参**

适合CTA、日内期货（燃油/纯碱/白糖）的标准方案是：**滚动窗口（Walk Forward Analysis，WFA，向前滚动分析）**，而不是简单切一段训练、一段测试（单分割容易选到特殊行情段）。

# 一、WFA 滚动校验标准流程（适配你的斜率过滤器）
## 1. 先定义窗口大小（非常关键）
你是日内15min，给一个通用模板，你可以按品种微调：
- 训练窗口（In-sample）：比如 **120个交易日** → 用来网格搜索 `N_slope ∈ [20,25,30,35,40]`，`T ∈ [0.0010,0.0030]`，选出该窗口内最优参数组
- 测试窗口（Out-of-sample）：比如 **40个交易日** → 用训练集选出的那组固定参数，在这段全新数据上跑，记录绩效，**不做任何参数优化**
- 滚动步长：40个交易日（和测试窗口等长）
> 含义：每过40天，重新在最近120天训练集寻优一次，拿到新参数，再去接下来40天测试。
> 👉 好处：兼顾“参数慢慢适应市场”，又保证每一段测试都是样本外。

> 窗口选择经验：
> - 训练集太短：参数噪声极大，每次选出的T跳来跳去，不稳定
> - 训练集太长：市场结构变了，参数陈旧
> - 测试集不能太短：至少要包含若干轮趋势+震荡，不然单次样本外结果没有统计意义

示例时间轴：
```
[训练 0~120交易日] → 选最优(N,T) → [测试121~160交易日]（样本外记录）
[训练 41~160交易日] → 选最优(N,T) → [测试161~200交易日]（样本外记录）
[训练 81~200交易日] → 选最优(N,T) → [测试201~240交易日]（样本外记录）
……持续滚动直到数据尾部
```

⚠️ 铁律：**测试集的任何绩效，不能反过来修改训练集的搜索范围和目标函数**。

## 2. 每一轮训练集内部做什么
在当前训练窗口内：
1. 逐Bar计算 EMA120、归一化回归斜率 slope_norm
2. 网格遍历候选 `(N_slope, T)`
3. 按你的环境规则：
   - `abs(slope_norm) < T`：震荡，禁止趋势开仓
   - `slope_norm > T`：多头环境，只允许开多
   - `slope_norm < -T`：空头环境，只允许开空
4. 对每一组参数，拆成【趋势时段绩效】、【震荡时段绩效】
5. 按你预先定好的目标函数打分，选出本轮训练最优参数组：
   > 优先目标：趋势段卡尔玛比率 > 震荡段卡尔玛比率，同时整体卡尔玛高，趋势Bar占比≥8%
   > （不要临时改打分规则！规则固定，才叫校验）

输出本轮最优：`best_N, best_T`

## 3. 每一轮样本外测试集做什么
拿到 `best_N, best_T`，**固定不变**，在测试集K线上原样跑一遍策略：
✅ 只记录指标，不寻优、不微调阈值
✅ 记录两类指标（这是评估斜率过滤器有效性的核心，不只是总收益）
1. 全局指标：样本外卡尔玛、年化收益、最大回撤、盈亏比、总交易次数
2. 拆分指标（重中之重，专门检验过滤器）
   - 样本外【趋势区间】：卡尔玛、盈亏比、胜率、每笔盈亏
   - 样本外【震荡区间】：卡尔玛、盈亏比、胜率、每笔盈亏

> 过滤器有效的核心判定条件（样本外！不是样本内）：
> ✅ 趋势子集卡尔玛 > 震荡子集卡尔玛
> ✅ 趋势子集盈亏比 > 震荡子集盈亏比
> 如果样本外，趋势段反而不如震荡段 → 这个斜率划分逻辑失效，阈值算法本身泛化差，不能实盘

## 4. 汇总所有滚动片段的样本外结果
把所有测试片段拼起来，得到**全样本外合并绩效**，这才是WFA的真实绩效，而不是某一段训练集的漂亮回测曲线。

统计两个稳定性指标：
1. 每一轮选出的 `best_T`、`best_N` 的标准差
   - 如果每一轮最优T来回剧烈跳动（一会儿0.0012，一会儿0.0028）：参数不稳定，市场一变阈值就变，实盘很难用；说明斜率信号信噪比低
   - 如果最优值集中在一个窄区间：稳健度高
2. 样本外片段胜率：多少个滚动测试片段里，满足【趋势卡尔玛 > 震荡卡尔玛】
   - 比如 10段测试里有8段满足：稳健
   - 10段只有4段满足：和抛硬币差不多，过滤器无效

# 二、两种校验对比（不要混淆）
1. **简单单分割（In-sample / OOS一次切分）**
   前70%训练，后30%测试
   - 缺点：行情结构可能前后差异巨大，结果有偶然性；你不知道是参数强还是刚好后面一段是大趋势
   - 适合：快速初步筛查，**不能作为最终有效性证明**

2. **向前滚动WFA（推荐，CTA行业标准）**
   分段滚动、多次样本外测试
   - 缺点：计算量大，回测慢
   - 优点：模拟真实实盘流程——交易者定期用历史数据重新评估参数，用新参数去应对未知行情；最贴近实盘的校验方式

# 三、关键校验指标清单（你写报告/代码里直接用）
在每一段样本外测试集，必须统计：
|指标|合格信号|危险信号|
| ---- | ---- | ---- |
|趋势段卡尔玛 / 震荡段卡尔玛|>1.2 以上，拉开差距|≤1，过滤器没有区分能力|
|趋势段盈亏比|高于震荡段|震荡段盈亏比更高|
|趋势Bar占比|8% ~ 25%|＜5%（样本太少，结论不可信）|
|滚动最优T的标准差|小，集中在小区间|大幅跳变|
|样本外合并卡尔玛|和样本内最优卡尔玛差距不大|样本内卡尔玛2.5，样本外直接掉到0.5（严重过拟合）|

> 重要：允许样本外绩效比样本内差一点（天然存在过拟合衰减），但是**不能反转优劣关系**。
> 样本内趋势赚震荡亏，样本外变成震荡赚趋势亏 → 直接放弃这套斜率过滤逻辑。

# 四、常见坑（非常容易踩）
1. ❌ 滚动的时候，测试集数据偷偷参与寻优
   很多人写代码bug：整个数据集一次性算完全部斜率，再切滚动窗口 → 计算斜率时用到了未来K线，属于**前视偏差(look-ahead bias)**，校验结果完全失真。
   > 正确：每一个滚动窗口内，斜率只能用窗口内已有的K线计算，严格bar-by-bar，不能拿未来数据算EMA和回归斜率。

2. ❌ 目标函数中途修改
   第一轮发现效果不好，改打分公式、改阈值上下限，反复试，本质等于把测试集信息泄露给参数搜索。

3. ❌ WFA之后，直接拿全部数据再跑一遍，挑一个全局最优T去实盘
   WFA的目的是验证方法；如果你校验完，又在全部数据上重新寻优一个固定T，前面样本外校验的意义就没了。
   两种实盘路线二选一：
   - 路线A（固定阈值）：WFA验证这套参数区间稳健，然后选区间中间平坦值固定使用，不再全量寻优
   - 路线B（滚动自适应参数）：实盘定期（比如每40个交易日）自动在最近120天训练集重选参数，和WFA流程一致

4. ❌ 只看总收益，不拆分趋势/震荡子集
   有可能整体赚钱，但是收益全部来自震荡段，斜率过滤器等于摆设。

# 五、极简伪代码框架（可以嵌入vnpy回测引擎）
```python
# 配置
train_days = 120
test_days = 40
rolling_step = 40

# 全部K线序列：bars
results_oos = []
param_history = []

start_idx = 0
while True:
    train_end = start_idx + train_days
    test_end = train_end + test_days
    if test_end >= len(bars):
        break
    
    # ========== 训练集：寻优 ==========
    train_bars = bars[start_idx : train_end]
    # 在train_bars内计算ema120、slope_norm，网格搜索
    best_N, best_T, train_metrics = grid_search(train_bars)
    param_history.append({"N":best_N, "T":best_T})

    # ========== 样本外测试集：固定参数跑 ==========
    test_bars = bars[train_end : test_end]
    oos_metrics = run_strategy(test_bars, N_slope=best_N, T=best_T)
    results_oos.append(oos_metrics)

    start_idx += rolling_step

# ========== 汇总评估 ==========
# 1. 合并所有oos_metrics，得到整体样本外绩效
# 2. 统计每一段：趋势卡尔玛、震荡卡尔玛
# 3. 统计best_T序列均值、标准差，看稳定性
```

# 六、补充：和自适应阈值方案怎么结合校验？
如果你后面打算用【滚动分位数自适应T】而不是固定T：
校验逻辑不变，只是把网格搜索T改成搜索**分位数q**（比如0.80/0.85/0.90），滚动训练集里选最优分位数q，样本外测试集用这个q动态生成T，再评估。
