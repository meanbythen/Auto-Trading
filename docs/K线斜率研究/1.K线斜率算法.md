# 核心思路说明
你想要的：**以EMA120为基准，计算均线斜率；震荡时斜率很小被过滤，趋势起来斜率突破阈值才触发信号**。
重点坑先说清楚：
> 直接用最后两根K线的EMA差值算斜率，噪声极大，反复假突破；
> 斜率不能固定阈值（价格高低不同，同样角度绝对值完全不一样），优先**归一化斜率**。

下面给3套梯度方案：最简版（上手快）、归一化斜率（推荐，适配你CTA/日内）、线性回归斜率（最稳，适合过滤震荡），附带Python代码（可直接嵌入vnpy）、过滤逻辑、阈值调试方法。

> 标的：EMA120，周期自己定（日线/15min都可以）

---

## 方案1：简单差分斜率（入门，不推荐直接实盘）
公式：
$$
slope_{diff} = EMA120[t] - EMA120[t-N]
$$
N：回看周期，比如N=10（取10根K线前的EMA值）

问题：价格基数影响巨大。纯碱2000点和燃油3000点，同样趋势，差值完全没法共用阈值。
👉 改进：除以基准价格做归一化，变成**年化/周期涨跌幅形式**

归一化差分斜率（可用）：
$$
slope_{norm\_diff} = \frac{EMA120[t] - EMA120[t-N]}{EMA120[t-N]}
$$
含义：**过去N根K线，120均线本身的涨跌幅**
- 震荡：这个值在0附近小幅来回
- 多头趋势：> 上阈值
- 空头趋势：< -下阈值

✅ 优点：计算极快，TICK/bar级别无压力
❌ 缺点：只取首尾两点，中间K线信息丢失，容易被单根异动K线带偏

---

## 方案2：线性回归斜率（强烈推荐！适配你的需求）
对最近N根K线的 EMA120 序列，做一元线性回归：
$$
y_i = a + b \cdot x_i
$$
- $y_i$：第i根K线的 EMA120 值
- $x_i$：时间序号 0,1,2...N-1
- $b$：回归斜率（原始斜率）

同样，原始b不能直接用，必须归一化：
$$
slope_{reg} = \frac{b}{mean(EMA120_{window})}
$$
> 除以窗口内EMA均值，得到**单位时间均线的相对变化率**，纯碱、燃油、玉米可以共用一套斜率阈值，跨品种友好。

参数说明：
1. EMA长度 = 120（你的基准）
2. 回归窗口N：**建议 20~40**
   - N太小（5）：灵敏、杂波多，震荡频繁出信号
   - N太大（60+）：滞后，趋势启动抓不到
> 平衡方案：N=30 是很常用的组合：看30根K线上EMA120整体倾斜程度，而不是一两根。

### 信号规则（直接抄）
```
slope_reg > slope_thresh  → 多头趋势环境（只开多，过滤震荡空单）
slope_reg < -slope_thresh → 空头趋势环境（只开空，过滤震荡多单）
abs(slope_reg) < slope_thresh → 判定震荡，禁止开趋势单，只做震荡策略或者不交易
```

额外叠加增强过滤（非常适合CTA）：
1. ADX二次过滤：ADX < 20 就算斜率达标，也认为是弱趋势，放弃信号（和你之前ADX+ATR过滤器天然适配）
2. 价格位置过滤：当前价格在EMA120上方才看多斜率；价格在EMA120下方才看空斜率，避免均线向上但价格在均线下方的背离陷阱

## 方案3：角度换算（不推荐用于程序化，仅可视化看）
很多人喜欢把斜率转角度：
$$
angle = \arctan(b) \cdot \frac{180}{\pi}
$$
致命问题：**角度高度依赖K线图表的X/Y轴缩放**，图表拉宽压缩，角度直接变，回测不稳定，程序化不要用角度做判断！只用归一化斜率。

# Python代码（vnpy直接可用，回归归一化斜率）
依赖：`numpy`
```python
import numpy as np

def calc_ema(series: np.ndarray, period: int = 120):
    """计算EMA"""
    ema = np.zeros_like(series)
    alpha = 2.0 / (period + 1)
    ema[0] = series[0]
    for i in range(1, len(series)):
        ema[i] = alpha * series[i] + (1 - alpha) * ema[i-1]
    return ema

def calc_ema_slope_reg(ema_series: np.ndarray, window: int = 30):
    """
    计算 EMA序列 线性回归归一化斜率
    :param ema_series: EMA数组
    :param window: 回归窗口N
    :return: slope_norm 归一化斜率
    """
    if len(ema_series) < window:
        return 0.0
    y = ema_series[-window:]
    x = np.arange(window)
    # 一元线性回归
    slope, intercept = np.polyfit(x, y, deg=1)
    y_mean = np.mean(y)
    if y_mean == 0:
        return 0.0
    slope_norm = slope / y_mean
    return slope_norm

# ========= 使用示例 =========
# close: np.ndarray K线收盘价
# ema120 = calc_ema(close, 120)
# slope = calc_ema_slope_reg(ema120, window=30)
# thresh = 0.0015  # 阈值需要回测调参
# if slope > thresh:
#     trend_mode = 1
# elif slope < -thresh:
#     trend_mode = -1
# else:
#     trend_mode = 0 # 震荡
```

# 阈值怎么调？重点（很多人卡在这里）
`slope_norm` 的物理含义：**每根K线，EMA120相对自身均值的变化比例**
举个例子（15min周期，供参考，不是万能值）：
- 阈值 `0.001 ~ 0.002`：比较灵敏，小趋势能抓到，假信号略多
- 阈值 `0.002 ~ 0.003`：偏稳，过滤大部分震荡，趋势确认后入场（推荐起步值）

> 调参原则：不要肉眼看K线拍脑袋，用回测遍历：
> 目标指标：卡尔玛比率、最大回撤、盈亏比，而不是胜率。
> 你本金3万日内，优先选**更高卡尔玛**的参数组合，不要追求信号多。

## 可选升级：斜率变化率（趋势加速度）
再加一层：计算斜率本身的差分，识别**斜率正在抬升（趋势加速）**，避开斜率慢慢衰减的趋势末期：
```python
slope_now = calc_ema_slope_reg(ema120, 30)
slope_prev = calc_ema_slope_reg(ema120_old, 30)
slope_delta = slope_now - slope_prev
# 多头优选：slope>thresh AND slope_delta>0，趋势正在变强
```

# 和你现有体系的组合方案（适配你的日内CTA）
你之前在用：DualThrust / R-Breaker、ATR动态仓位、ADX过滤器
组合架构：
1. 第一层环境过滤器：**EMA120归一化回归斜率**，区分【震荡/多头趋势/空头趋势】
   - 震荡模式：关闭趋势突破开仓，只不做或者切换震荡反转策略
   - 趋势模式：允许DualThrust、突破类信号进场
2. 第二层：ADX，ADX<20 压制信号，弱趋势放弃
3. 第三层：ATR计算止损、仓位
4. 第四层：价格相对EMA120位置过滤：顺斜率方向开仓

> 避坑提醒：EMA120本身是滞后均线，这个方案是**抓中长期均线的趋势环境**，不是抓拐点，适合趋势跟踪；如果你想要拐点，不能用120EMA斜率体系。
