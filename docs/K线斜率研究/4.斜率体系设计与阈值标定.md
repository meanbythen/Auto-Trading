# K 线斜率体系设计与阈值标定

目标：**EMA 走平时过滤震荡，斜率足够时确认趋势**，并把这套判断做成所有策略共用的一份实现，而不是每个策略各写一套。

本文只给设计与标定方法，不改现有开仓规则。落地分三步，见第 7 节。

---

## 1. 判定框架

斜率只回答一个问题：**这根均线现在是在走平，还是在朝某个方向走。**

输出三态，而不是简单的「过/不过」：

| 状态 | 条件 | 策略含义 |
|---|---|---|
| 多头趋势 | 角度 ≥ 入场阈值，且价格在均线之上 | 允许做多 |
| 空头趋势 | 角度 ≤ -入场阈值，且价格在均线之下 | 允许做空 |
| 走平/震荡 | 角度绝对值 < 离场阈值 | 禁止新开趋势仓 |
| 中间带 | 离场阈值 ≤ 角度绝对值 < 入场阈值 | 保持上一状态（滞回） |

滞回带的作用：避免角度在阈值附近来回抖动，导致开关反复。建议 `离场阈值 = 0.8 × 入场阈值`。

斜率是**环境过滤器**，不是入场信号。方向仍由均线排列、价格位置、突破等条件决定。

## 2. 算法

### 2.1 输入

- `close`：已收盘 K 线收盘价（实盘用最后一根已收线，不用未完成 K 线）
- `EMA_L`：方向均线，默认 120
- `N`：斜率回看根数，默认 20
- `ATR`：ATR14，作为波动率标尺

### 2.2 斜率估计

在 `EMA_L[t-N .. t]` 共 N+1 个点上做一元线性回归：

```
b = Cov(i, y) / Var(i)          i = 0..N
rise_N = b × N                   N 根累计涨幅
```

`b` 是每根均线的平均变化量，`rise_N` 是整段涨幅。用回归而不是首尾两点，能避免端点单根异动把斜率带偏；两者在本项目 lh2701/lh2703 上的相关性约 0.999，但回归在门槛附近更稳。

### 2.3 归一化

推荐 **ATR 归一化**：

```
s = rise_N / (N × ATR) = b / ATR
角度 θ = atan(s) × 180 / π
```

含义：均线每根走掉的幅度，相当于多少倍 ATR。价格高低、波动大小不同的品种可以直接共用同一把尺子。

不推荐直接用价格归一化（`b / mean(EMA)`）定阈值：

- 本地 15 分钟数据里，价格归一化的 85 分位在 0.00044（lh）到 0.00085（fu），差近一倍；
- 资料中建议的 0.0015~0.003，在本地数据上的通过率接近 0，直接套用会让策略几乎没有信号。

价格归一化可以保留作**诊断指标**（跨品种比较趋势强度），但不作为开关阈值。

### 2.4 稳定性处理

1. ATR 分母做 5 根中位数平滑，并下限 `max(3 × 最小变动价位, 1e-9)`，避免单根巨幅波动把角度压小。
2. 至少需要 `EMA_L + N + 1` 根 K 线才输出有效状态；不足时返回「未知」，按走平处理。
3. 可选 `R² ≥ 0.5`：回归拟合度太低说明均线在弯折，不算干净趋势。默认关闭。业界更常用**斜率的 t 值**（斜率除以斜率标准误），它与 R² 单调等价、但自带显著性含义；阶段 1 建议直接实现 t 值，R² 只做展示。
4. 可选价格位置确认：做多要求 `close > EMA_L`，做空要求 `close < EMA_L`。默认开启。
5. 可选 ADX ≥ 20：与斜率同向时更稳，默认关闭，避免和斜率重复过滤。

## 3. 阈值怎么定

### 3.1 先看本地数据

15 分钟、EMA120、N=20、ATR14、回归口径，`|角度|` 的分位数与通过率：

| 合约 | 中位数 | q80 | q85 | q90 | q95 | ≥3° 占比 | ≥5° 占比 |
|---|---|---|---|---|---|---|---|
| lh2701 | 2.49° | 5.07° | 5.63° | 6.37° | 7.49° | 42.2% | 20.8% |
| lh2703 | 2.58° | 5.16° | 5.83° | 6.77° | 7.82° | 42.6% | 21.6% |
| fu2701 | 3.64° | 6.46° | 7.12° | 8.50° | 9.87° | 60.3% | 33.1% |
| fu0（5 分钟） | 3.19° | 6.10° | 7.51° | 9.56° | 11.12° | 53.2% | 26.3% |

两个结论：

1. **3° 并不是强趋势门槛**：它让 42%~60% 的 K 线都算「有角度」，作为震荡过滤器偏松。真正接近「少数趋势时段」的是 5°~7°。
2. **不同品种的分布差异明显**：同样 5°，lh 只通过约 21%，fu 通过约 33%。所以阈值要么按品种标定，要么用滚动分位数自适应。

### 3.2 标定原则

- 目标覆盖率：**趋势状态占全部 K 线的 20%~25%**（多空合计），对应 `q75~q80`。
- 覆盖率只是**体检指标**，不是标定目标。真正的标定目标是「未来是否走出趋势」：用未来 20 根的走势给每根 K 线打趋势/震荡标签，再看阈值能否把两类分开（AUC、精确率、召回率），最后才看回测收益。只按分位数定阈值，等于强行规定「永远有 20% 是趋势」，震荡市里也会误判。
- 每个「品种 × 周期」单独统计 12~24 个月；同一品种的近月与远月（lh2701/lh2703）差异小于 30% 时，可合并取池化分位数。
- 阈值下限 2°，上限 8°；超出范围的标定结果视为样本不足，回到默认值。
- 样本必须按时间切分：前 70%~80% 标定，最后 20%~30% 完全不参与定参，只做最终验收；否则分位数里已经含了未来信息。

### 3.3 建议初始值

| 周期 | 默认入场阈值 | 参考依据 |
|---|---|---|
| 5 分钟 | 6.0° | fu0 的 q80 约 6.1°；5 分钟噪声更大，不宜低于 5.5° |
| 15 分钟 | 5.5°（lh 5.0°，fu 6.5°） | 两者 q80 分别约 5.1°、6.5° |
| 60 分钟 | 3.5°~4.0° | 周期越大噪声越小，需用 6~12 个月数据复核 |
| 日线 | 2.0°~2.5° | 日线样本少，先按经验值，至少 2 年数据再定 |

离场阈值取入场阈值的 0.8 倍。例如 15 分钟 lh：入场 5.0°，离场 4.0°。

### 3.4 自适应模式（已实现，默认关闭）

固定阈值已经做了波动率归一化，但无法消除品种间「趋势性」差异。可选自适应：

```
T_t = clip( quantile(|θ|, q=0.80, 过去 500 根), 0.7×T0, 1.3×T0 )
```

- 只使用已收盘数据，无未来函数；当前这根已收盘，允许计入窗口；
- 有效角度不足 50 根时退回基准 `T0`，不会因为预热期算出离谱阈值；
- 默认关闭；只有样本外验证证明它比固定阈值更稳时才启用。

实现（53.2.0，53.4.0 增加日线冻结，53.6.0 统一 0=关闭）：

- `slope_angle_series()` 逐根算角度，口径与 `measure_slope` 完全一致（同一回归、同一 ATR 归一化），最后一点逐位对齐，有单测保证；
- `adaptive_angle_threshold()` 取窗口内 `|角度|` 分位并按 0.7~1.3 倍夹紧；
- `ema_swing`：`slope_adaptive / slope_adaptive_quantile / slope_adaptive_window`；
- `trend_follow`、`supertrend`：`slope_gate.adaptive / adaptive_quantile / adaptive_window`；
- 日线开盘冻结：`slope_adaptive_daily`（默认开）、`slope_gate.adaptive_daily`（默认开）。同一交易日只算一次阈值，夜盘 21:00 起算下一交易日，盘内不再随滚动窗口跳动；关掉才逐根更新。
- 冻结时同一天直接复用缓存，省掉逐根重算角度序列；不同合约按 `symbol` 分开缓存。
- 关闭自适应时不做任何额外计算，逐根行为与固定阈值完全一致。
- 关闭斜率门的两种写法等价：`slope_gate.enabled=false`，或 `min_deg=0` 且 `min_t=0`（此时 `SlopeGate.enabled` 视为 false，不占预热 K 线）；`ema_swing` 同理，`slope_min_deg=0` 且 `slope_min_t=0` 直接放行。

## 4. 检验方法

### 4.1 参数网格

- N：15、20、25、30
- 阈值：固定值 {3.0, 4.0, 5.0, 5.5, 6.0, 7.0}，加上该品种的 q70、q75、q80、q85、q90
- 估计器：`reg` 与 `diff` 各跑一遍，确认结论不依赖估计器

### 4.2 评价指标

不只看胜率：

1. **净盈亏、盈利因子、最大回撤、Calmar**（年化收益/最大回撤）
2. **期望值**（每笔平均盈亏）
3. **趋势捕获率**：定义为「未来 20 根内同向移动 ≥ 2×ATR，且最大逆向 < 1×ATR」的趋势片段中，被策略抓到方向的比例
4. **震荡假信号率**：没有趋势片段却开仓、并被止损的比例
5. **暴露时间**：有仓时间占比，防止靠长期空仓做出好看的回撤

硬性门槛：成交 ≥ 30 笔；否则只能作为观察，不能定参数。

### 4.3 样本外与稳健性

- **滚动样本外**：6 个月训练、2 个月测试，每次前滚 2 个月，至少 3 折。
- 验收：样本外 Calmar ≥ 0.7 × 样本内；至少 2/3 折为正；阈值漂移不超过 20%。
- **邻域平台**：N±1、阈值±0.5° 的结果不能明显翻转；最优点周围 8 个邻居平均绩效与最优点差距在 15% 以内，才算稳定。
- **跨品种**：lh2701、lh2703、fu2701 同时跑；相关合约的标定阈值差超过 50% 时，改用池化分位数，不各用各的。
- **跨周期**：5 分钟和 15 分钟结论方向应一致；只在一个周期有效，说明是拟合噪声。

### 4.4 上线后监控

每月统计一次：趋势覆盖率、开仓次数、被斜率拦下的次数、趋势捕获率。

- 覆盖率连续 20 个交易日低于 8%：阈值过高或行情长期震荡，检查是否需要自适应；
- 覆盖率高于 45%：阈值过低，震荡过滤失效；
- 趋势捕获率比回测下降超过 30%：检查数据源、合约切换或波动率结构变化。

## 5. 统一接口

建议新增 `src/strategy/slope.py`，所有策略共用，不再各自实现（阶段 1 已完成，见第 7 节）：

```python
@dataclass(frozen=True)
class SlopeConfig:
    ema_period: int = 120
    lookback: int = 20
    method: str = "reg"          # reg | diff
    normalize: str = "atr"       # atr | price（price 仅诊断）
    entry_deg: float = 5.0
    exit_deg: float = 4.0
    adaptive: bool = False
    quantile: float = 0.80
    window: int = 500
    floor_deg: float = 2.0
    cap_deg: float = 8.0
    price_side: bool = True
    min_r2: float = 0.0          # 0 = 关闭，仅展示
    min_t: float = 0.0           # 0 = 关闭；灵敏度门槛，20 根建议 ≥ 2.1
    confirm_er: float = 0.0      # 0 = 关闭；Kaufman 效率比下限，如 0.30
    confirm_chop: float = 0.0    # 0 = 关闭；震荡指数上限，如 61.8
    htf_slope: bool = False      # 是否要求高一级周期斜率同向
    adx_min: float = 0.0         # 0 = 关闭


@dataclass(frozen=True)
class SlopeState:
    direction: int               # 1 多 / -1 空 / 0 走平
    angle_deg: float             # 带符号
    threshold_deg: float
    regime: str                  # up / down / flat / neutral / unknown
    r2: float
    reason: str
```

核心方法：

```python
class SlopeFilter:
    def evaluate(self, bars: pd.DataFrame, atr: pd.Series, ema: pd.Series) -> SlopeState: ...
```

约定：

- 只读已收盘 K 线，索引最后一根；
- ATR 不足或均线未预热时返回 `unknown`，按 `flat` 处理；
- 产出的 `reason` 直接用于日志和下单备注，便于复盘。

## 6. 接到现有策略

| 策略 | 现状 | 接法 |
|---|---|---|
| `ema_swing` | 已有 `slope_min_deg/lookback/method`，本地实现 | 改为调用共用 `SlopeFilter`，先保证输出与现在逐根一致（黄金测试） |
| `multi_factor` | 均线因子看排列，没有环境斜率 | 增加可选 `slope_gate`，默认关闭；开启后只在对角方向加分/放行 |
| `trend_follow` | 无斜率过滤 | 可选环境门，默认关闭 |
| `supertrend` / `bollinger` / `sar_trend` | 无斜率过滤 | 可选环境门，默认关闭 |

原则：**先共用实现，再逐个策略 A/B，最后才改默认值。** 不同策略同时换闸门，回测结果无法归因。

配置建议：

```yaml
strategy:
  ema_swing:
    slope:
      ema_period: 120
      lookback: 20
      method: reg
      entry_deg: 5.0
      exit_deg: 4.0
      price_side: true
```

为兼容旧配置，`slope_min_deg`、`slope_lookback`、`slope_method` 继续识别，映射到新字段；旧键优先，避免升级后行为突变。

验收线：

- 阶段 1：黄金测试逐根一致；全量测试、ruff、mypy 通过。
- 阶段 3：样本外 Calmar ≥ 0.7 × 样本内；至少 2/3 折为正；成交数不少于 30 笔；邻域平台内不翻转；候选的全段 Calmar 和样本外净盈亏都不能低于基线。

阶段 2 实测（2026-11-23，本地 `market.sqlite`，15 分钟 + 日线）：

- 15 分钟 12 个合约、每个 2300~5500 根样本：未来 20 根趋势标签下，`|角度|` 的样本外 AUC 集中在 0.46~0.55，方向精确率约 24%~39%（趋势占比约 41%，方向基准约 21%），只有极弱的正向 lift；提高阈值到 6° 并没有让精确率明显变好。
- 日线每个交割月只有 160~480 根，样本外仅几十根，AUC 在 0.2~0.9 之间大幅跳动，属于小样本噪声，不能据此定阈值。
- 因此阶段 2 的结论是：分位数可以当体检，但**不能**把 q80 或「AUC 最优」直接当成新默认；阶段 3 必须以真实策略回测的盈亏、Calmar 和成交数做 A/B，且允许结论是「维持 3°」。
- 报告生成：`python tools/slope_calibrate.py --periods 15,D` → `data/斜率标定.xlsx`（「推荐」表第 19 列「标定结论」直接写是否具备样本外区分度）。

阶段 3 实测（2026-11-23，`ema_swing` 真实换月回测，lh + fu 15 分钟，3 折时间切分）：

| 阈值 | 成交 | 全段净盈亏 | 全段 Calmar | 样本外净盈亏 | 样本外 Calmar | 结论 |
|---|---|---|---|---|---|---|
| 2.5° | 70 | 68745 | 1.44 | 35284 | 2.18 | 全段 Calmar 不如 3°，不换 |
| 3° | 65 | 67458 | 1.58 | 29159 | 1.46 | 基线 |
| 4° | 53 | 63685 | 1.38 | 29823 | 1.70 | 全段 Calmar 不如 3°，不换 |

- 2.5° 的样本外 Calmar 最高，但全段回撤更大、全段 Calmar 1.44 < 1.58，属于「押中最后一段」；4°/5° 的成交和收益逐档下降，5° 明显更差。
- 这与阶段 2 的 AUC 结论一致：问题不在 3° 这个点，而在「EMA120 的 15 分钟角度」本身对未来的信息量很弱。提高阈值只会减少交易，不会提高质量。

## 8. 风险清单

1. **阈值过拟合**：单品种、单周期、十几笔交易的结果不足以定参数，必须跨品种、样本外。
2. **ATR 分母失真**：极端行情下 ATR 跳变会让角度瞬间变小，需平滑和下限。
3. **趋势晚期才确认**：EMA120 + 20 根回看天然滞后，抓不到第一段，这是设计代价，不要用降低阈值来换。
4. **滞回造成延迟**：入场 5°、离场 4° 会比单阈值晚一点退出，需在回测里确认回撤可接受。
5. **品种差异**：lh 与 fu 的分布差近 50%，不要用一个阈值硬套所有品种。

## 9. 业界做法对照与改进结论

### 9.1 主流做法

| 做法 | 代表实现 | 归一化 | 常用阈值 |
|---|---|---|---|
| 原始回归斜率 | TA-Lib `LINEARREG_SLOPE`、pandas-ta `linreg` | 价格单位/根，未归一化 | 需自行换算 |
| 斜率 t 值 | 把斜率除以斜率标准误，等价于回归 t 统计量 | 无量纲 | 大样本 \|t\|≥1.96；20 根左右约 2.1；16 根约 2.13 |
| 效率比 ER | Kaufman KAMA | 净位移/总路径，0~1 | >0.6 强趋势，0.3~0.6 过渡，<0.3 震荡 |
| 震荡指数 CHOP | Dreiss、TA-Lib `CHOP` | 0~100 | >61.8 震荡，<38.2 趋势 |
| ADX | Wilder | 0~100 | 20~25 以上算有趋势，但无方向、滞后 |
| 趋势扫描 | López de Prado / MlFinLab | 多窗口取最大 \|t\| | 多用于给样本打标签 |
| 图表角度 | pandas-ta 的 `degrees` 选项 | 依赖图表 X/Y 缩放 | 不建议做程序化阈值 |

### 9.2 对照结论

1. **估计器没问题**：全窗最小二乘回归与 TA-Lib 同源，比首尾两点稳；EMA 斜率比价格斜率更平滑但更滞后，可作为对照项。
2. **ATR 归一化适合期货跨品种**，但业界更常见的两种是「t 值」和「百分比/根」。建议保留 ATR 角度做主口径，另加 t 值做质量门，而不是二选一。
3. **R² 不用单独做**：一元回归里 t 值与 R² 单调等价（`t = r × √((n-2)/(1-r²))`），实现 t 值即可，R² 只做日志展示。
4. **只看角度不够**：ER 和 CHOP 直接度量「价格走得多有效率」，与斜率高低正交；把它们作为可选确认，比继续微调角度阈值更能减少震荡假信号。
5. **标定目标要改**：按分位数定阈值只能保证覆盖率，不能保证「选出的是趋势」。应以未来 20 根是否走出趋势为标签，看阈值对趋势/震荡的区分度（AUC、精确率），并严格按时间切分样本。
6. **多周期确认是成熟做法**：15 分钟入场用 60 分钟斜率同向，通常比单周期调参更稳；建议做成可选开关。
7. **角度只用于展示**：文档里的「3°、5°」本质是 ATR 倍数的换算，内部应存 `ATR/根`，避免被图表缩放误导。

### 9.3 改进优先级

**P0（先做，直接影响可信度）**

- 增加斜率 t 值：20 根窗口用 t 分布临界值（约 2.09），不要用大样本的 1.96。53.1.0 已接入 `ema_swing`（`slope_min_t`，默认 0 关闭），与角度并存，开启与否留给 A/B。
- 标定改为「未来趋势标签 + 时间切分 + 样本外」，`q80` 只作为初始值，不作为验收标准。

**P1（提高稳健性）**

- 加一个正交确认：ER > 0.3 或 CHOP < 61.8，二选一，默认关闭，先 A/B。
- 可选高周期斜率同向（15 分钟参考 60 分钟），默认关闭。

**P2（研究项）**

- Theil-Sen 稳健斜率、对数价格斜率，与现有 OLS 对照，确认端点敏感度。
- 价格回归斜率 vs EMA 回归斜率，确认滞后与噪声的取舍。

### 9.4 总体结论

现有体系方向正确，**不需要改用 ADX 或 ER 作为主判断**：ADX 没有方向且滞后，ER 没有方向，都无法替代「带符号的斜率」。需要补的是三件事：**t 值质量门、以未来趋势为目标的样本外标定、一个正交的趋势/震荡确认**。完成这三项后，再讨论是否把 `ema_swing` 的默认阈值从 3° 调到 5°。
