大级别箱体突破（日线为主、周线共振过滤）入场规则
核心原则：只做收盘价突破，拒绝盘中刺破；先确认箱体，再等突破，叠加动能过滤，减少假突破；箱体边界为开仓前已成型的历史区间，不包含未来K线，无未来函数
适用：国内期货主力合约（燃油、纯碱、玉米、螺纹等），长线趋势，持仓几周~数月，单笔风险控制1.5%以内
一、前置条件（先判断箱体合格，不满足直接放弃）
1. 箱体回看周期：默认40根日线K（最低20根，优先≥40）；周线过滤用8根以上周K
2. 箱体上下沿计算（仅用突破K线之前的历史K线）
  ○ 箱体上沿BoxHigh：区间内次高高点均值，剔除超长上影毛刺，不是简单单根最高
  ○ 箱体下沿BoxLow：区间内次低低点均值，剔除超长下影毛刺
  ○ 箱体高度 H = BoxHigh − BoxLow
3. 箱体硬性过滤（全部满足才算有效箱体）
  ○ H ≥ 1.2 × ATR(20)：过滤窄箱体，窄箱体假突破极多
  ○ 区间至少包含2个有效高点、2个有效低点，高点/低点不能过度集中
  ○ ADX(14)＞20（动能前置过滤，代表震荡在积蓄力量；ADX＜20走平直接放弃本次突破信号）
4. 附加时间风控过滤（满足任意一条，即使突破也不开仓）
  ○ 长假前3个交易日不新开仓
  ○ 合约临近换月、流动性萎缩，不做
  ○ 重大政策/数据公告窗口期避开
二、多头入场（向上突破箱体）
✅ 全部条件同时满足，才触发多头开仓：
1. 日线收盘价 ＞ BoxHigh（收盘价突破是核心，盘中刺破、收盘跌回箱内不算突破）
2. 【可选强过滤，提高盈亏比、减少信号】周线收盘价同样站上对应箱体上沿（大小周期共振）
3. 动能二选一过滤：
  ○ 方案1（量能）：突破K成交量 ＞ 箱体震荡阶段平均成交量 ×1.3，放量突破
  ○ 方案2（趋势）：ADX(14)＞20 且 ADX拐头向上
入场点位二选一：
① 保守：突破K的收盘价进场
② 稳健：下一交易日开盘价进场（规避收盘瞬间假突破、夜盘跳空）
多头初始止损同步设置：StopLong = BoxHigh − 0.5 × ATR(20)
三、空头入场（向下突破箱体）
✅ 全部条件同时满足，才触发空头开仓：
1. 日线收盘价 ＜ BoxLow
2. 【可选强过滤】周线收盘价同步跌破箱体下沿
3. 动能二选一过滤（和多头一致）：放量 / ADX＞20且拐头向下
入场点位二选一：突破K收盘价 / 次交易日开盘价
空头初始止损同步设置：StopShort = BoxLow + 0.5 × ATR(20)

2. 箱体形成时间不足20根日线、箱体高度不足1.2倍ATR → 放弃
3. ADX＜20，无趋势动能，价格小幅滑出箱体 → 放弃
4. 已经持仓同品种，不重复开同方向；加仓属于趋势中继次级箱体规则，不是本主入场规则
5. 不逆势开仓：多头趋势里，只做多突破，不做空；空头趋势只做空突破
