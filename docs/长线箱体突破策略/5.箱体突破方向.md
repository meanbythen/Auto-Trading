核心原则先讲清楚
箱体突破方向，不是预判，是价格收盘位置的客观判定；优先用【收盘价】，不用盘中刺破，和咱们整套策略、有效高低点规则保持一致，避免主观猜方向、被影线毛刺骗。
前提：箱体已经验证合格：窗口内≥2个有效高点、≥2个有效低点，箱体高度 ≥1.2×ATR，ADX>20。
箱体上沿 = 最高2个有效高点均值；箱体下沿 = 最低2个有效低点均值（固定）
一、标准判定规则（主规则，程序化用这个）
● ✅ 向上突破（做多方向）
当前K线 收盘价 > 箱体上沿
附加约定：盘中冲高刺破上沿、收盘又跌回箱体内部 → 不算向上突破，无效。
● ✅ 向下突破（做空方向）
当前K线 收盘价 < 箱体下沿
附加约定：盘中砸破下沿、收盘收回箱体里面 → 不算向下突破，无效。
中间地带：箱体下沿 ≤ 收盘价 ≤ 箱体上沿 → 仍然属于震荡，无突破方向，不交易
二、共振过滤（降低假突破，可选，你策略里的增强项）
日线收盘价突破是基础；想要更高质量信号，可以叠加大周期共振：
1. 日线收盘上破箱体上沿 + 周线收盘价也站上对应箱体上沿 → 多头共振突破
2. 日线收盘下破箱体下沿 + 周线收盘价也跌破对应箱体下沿 → 空头共振突破
代价：信号变少，很多趋势会错过；适合本金偏小、不想频繁试错。
三、成交量辅助确认（定性过滤，不单独作为判定依据）
只用来“确认力度”，不能单独用来判定方向：
● 向上突破：突破K成交量 > 箱体震荡期平均成交量（1.3倍以上），多头突破可信度更高；放量代表主动买盘
● 向下突破：突破K放量，代表主动卖盘涌出，空头可信度更高
● 缩量突破：信号保留，但优先级降低，可以选择直接放弃，或者缩小仓位试错
⚠️ 重点：放量只是加分项，不是必要条件。很多大趋势是缩量突破后再加速，完全砍掉缩量突破会丢趋势。
四、容易混淆的边界场景（实盘高频踩坑）
1. 同时碰上下沿？不可能，一根K收盘价只能在一个位置
2. 跳空直接突破
开盘直接跳在箱体上沿上方、收盘仍然在上方 → 有效向上突破；
开盘直接跳在箱体下沿下方、收盘留在下方 → 有效向下突破；
跳空突破是强信号，但跳空也会带来滑点、止损被跳开风险，仓位要保守。
3. 连续多根K线慢慢爬出去
不是一根K线直接突破，连续几根K收盘价逐步站上箱体上沿：第一根收盘站上的K，就是突破确认K，方向多头
4. K线收盘在箱体上沿/下沿线上
等于在边界上，不算突破，继续等待。
五、绝对禁止的判断方式（坑）
❌ 看盘中最高价刺破上沿就判定多头突破
❌ 看盘中最低价刺破下沿就判定空头突破
❌ 根据基本面、消息预判哪边会突破
❌ 箱体中间提前预判方向、提前挂单博弈突破（属于主观猜方向，脱离策略框架）
❌ 一根K先上破、再下破，来回切换方向（收盘价为准，一根K只能有一个结果）
六、时序逻辑（和前面规则串起来）
1. 滑动窗口 → 提取有效高低点 → 生成箱体上下沿
2. 每根K收盘后校验：
  ○ 收盘 > 上沿 → 方向=多头，触发多头开仓条件
  ○ 收盘 < 下沿 → 方向=空头，触发空头开仓条件
  ○ 在区间内 → 无突破方向，等待下一根K
3. 一旦确认突破、开仓：箱体边界固定不变，后面新的高低点不修改这个箱体，出场规则沿用之前的。
七、伪代码片段（直接接入vnpy）
box_high, box_low = get_valid_box() # 前面有效高低点函数
close = bar.close

direction = 0 # 0=无突破，1=向上，-1=向下
if close > box_high:
    direction = 1
elif close < box_low:
    direction = -1
else:
    direction = 0

八、补充：中继箱体的突破方向约束（非常关键）
趋势走出来之后形成次级中继箱体：
● 原有大趋势是多头 → 中继箱体只认向上突破，向下突破直接忽略，不做空
● 原有大趋势是空头 → 中继箱体只认向下突破，向上突破直接忽略，不做多
这就是顺势过滤，避免中继箱体反向突破来回挨打。
