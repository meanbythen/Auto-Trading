如何确定箱体的有效高点和有效低点
核心一句话
有效高/低点，是震荡区间内，能代表区间压力、支撑，剔除毛刺长影线之后的拐点；不是简单取这段K线的最高、最低。
适用：咱们这套大级别箱体突破策略（日线为主，箱体回看20~40根K线）；目标：减少上影/下影毛刺把箱体画得过大，导致突破信号滞后、止损过宽。
重要约束：计算箱体高低点，只能用【开仓bar之前的历史K线】，不能包含当前K线，杜绝未来函数
下面分：定义、筛选规则、3种实操方案（从简单到严谨，推荐方案2用于vnpy编码）、代码要点、避坑。
前置前提
选定一段候选震荡窗口：N根K线（比如40根日线），窗口边界固定，在窗口内找有效高低点。
箱体：至少2个有效高点、2个有效低点，只有1高1低的区间不算合格箱体。
毛刺定义：单根K线的长影线，刺破区间，但收盘价迅速回到区间内部，没有持续停留。也就是“穿刺但站不住”。

方案1：肉眼人工版（复盘用，不适合程序化）
适合你手动复盘理解逻辑：
1. 在窗口里，找出价格反弹到这里就掉头向下的拐点（有效高点）；
2. 找出下跌到这里就反弹向上的拐点（有效低点）；
3. 剔除：
  ○ 只一根K线刺出去、后面K线立刻收回的长上影/长下影；
  ○ 单日消息冲击的跳空尖点（孤立单K尖峰/尖底）；
4. 取2个最强有效高点求平均，作为箱体上沿；2个最强有效低点求平均，作为箱体下沿。
缺点：主观，没法写成代码。

方案2：拐点识别法（推荐！适合vnpy程序化，适配咱们箱体策略）
用局部极值（拐点）识别，也是CTA箱体策略最主流写法：
参数：拐点回看 lookback_peak = 2（一根高点，左右各2根K线都低于它，才算有效高点；低点同理）
含义：
✅ 有效高点（局部峰值）：
high[i] > high[i-1]
high[i] > high[i-2]
high[i] > high[i+1]
high[i] > high[i+2]
也就是：这根K线高点，前后2根K线高点都比它低 → 这是一个折返拐点，不是毛刺。
✅ 有效低点（局部谷值）：
low[i] < low[i-1]
low[i] < low[i-2]
low[i] < low[i+1]
low[i] < low[i+2]
这根K线低点，前后2根K线低点都比它高。
箱体上沿 & 下沿取值规则（二选一，固定不要来回换）
A（保守，信号少，假突破少）：取窗口内所有有效高点里的最大值，有效低点里最小值
B（均衡，我推荐给你这套策略）：取出窗口内最高的2个有效高点取均值；最低的2个有效低点取均值
为什么取2个均值？
避免单一孤峰毛刺拉高箱体上沿，止损被动放很大；同时保留区间真实压力支撑。
过滤规则（必须加）
1. 两个有效高点之间，间隔至少≥5根K线；紧挨着的拐点不算，属于小波动；
2. 两个有效低点之间间隔≥5根K线；
3. 窗口内有效高点数量≥2，有效低点数量≥2，这个箱体才算合格；不够直接放弃该窗口，不生成信号。
示例：40根K线窗口，筛选出3个有效高点，取最高2个平均 = 箱体上沿；3个有效低点，取最低2个平均 = 箱体下沿。

方案3：基于收盘价箱体（极简替代，适合新手回测）
不看影线，只用收盘价计算高低：
箱体上沿 = 窗口内最高收盘价
箱体下沿 = 窗口内最低收盘价
✅ 优点：代码最简单，无歧义；
❌ 缺点：完全忽略影线信息，容易把真实支撑压力漏掉，假突破会变多。
适用场景：只适合流动性极好的品种（玉米、燃油），不推荐纯碱这种波动大影线多的。

补充：成交量增强筛选（进阶，VA成交量分布搭配）
如果你后面叠加成交量分布VA：
在已经筛选出来的拐点里，优先选拐点位置伴随成交量放大的高/低点；
孤立尖点、成交量很低的拐点，直接剔除，认定为无效毛刺。
逻辑：真正的压力支撑，往往在拐点有换手；无量穿刺大多是诱多诱空。

【重点避坑】写代码最容易犯的3个错误
1. ❌ 遍历窗口时，i+1、i+2取到未来K线
解决：拐点识别只在 [0, N-3] 位置计算，保证后面有2根历史K线，绝对不能引用未发生K线。
2. ❌ 箱体窗口动态滑动、不断重算高低点
解决：一旦突破信号触发、开仓，这一组有效高低点永久固定，后面行情再出新高低，不修改当前持仓的箱体边界（和前面出场规则匹配）。
3. ❌ 拐点参数乱调：lookback_peak设太大（比如5），拐点太少，很久没有箱体；太小（1），拐点爆炸，全是噪声。
日线推荐固定 lookback_peak=2；周线可以调到3。

极简伪代码片段（可以直接替换进vnpy）
# lookback_window = 40 箱体总窗口
# peak_look = 2 拐点左右验证K线数量
highs = []
lows = []
for i in range(peak_look, len(am.high)-peak_look):
    h = am.high[i]
    # 判断高点拐点
    is_peak = True
    for j in range(1, peak_look+1):
        if am.high[i] <= am.high[i-j] or am.high[i] <= am.high[i+j]:
            is_peak = False
            break
    if is_peak:
        highs.append(h)

    l = am.low[i]
    is_valley = True
    for j in range(1, peak_look+1):
        if am.low[i] >= am.low[i-j] or am.low[i] >= am.low[i+j]:
            is_valley = False
            break
    if is_valley:
        lows.append(l)

# 至少2个有效高点、低点
if len(highs)>=2 and len(lows)>=2:
    highs_sorted = sorted(highs, reverse=True)
    box_high = (highs_sorted[0] + highs_sorted[1]) / 2
    lows_sorted = sorted(lows)
    box_low = (lows_sorted[0] + lows_sorted[1]) / 2
else:
    # 箱体不合格，跳过
    box_high = None
    box_low = None

和你整套策略串起来总结
1. 滑动窗口（40根日线）→ 用左右2根K线验证拐点，提取有效高点、低点；
2. 检查：≥2有效高、≥2有效低，高低点间隔≥5根K线；
3. 取最高2高均值、最低2低均值作为箱体上下沿；
4. 再校验箱体高度 ≥ 1.2*ATR，ADX>20；
5. 满足后，等待收盘价突破；开仓后，这组box_high/box_low永久固定，用于初始止损、箱体失效离场判断。
