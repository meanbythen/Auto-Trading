大级别箱体突破策略出场规则（原版体系，分4类出场，优先级从高到低）
前提：这是长线趋势策略，核心原则：没到触发条件，绝不主动止盈；不设固定目标价，靠跟踪止损让利润奔跑
区分：初始止损（保命）、跟踪止盈（趋势持有）、失效离场（重回震荡）、强制离场（风控/时间）
一、初始止损出场（开仓同步挂好，最高优先级）
作用：过滤假突破，突破失败立刻离场，单笔亏损封顶
● 多头：止损价 = 箱体上沿 − 0.5×20日ATR
触发：价格收盘跌破该止损价（保守版；也可以选盘中跌破，看你风格）→ 平仓离场
● 空头：止损价 = 箱体下沿 + 0.5×20日ATR
触发：价格收盘站上该止损价 → 平仓离场
✅ 重点：在盈利还没达到1倍箱体高度 H 之前，止损线固定不动，不移动、不提前推到成本
目的：避免趋势正常回撤被扫出局。
二、跟踪止盈出场（趋势持有阶段，本策略核心出场）
触发启动跟踪的门槛
持仓盈利 ≥ 1倍箱体高度 H（H=箱体上沿−箱体下沿），才启动跟踪止损
盈利不足1H时，一直拿着初始止损不动，不开启跟踪。
● 多头跟踪规则：
启动后，跟踪线 = 近期最高点 − 2×20日ATR
每次创出新高，跟踪线跟随上移；不创新高，跟踪线不动。
出场：价格触碰/收盘跌破跟踪线 → 全部平仓
● 空头跟踪规则：
启动后，跟踪线 = 近期最低点 + 2×20日ATR
每次创出新低，跟踪线跟随下移；不创新低，跟踪线不动。
出场：价格触碰/收盘站上跟踪线 → 全部平仓
进阶可选（超级大趋势）：趋势走得很流畅后，可以把ATR倍数放大到2.2~2.5，给行情更大回撤空间，减少被正常回撤洗出去。
❗ 是全部平仓，本基础版本不做减仓；想要分批止盈可以单独加规则。
三、箱体失效离场（震荡回归出场，独立条件）
不管有没有盈利、跟踪止损有没有触发，只要价格重新回到箱体内部，直接平仓离场。
● 多头持仓：价格收盘 ≤ 箱体上沿 → 重回震荡区间，突破逻辑失效，离场
● 空头持仓：价格收盘 ≥ 箱体下沿 → 重回震荡区间，突破逻辑失效，离场
逻辑：箱体突破策略的底层假设是“突破后走出趋势”；一旦价格跌回箱体，说明突破失败、行情重新进入震荡，策略基础不存在，不要继续扛单。
注意：这条和初始止损是两套东西，位置不一样，不要混淆。
四、附加强制离场（风控/特殊场景，兜底）
满足下面任意一条，无条件平仓，和行情无关：
1. 长假前最后一个交易日收盘前平仓（规避隔夜大跳空风险，可选）
2. 单笔浮亏已经触及预先设置的资金硬上限（总资金1.5%），立刻离场
3. 持仓超过最大持有周期（可选附加：日线级别最长持有60根K线，防止行情长期横盘耗着）

出场流程时序（方便你写代码）
1. 刚开仓 → 固定初始止损，不跟踪，不主动止盈
2. 持仓浮盈 < 1H → 只监控初始止损 + 箱体失效条件
3. 持仓浮盈 ≥ 1H → 启动ATR跟踪止损，同时继续监控箱体失效
4. 任意一条出场条件触发 → 平仓，本次交易结束，等待下一次箱体信号
容易踩坑的细节（实盘&回测重点）
1. 箱体边界是开仓那一刻的历史箱体，箱体不会随新K线动态重算！一旦开仓，箱体上下沿固定不变，这是很多人写代码出未来函数的地方
2. 推荐优先用收盘价判断出场，盘中毛刺不处理，减少震荡来回扫；追求更灵敏可以改成盘中触发，但假信号会变多
3. 跟踪止损只朝盈利方向移动，绝对不能反向移动（多头跟踪线只能上移、不能下移）
4. 出场后，需要等新的箱体形成，不能立刻反手
可选增强版本（两个常用变体）
变体A：分批出场
● 浮盈1H：平一半仓位，剩余仓位继续用2ATR跟踪
● 浮盈2H：剩余仓位改成2.5ATR跟踪，博取超大行情
变体B：ADX辅助离场
趋势衰减过滤：ADX从高位拐头向下、跌破20，提前平仓，避免趋势末期大幅回撤
