大级别箱体突破策略｜完整实战示例（日线级别，纯碱SA，适配我们前面整套规则）
回顾前置规则统一口径：
1. 箱体窗口：40根日线；拐点验证：左右各2根K才算有效高低点
2. 箱体上沿=最高2个有效高点均值；箱体下沿=最低2个有效低点均值
3. 突破判定：收盘价突破；单笔风险固定总资金1.5%；3万本金，单笔最大允许亏损450元
4. 出场：盈利＜1倍箱体高度H → 固定初始止损；盈利≥1H启动2×ATR跟踪止盈；价格重回箱体内部直接离场
5. 合约：纯碱SA，合约乘数20吨/手
第一步：形成合格箱体（40根日线震荡窗口）
经过拐点扫描，40根K内识别出：
有效高点：2142、2130（两个满足左右2根K更低的拐点）
有效低点：1940、1948（两个满足左右2根K更高的拐点）
箱体上沿 BoxHigh = (2142 + 2130) ÷ 2 = 2136
箱体下沿 BoxLow = (1940 + 1948) ÷ 2 = 1944
箱体高度 H = 2136 − 1944 = 192
校验箱体合格条件：
● 20日ATR = 145
● 1.2 × ATR = 174
● H=192＞174 ✔️ 箱体高度达标
● ADX(14)=24＞20 ✔️ 有趋势动能
● 有效高点≥2、有效低点≥2 ✔️
👉 箱体合格，等待突破
第二步：向上突破，确认方向、开仓
后续一根日线收盘价格：2145
判断：收盘价2145 ＞ BoxHigh 2136 → 向上突破，多头信号
盘中曾经冲高回落、长上影刺破2136但收盘回落的K，不算突破；这根是收盘站稳，有效突破
计算初始止损
ATR=145
多头初始止损 = BoxHigh − 0.5×ATR = 2136 − 0.5×145 = 2063.5
入场价：2145
每手风险金额 =（入场价 − 止损价）× 合约乘数
= (2145 − 2063.5) × 20 = 81.5 × 20 = 1630 元/手
⚠️ 我们单笔最多只能亏450元
450 ÷ 1630 ≈ 0.276 → 只能开 0手
说明：这个位置止损空间太大，超出单笔风险上限，放弃本次开仓

换一个信号示例（风险合适，可以开仓，继续往下看）
同样箱体 BoxHigh=2136，BoxLow=1944，H=192，ATR=145
另一根突破K收盘：2140（>2136，多头突破）
止损价依然：2063.5
入场价=2140
每手风险 = (2140 − 2063.5) ×20 = 76.5 ×20 = 1530，依然大于450，还是不能开。
👉 换一个波动更小的品种：玉米C，乘数10，演示一笔能正常开仓的案例
正式可交易完整示例：玉米C 日线箱体突破（3万本金，单笔风险1.5%=450元）
1. 箱体扫描40根日线
有效高点：2820、2816
有效低点：2722、2726
BoxHigh = (2820+2816)/2 = 2818
BoxLow = (2722+2726)/2 = 2724
H = 2818 − 2724 = 94
ATR(20)=70
1.2×ATR=84，H=94＞84 ✔️
ADX=23＞20 ✔️
2. 突破信号：日线收盘 2825 ＞ 2818 → 多头突破
入场价 = 2825
初始止损价 = BoxHigh − 0.5×ATR = 2818 − 0.5×70 = 2783
每手风险 = (2825 − 2783) × 10 = 42 × 10 = 420元/手
单笔允许最大亏损450元
420＜450 ✔️ → 开仓 1手玉米多单
本次交易：风险420元，占总资金1.4%，符合1.5%上限要求
第三步：持仓阶段，分阶段监控出场条件
H=94，启动跟踪止盈门槛：浮盈 ≥ 94点
入场价2825，浮盈门槛价 = 2825 + 94 = 2919
阶段A：价格 2825 ~ 2918（浮盈不足1H）
✅ 规则：不启动跟踪止损，止损固定2783不动
监控两个离场条件：
1. 收盘价 ≤ 2783 → 初始止损离场
2. 收盘价 ≤ 2818（跌回箱体上沿以内）→ 箱体失效，直接离场
情景举例：
行情回调到2800，收盘仍然＞2783、＞2818 → 继续持有，不动止损。
行情一根阴线收盘2815（＜2818）→ 重回箱体，直接平仓离场，不管盈亏。
阶段B：价格上涨，收盘站上2919（浮盈≥1H，启动跟踪止盈）
跟踪参数：2×ATR = 2×70 = 140
跟踪线规则：多头跟踪线 = 近期新高 − 140
跟踪线只上移，不下移
举例行情演进：
1. 新高2940 → 跟踪止损 = 2940 − 140 = 2800
2. 后续再创新高2965 → 跟踪止损 = 2965 − 140 = 2825
3. 之后不再创新高，跟踪线固定在2825
4. 某日收盘 2819 ＜ 2825 → 触碰跟踪止损，全部平仓离场
此时离场，这笔交易盈利：2825入场，2819离场？不对，新高是2965，跟踪线抬到2825，意味着回撤到2825才离场，相当于保本附近出局，是趋势末期回撤洗出。
情景C：大趋势延续，持续创新高
新高3020 → 跟踪止损=3020−140=2880
后续只要不收盘跌破2880，就一直拿住。
第四步：空头突破示例（同品种玉米）
同一个箱体 BoxHigh=2818，BoxLow=2724，H=94，ATR=70
日线收盘 2715 ＜ 2724 → 空头突破
入场价=2715
空头初始止损 = BoxLow + 0.5×ATR = 2724 + 35 = 2759
每手风险 = (2759 − 2715) × 10 = 44 × 10 = 440元
440＜450，开1手空单
启动跟踪门槛：浮盈≥94点，目标价 2715−94=2621
浮盈不足2621：止损固定2759，同时监控：收盘价≥2724（重回箱体）→离场
价格跌破2621之后，跟踪线=近期低点+140，只向下移动，收盘站上跟踪线则平仓。
第五步：一笔失败交易（假突破演示）
玉米箱体同上，收盘2822>2818，多头突破，入场2822，止损2783
开仓后下一根K线收盘2810，2810＜2818（箱体上沿）
👉 触发箱体失效规则，立刻平仓，这笔是假突破，亏损：(2822−2810)×10=120元，小于预设风险上限。
第六步：汇总这笔玉米多头完整交易台账
● 品种：玉米C，日线
● 箱体：[2724，2818]，H=94
● 信号：收盘价突破上沿2818，入场2825，1手多
● 初始止损：2783
● 跟踪启动阈值：2919
● 跟踪止损：2×ATR=140
● 结果路径1（假突破）：收盘2815 → 重回箱体，平仓离场
● 结果路径2（小幅回撤扫初始止损）：收盘2780 → 止损离场，亏损420元
● 结果路径3（走趋势）：涨到2965，跟踪线上移至2825，后续回撤触碰2825平仓
● 结果路径4（大趋势）：持续新高，跟踪止损不断抬升，吃大波段
关键要点（对应前面所有规则）
1. 箱体边界一旦开仓就固定：2724/2818不会随后面K线重算，无未来函数
2. 所有判断都是收盘价，盘中毛刺不处理
3. 两个离场条件并行：箱体失效、止损（初始/跟踪），哪个先触发哪个执行
4. 仓位严格由单笔1.5%风险约束，波动大的品种（纯碱）经常出现“有信号但是不能开仓”，这是正常风控，不是策略缺陷
5. 中继箱体：后续上涨途中再形成小箱体，只做向上突破，忽略向下突破
