每日收盘后（15:00之后）固定流程：
1. 拉取该品种最近40根日线K线
2. 算法识别有效高低点（拐点左右各2根K验证）
3. 统计有效高点、低点数量：≥2高+≥2低才是候选箱体
4. 计算BoxHigh、BoxLow、箱体高度H、20日ATR、ADX(14)
5. 校验过滤条件：

✅ 全部满足 → 标记为【观察箱体】，记录箱体上下沿、ATR、H，写入备忘录/策略变量；
❌ 任意一条不满足 → 无观察信号，跳过，等下一个交易日收盘重新扫描。
重点：标记箱体之后，箱体边界固定，直到突破发生；后续新K线只用来判断是否突破，不重新计算箱体

三、第三步：信号确认 + 开仓前仓位验算（实盘最容易踩坑）
次日，只有两种情况触发开仓：
1. 前一日收盘，收盘价＞BoxHigh → 多头突破信号
2. 前一日收盘，收盘价＜BoxLow → 空头突破信号
拿到信号，不要直接下单，先算风险和手数
公式回顾：
单笔最大允许亏损 = 总资金 × 1.5%
多头止损价 = BoxHigh − 0.5×ATR
空头止损价 = BoxLow + 0.5×ATR
每手风险 = |入场价 − 止损价| × 合约乘数
可开手数 = 单笔允许亏损 ÷ 每手风险
实盘铁律：
1. 算出来手数＜1 → 放弃本次信号，不强行开仓（波动大的纯碱经常出现这个情况，是风控保护，不是错过机会）
2. 单一品种保证金占用不超过总资金20%；全部品种合计保证金尽量≤40%，预留回撤缓冲
3. 跳空开盘的突破：
  ○ 跳空直接突破箱体，收盘仍然在箱体外侧 → 有效信号
  ○ 但是跳空会造成止损滑点，手数再打8折，防范跳空击穿止损，亏损放大
4. 开仓时机：优先次日开盘成交；不追高，不埋单在箱体边界博弈刺破

四、第四步：持仓阶段监控规则（固定两套离场条件并行）
开仓那一刻，这一组BoxHigh/BoxLow永久锁定，不再变动
分两个持仓阶段：
阶段1：浮盈＜1倍箱体高度H
● 止损线：固定初始止损，绝不提前移动到成本线
● 同时监控：价格收盘重回箱体内部（多头收盘≤BoxHigh；空头收盘≥BoxLow）→ 直接平仓离场（箱体失效）
● 只看收盘，盘中影线来回刺，忽略
阶段2：浮盈≥1倍H，启动2×ATR跟踪止损
● 多头跟踪线 = 近期新高 − 2×ATR，只上移、不下移
● 空头跟踪线 = 近期新低 + 2×ATR，只下移、不上移
● 离场触发：收盘价触碰跟踪线，全部平仓
● 仍然保留箱体失效兜底条件：一旦价格回到箱体内部，无条件离场
实盘提醒：不要盘中看到回撤就手动平；策略是日线级别，以日线收盘判定，过滤日内杂波。
如果你想更灵敏：可以改成盘中触发离场，但假信号、来回扫损会显著增加，要提前接受。
五、第五步：离场执行（分4类离场场景，严格按优先级）
优先级从高到低：
1. 跳空直接越过止损：无法按预设止损成交，成交后立刻停止这笔交易，记录实际亏损，不再补仓
2. 收盘触发初始止损 / 跟踪止损 → 平仓
3. 收盘价格回到箱体内部（突破逻辑失效）→ 平仓
4. 兜底强制离场：长假前、持仓超过60根日线仍没有大行情，主动平仓（可选规则）
✅ 离场之后：这笔交易对应的箱体作废，不能反手；等待新的合格箱体重新生成，再找下一个信号
禁止：刚被止损，立刻反向开仓博弈反转，这是趋势策略大忌。
