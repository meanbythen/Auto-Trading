⚠️ 重要前置声明
1. 下面代码全部基于 vnpy 2.x / vnpy_ctastrategy 规范编写，可直接放入 vnpy_ctastrategy/strategies/ 目录加载，适配国内 CTP 商品期货；
2. 不保证实盘盈利，开源仅为逻辑复刻；回测必须填入真实手续费、滑点、跳空、涨跌停限制；
3. 日内策略务必设置收盘强平，防止隔夜持仓；
4. 3w本金小资金：严格控制单品种最大仓位，ATR仓位只是仓位分配工具，不是保本工具；
5. ADX 用来过滤震荡：ADX < 阈值，禁止开新仓，只持有原有持仓或者直接不交易。

## 与本程序内置策略的对应关系

本程序不加载下面的 vnpy Python 代码，而是用 `config/rules/*.yaml`（规则 DSL）复刻同样的逻辑。内置 5 套里，前 4 套与本文一一对应，第 5 套是语法模板兼等价基线：

| 编辑器内置规则（下拉带 `[内置]`） | 对应本文 | vnpy 类名 | 规则文件 |
| --- | --- | --- | --- |
| DualThrust 日内突破 | 第 1 套 | `DualThrustStrategy` | `config/rules/dualthrust.yaml` |
| R-Breaker 六档 | 第 2 套 | `RBreakerStrategy` | `config/rules/r_breaker.yaml` |
| 海龟唐奇安+ADX | 第 3 套 | `TurtleAdxStrategy` | `config/rules/turtle_adx.yaml` |
| ADX+ATR 波动率突破 | 第 4 套 | `AdxAtrBreakStrategy` | `config/rules/adx_atr_break.yaml` |
| 双均线 20/60（`dual_ma_equiv`） | 不在本文 | 对应程序原有 `dual_ma` 引擎 | `config/rules/dual_ma_equiv.yaml` |

第 5 套的两个用途：一是「新建」规则时套用的语法模板（文件头有完整语法速查）；二是迁移等价基线——用 DSL 写出与原 `dual_ma` 引擎逻辑一致的规则，再逐字段对比回测输出，证明 DSL 与老引擎一致。

### 复刻口径与 vnpy 原版的差异

每份 YAML 头部都写了「和原版的差异」，汇总如下：

| 项目 | vnpy 原版 | 本程序 DSL 版 |
| --- | --- | --- |
| 触发方式 | 收盘算出档位，挂停止单，盘中触及即成交 | 收盘确认突破，由回测/实盘引擎成交（回测按下一根开盘） |
| 档位取值 | 当根数据直接算 | 用 `{prev: 档位, n: 1}`，避免当根自己把窗口撑大 |
| 仓位 | 策略里按 `atr_risk` 自己算手数 | 手数沿用配置页「每笔风险%」，文件里 `sizing: inherit` |
| 止损 | 每根刷新 `low/high ± ATR` | `exit` 用上一根守卫价近似，另加 2ATR 固定止损兜底 |
| 14:55 强平 | 策略内判断时间平仓 | 由 `config.yaml` 的 `strategy.flatten_times` 负责 |
| R-Breaker 反转 | 4 张停止单同挂，靠触碰先后区分 | 收盘口径分不清先后，改为「收在 r1~r3 区间做空、s1~s3 区间做多」 |

### 本文提到但 DSL 版未实现

涨跌停过滤、流动性过滤、夜盘品种的夜盘平仓时间、与 tqsdk 原版完全一致的 ADX 算法。前两项属于引擎层能力，后两项属于不同实现口径，规则文件无法覆盖；日内收盘强平请确认 `config.yaml` 的 `strategy.flatten_times` 已设置。

1. DualThrust 日内策略（vnpy版，国内商品，燃油/纯碱适用）
"""
DualThrust 日内突破策略
适合：燃油、纯碱等波动商品，日内，收盘强制平仓
"""
from vnpy_ctastrategy import (
    CtaTemplate,
    StopOrder,
    TickData,
    BarData,
    TradeData,
    OrderData,
    BarGenerator,
    ArrayManager,
)


class DualThrustStrategy(CtaTemplate):
    author = "DualThrust"

    # 参数
    k1 = 0.7
    k2 = 0.7
    n_window = 20
    atr_length = 20
    atr_risk = 0.01  # 账户风险比例
    intra_day_close = True  # 收盘强平
    close_hour = 14
    close_minute = 55

    # 变量
    up_bound = 0.0
    dn_bound = 0.0
    atr_value = 0.0
    long_stop = 0.0
    short_stop = 0.0

    parameters = ["k1", "k2", "n_window", "atr_length", "atr_risk", "intra_day_close"]
    variables = ["up_bound", "dn_bound", "atr_value"]

    def __init__(self, cta_engine, strategy_name, vt_symbol, setting):
        super().__init__(cta_engine, strategy_name, vt_symbol, setting)
        self.bg = BarGenerator(self.on_bar)
        self.am = ArrayManager(max(self.n_window, self.atr_length) + 10)

    def on_init(self):
        self.write_log("策略初始化")
        self.load_bar(10)

    def on_start(self):
        self.write_log("策略启动")

    def on_stop(self):
        self.write_log("策略停止")

    def on_tick(self, tick: TickData):
        self.bg.update_tick(tick)

    def on_bar(self, bar: BarData):
        self.cancel_all()
        self.am.update_bar(bar)
        if not self.am.inited:
            return

        # 收盘强平逻辑
        if self.intra_day_close:
            if bar.hour == self.close_hour and bar.minute >= self.close_minute:
                if self.pos > 0:
                    self.sell(bar.close - 1, abs(self.pos))
                elif self.pos < 0:
                    self.cover(bar.close + 1, abs(self.pos))
                return

        # DualThrust 区间计算
        hh = self.am.high[-self.n_window:].max()
        ll = self.am.low[-self.n_window:].min()
        hc = self.am.close[-self.n_window:].max()
        lc = self.am.close[-self.n_window:].min()
        range_high = max(hh - lc, hc - ll)
        self.up_bound = bar.open + self.k1 * range_high
        self.dn_bound = bar.open - self.k2 * range_high

        self.atr_value = self.am.atr(self.atr_length)
        if self.atr_value <= 0:
            return

        # ATR动态仓位
        capital = self.cta_engine.capital
        risk_amount = capital * self.atr_risk
        vol = int(risk_amount / (self.atr_value * self.am.underlying_symbol.size))
        vol = max(1, vol)

        if self.pos == 0:
            self.buy(self.up_bound, vol, stop=True)
            self.short(self.dn_bound, vol, stop=True)
        elif self.pos > 0:
            self.long_stop = self.am.low[-1] - self.atr_value
            self.sell(self.long_stop, abs(self.pos), stop=True)
        elif self.pos < 0:
            self.short_stop = self.am.high[-1] + self.atr_value
            self.cover(self.short_stop, abs(self.pos), stop=True)

        self.put_event()

    def on_order(self, order: OrderData):
        pass

    def on_trade(self, trade: TradeData):
        self.put_event()

    def on_stop_order(self, so: StopOrder):
        pass

2. R-Breaker 日内策略（vnpy移植版，趋势+反转，震荡友好）
"""
R-Breaker 日内策略
6个价格：S1/S2/S3 支撑；R1/R2/R3 压力
趋势突破 + 反转双逻辑
"""
from vnpy_ctastrategy import (
    CtaTemplate,
    StopOrder,
    TickData,
    BarData,
    TradeData,
    OrderData,
    BarGenerator,
    ArrayManager,
)


class RBreakerStrategy(CtaTemplate):
    author = "R-Breaker"

    # 参数
    n = 20
    k1 = 0.35
    k2 = 0.07
    k3 = 0.25
    atr_length = 20
    atr_risk = 0.01
    intra_day_close = True
    close_hour = 14
    close_minute = 55

    # 变量
    r3 = 0.0
    r2 = 0.0
    r1 = 0.0
    s1 = 0.0
    s2 = 0.0
    s3 = 0.0
    atr_value = 0.0

    parameters = ["n", "k1", "k2", "k3", "atr_length", "atr_risk"]
    variables = ["r3", "r2", "r1", "s1", "s2", "s3"]

    def __init__(self, cta_engine, strategy_name, vt_symbol, setting):
        super().__init__(cta_engine, strategy_name, vt_symbol, setting)
        self.bg = BarGenerator(self.on_bar)
        self.am = ArrayManager(self.n + 10)

    def on_init(self):
        self.write_log("R-Breaker初始化")
        self.load_bar(10)

    def on_start(self):
        pass

    def on_stop(self):
        pass

    def on_tick(self, tick: TickData):
        self.bg.update_tick(tick)

    def on_bar(self, bar: BarData):
        self.cancel_all()
        self.am.update_bar(bar)
        if not self.am.inited:
            return

        # 收盘强平
        if self.intra_day_close:
            if bar.hour == self.close_hour and bar.minute >= self.close_minute:
                if self.pos > 0:
                    self.sell(bar.close - 1, abs(self.pos))
                elif self.pos < 0:
                    self.cover(bar.close + 1, abs(self.pos))
                return

        hh = self.am.high[-self.n_window:]
        ll = self.am.low[-self.n_window:]
        cc = self.am.close[-self.n_window:]
        h = hh.max()
        l = ll.min()
        c = cc[-1]

        # R-Breaker 六档价格公式
        self.r3 = h + k1 * (c - l)
        self.r2 = h - k2 * (h - l)
        self.r1 = c + k3 * (h - l)
        self.s1 = c - k3 * (h - l)
        self.s2 = l + k2 * (h - l)
        self.s3 = l - k1 * (h - l)

        self.atr_value = self.am.atr(self.atr_length)
        if self.atr_value <= 0:
            return
        capital = self.cta_engine.capital
        risk_amount = capital * self.atr_risk
        vol = int(risk_amount / (self.atr_value * self.am.underlying_symbol.size))
        vol = max(1, vol)

        if self.pos == 0:
            # 趋势突破
            self.buy(self.r3, vol, stop=True)
            self.short(self.s3, vol, stop=True)
            # 反转
            self.short(self.r1, vol, stop=True)
            self.buy(self.s1, vol, stop=True)
        elif self.pos > 0:
            self.sell(self.s2, abs(self.pos), stop=True)
        elif self.pos < 0:
            self.cover(self.r2, abs(self.pos), stop=True)

        self.put_event()

    def on_order(self, order: OrderData):
        pass

    def on_trade(self, trade: TradeData):
        self.put_event()

    def on_stop_order(self, so: StopOrder):
        pass

3. 海龟唐奇安 + ATR仓位 + ADX震荡过滤（波段，适合玉米）
"""
海龟交易法则 唐奇安通道
增加 ADX 过滤：ADX < adx_threshold 禁止开仓
ATR动态仓位，波段策略，不强制日内平仓（可自选）
"""
from vnpy_ctastrategy import (
    CtaTemplate,
    StopOrder,
    TickData,
    BarData,
    TradeData,
    OrderData,
    BarGenerator,
    ArrayManager,
)


class TurtleAdxStrategy(CtaTemplate):
    author = "Turtle+ADX"

    # 参数
    entry_window = 20
    exit_window = 10
    atr_length = 20
    adx_length = 14
    adx_threshold = 25
    atr_risk = 0.01

    # 变量
    entry_high = 0.0
    entry_low = 0.0
    exit_high = 0.0
    exit_low = 0.0
    atr_value = 0.0
    adx_value = 0.0

    parameters = ["entry_window", "exit_window", "atr_length", "adx_length", "adx_threshold", "atr_risk"]
    variables = ["entry_high", "entry_low", "exit_high", "exit_low", "atr_value", "adx_value"]

    def __init__(self, cta_engine, strategy_name, vt_symbol, setting):
        super().__init__(cta_engine, strategy_name, vt_symbol, setting)
        self.bg = BarGenerator(self.on_bar)
        self.am = ArrayManager(max(entry_window, exit_window, atr_length, adx_length) + 10)

    def on_init(self):
        self.write_log("海龟ADX策略初始化")
        self.load_bar(20)

    def on_start(self):
        pass

    def on_stop(self):
        pass

    def on_tick(self, tick: TickData):
        self.bg.update_tick(tick)

    def on_bar(self, bar: BarData):
        self.cancel_all()
        self.am.update_bar(bar)
        if not self.am.inited:
            return

        self.entry_high = self.am.high[-self.entry_window:].max()
        self.entry_low = self.am.low[-self.entry_window:].min()
        self.exit_high = self.am.high[-self.exit_window:].max()
        self.exit_low = self.am.low[-self.exit_window:].min()
        self.atr_value = self.am.atr(self.atr_length)
        self.adx_value = self.am.adx(self.adx_length)

        if self.atr_value <= 0:
            return

        capital = self.cta_engine.capital
        risk_amount = capital * self.atr_risk
        vol = int(risk_amount / (self.atr_value * self.am.underlying_symbol.size))
        vol = max(1, vol)

        if self.pos == 0:
            # ADX过滤震荡，只有趋势才开仓
            if self.adx_value >= self.adx_threshold:
                self.buy(self.entry_high, vol, stop=True)
                self.short(self.entry_low, vol, stop=True)
        elif self.pos > 0:
            self.sell(self.exit_low, abs(self.pos), stop=True)
        elif self.pos < 0:
            self.cover(self.exit_high, abs(self.pos), stop=True)

        self.put_event()

    def on_order(self, order: OrderData):
        pass

    def on_trade(self, trade: TradeData):
        self.put_event()

    def on_stop_order(self, so: StopOrder):
        pass

4. ADX+ATR波动率突破策略（vnpy复刻tqsdk版本逻辑）
"""
ADX+ATR波动率突破
逻辑：ADX判断趋势强弱；当ADX>阈值，价格突破上轨/下轨开仓，ATR动态止盈止损
"""
from vnpy_ctastrategy import (
    CtaTemplate,
    StopOrder,
    TickData,
    BarData,
    TradeData,
    OrderData,
    BarGenerator,
    ArrayManager,
)


class AdxAtrBreakStrategy(CtaTemplate):
    author = "ADX+ATR Break"

    # 参数
    lookback = 20
    adx_length = 14
    adx_threshold = 22
    atr_length = 20
    atr_multiple = 1.5
    atr_risk = 0.01

    # 变量
    upper = 0.0
    lower = 0.0
    atr_value = 0.0
    adx_value = 0.0

    parameters = ["lookback", "adx_length", "adx_threshold", "atr_length", "atr_multiple", "atr_risk"]
    variables = ["upper", "lower", "atr_value", "adx_value"]

    def __init__(self, cta_engine, strategy_name, vt_symbol, setting):
        super().__init__(cta_engine, strategy_name, vt_symbol, setting)
        self.bg = BarGenerator(self.on_bar)
        self.am = ArrayManager(max(lookback, adx_length, atr_length)+10)

    def on_init(self):
        self.write_log("ADX+ATR波动率突破初始化")
        self.load_bar(10)

    def on_start(self):
        pass

    def on_stop(self):
        pass

    def on_tick(self, tick: TickData):
        self.bg.update_tick(tick)

    def on_bar(self, bar: BarData):
        self.cancel_all()
        self.am.update_bar(bar)
        if not self.am.inited:
            return

        self.atr_value = self.am.atr(self.atr_length)
        self.adx_value = self.am.adx(self.adx_length)
        mid = self.am.close[-self.lookback:].mean()
        self.upper = mid + self.atr_multiple * self.atr_value
        self.lower = mid - self.atr_multiple * self.atr_value

        if self.atr_value <= 0:
            return

        capital = self.cta_engine.capital
        risk_amount = capital * self.atr_risk
        vol = int(risk_amount / (self.atr_value * self.am.underlying_symbol.size))
        vol = max(1, vol)

        if self.pos == 0:
            if self.adx_value >= self.adx_threshold:
                self.buy(self.upper, vol, stop=True)
                self.short(self.lower, vol, stop=True)
        elif self.pos > 0:
            self.sell(self.am.close[-1] - self.atr_value, abs(self.pos), stop=True)
        elif self.pos < 0:
            self.cover(self.am.close[-1] + self.atr_value, abs(self.pos), stop=True)

        self.put_event()

    def on_order(self, order: OrderData):
        pass

    def on_trade(self, trade: TradeData):
        self.put_event()

    def on_stop_order(self, so: StopOrder):
        pass

使用说明 & 调参建议（适配你3w资金、燃油/纯碱/玉米）
1. 放置路径：vnpy_ctastrategy/strategies/xxx.py，重启vnpy，在CTA策略引擎里添加；
2. 回测配置：
  ○ 燃油、纯碱：用15min K线，DualThrust / R-Breaker（日内）
  ○ 玉米：30min / 60min，海龟ADX波段
3. 参数参考起点：
  ○ ADX阈值：22~28，数值越高越苛刻，过滤越多震荡，信号变少
  ○ atr_risk：0.005~0.01（3w本金建议先用0.005，单笔风险控制在150~300）
4. 缺陷提醒：
  ○ ArrayManager自带ADX计算有微小差异，和tqsdk原版不完全一致；如果要和tqsdk原版对齐，可以替换独立ADX函数；
  ○ 日内策略收盘强平时间，夜盘品种需要额外增加夜盘平仓时间；
  ○ 没有增加涨跌停过滤、流动性过滤，纯碱、燃油涨跌停容易无法成交，实盘必须叠加。
