# R10 成本与成交现实性

对应版本：49.17.0
上位文档：[阶段性验收报告-49.16.0.md](../阶段性验收报告-49.16.0.md) 第六节 R10、第八节

## 1. 目标

把「回测净盈亏」和「实盘能成交多少」拉到同一套现实假设上，四项各收口一次：

1. 在跑品种补齐手续费，零费率不再是默认。
2. 锁板、部分成交、挂单超时撤单进回测默认模型。
3. 收盘清仓 14:55 / 15:00 口径统一到品种与合约表。
4. 修正品种夜盘表（生猪、鸡蛋、苹果、集运指数等无夜盘；有色到 01:00；原油 02:30）。

不做：手续费从「按手固定」改成「按成交额比例」的费模型；断网/杀进程实机演练（R6 遗留）；两周 CTP 仿真。

## 2. 范围与判定

| 编号 | 问题 | 处置 |
|---|---|---|
| A1 | 8 个在跑品种里 7 个 `commission: 0`，回测净盈亏系统性偏高 | 按交易所标准补每手手续费；评审单零费率不能判「通过」 |
| B1 | 锁板、部分成交、挂单超时默认关闭，回测假设「一定成交、全额成交」 | 三项默认开启，写进结果快照与成交说明 |
| C1 | 回测按 14:55 清仓、实盘/对照按 15:00 口径，最后 5 分钟未对齐 | 清仓时刻只读品种与合约表；对照页显式标出清仓窗口 |
| D1 | 品种表把 `lh`、`jd`、`ap` 等无夜盘品种写成 21:00–23:00；`lu` 跟着原油算成 02:30；有色缺 01:00 | 修正出厂时段并回写总表；清仓时刻由时段推出 |
| E1 | 滑点「按时段」统计只按钟点粗分，22:00 的旧记录会算进夜盘，哪怕该品种没有夜盘 | 统计改为按品种与合约表的时段归类 |

## 3. 实现

### A1 手续费

`config/品种与合约.xlsx` 的 8 个在跑品种补齐开仓/平今手续费（每手，元）：

| 品种 | 开仓 | 平昨 | 平今 | 依据 |
|---|---|---|---|---|
| lh 生猪 | 24.0 | 同开仓 | 48.0 | 成交额万分之一，平今万分之二（按 15000 元/吨 × 16 折算） |
| jd 鸡蛋 | 5.25 | 同开仓 | 同开仓 | 成交额万分之一点五（按 3500 元/500kg × 10 折算） |
| SH 烧碱 | 7.5 | 同开仓 | 同开仓 | 成交额万分之一（按 2500 元/吨 × 30 折算） |
| FG 玻璃 | 6.0 | 同开仓 | 同开仓 | 6 元/手 |
| sp 纸浆 | 2.75 | 同开仓 | 同开仓 | 成交额万分之零点五（按 5500 元/吨 × 10 折算） |
| SR 白糖 | 3.0 | 同开仓 | 同开仓 | 3 元/手 |
| UR 尿素 | 5.0 | 同开仓 | 同开仓 | 5 元/手 |
| fu 燃油 | 2.63 | 2.63 | 0.0 | 保持原配置 |

价格型费率按近期典型价折算成每手固定值，**必须按期货公司结算单核对**。校验入口：
`src/risk/commission.py:zero_fee_products`，评审单「数据门禁」遇到零费率品种时状态降到「注意」并写明成本没扣。

### B1 成交模型

`src/backtest/liquidity.py` 默认值改为：

```python
block_limit_locked = True    # 一字板不成交，平仓顺延
max_volume_pct = 0.1         # 单根最多吃成交量 10%，余量当根撤单
entry_timeout_bars = 1       # 挂单最多等 1 根可成交K线，等到超时撤单
```

`src/backtest/engine.py`：

- 开仓前用 `wait_fill_index` 找第一根能成交的 K；等满 `entry_timeout_bars` 仍是一字板就记「超时撤单」。
- 锁板导致顺延时，成交价改用真正成交那根的开盘价，不再用原下一根开盘价。
- 成交量上限截断时记「部分成交 x/y 手，余量当根撤单」。
- 结果 `params_snapshot` 写 `liquidity` 三项；`fill_note` 追加一行成交约束说明。

配置键在 `backtest.liquidity`（`config.example.yaml` 已同步默认值）。要复现旧成绩可整组改成 `false` / `0`。

止损滑点本来就在默认模型里，本轮只核实不重写：`src/backtest/exit_policy.py:exit_fill_price` 先取 `min(止损, 开盘)`（多单）/`max(止损, 开盘)`（空单），再按方向让滑点；收盘确认型离场退回下一根开盘价，同样让滑点。`fill.describe()` 与测试固定这一行为。

### C1 收盘口径

`src/utils/session_clock.py`：

- 新增 `flatten_times_from_sessions`：日盘收 15:00 → 14:55，夜盘收到几点就提前 5 分钟。
- `default_flatten_for_product` 改为由出厂时段推出，删掉 14:55/22:55/02:25/00:55 的硬编码分组。
- `flatten_times_for_symbol` 顺序：品种表 → 策略页旧字段 → 由时段推出；回测、实盘、复盘都走这一个函数。

`src/review/consistency.py`：今日一致性开头增加一行「收盘口径 按品种与合约表清仓 14:55，之后只平不开，不进开仓对照」。

### D1 夜盘表

- `LATE_NIGHT_PRODUCTS` 去掉 `lu`（低硫燃料油夜盘只到 23:00）。
- `NIGHT_0100_PRODUCTS` 补 `bc`（国际铜）。
- `NO_NIGHT_PRODUCTS` 补 `ec`（集运指数）。
- `config/品种与合约.xlsx` 全部 81 行按出厂时段回写；`config.yaml` 经 `save_config` 同步。

### E1 时段统计

`src/account/slippage_log.py`：

- `summarize_by_session(root, cfg)` / `quality_text(root, cfg)` 增加配置参数。
- 有配置时按 `sessions_for_symbol` + `split_day_night_sessions` 判日盘/夜盘/其他；没有配置才退回按钟点粗分。
- 复盘页 `src/ui/review_tab.py` 传入 `self.cfg`，22:00 的生猪、鸡蛋记录不再算进夜盘。

## 4. 验收

- 在跑 8 个品种 `commission > 0`；评审单零费率降为「注意」。
- 默认配置下：一字板不成交、超时撤单、部分成交都有回归用例；快照记录三项口径。
- `flatten_times_for_symbol({}, "lh2701") == ["14:55"]`、`ag → ["14:55", "02:25"]`、`lu → ["14:55", "22:55"]`。
- 止损滑点已核实：`exit_fill_price` 先取更差的止损/开盘价，再按方向让滑点；无需新增代码。
- 时段统计按品种与合约表归类：`lh` 22:10 的记录归「其他」而不是「夜盘」。
- 全量 `pytest` 0 失败；改动文件 `ruff`、`mypy` 通过。

## 5. 风险

- 手续费是近似值，价格型费率随价格变化；签字前必须按期货公司结算单核对一次。
- 成交模型默认开启后，历史回测成绩会变；与旧结果对比时要看 `params_snapshot.liquidity`。
- `entry_timeout_bars` 只处理一字板导致的等待，未模拟委托队列与排队价差。
- 时段统计要求记录时间与品种表时段严格对应；跨零点的夜盘记录按 `in_clock_window` 的跨日规则判断，若交易所节假日前夜无夜盘，仍会按常规时段归类。
