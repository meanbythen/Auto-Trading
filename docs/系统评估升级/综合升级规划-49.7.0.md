## 一、一页结论

系统自评约 **107 / 155（B：可继续模拟、补短板）**。三条主线各自的真实短板是：

| 主线 | 已经不是问题 | 仍是问题 |
|---|---|---|
| 系统稳定性 | 心跳看门狗、断线重连、重启捡仓、三方对账、CTP 查询错误保护（49.6.16） | 账本文件锁偶发、对账超时只能熔断、交易台与常驻双连接、断电演练未做 |
| 回测可信度一致性 | 共用 `evaluate`、下一根开盘成交、样本外冻结、实盘镜像闸门（S1）、1 分钟复核（P2.2 代码） | 镜像差异未进日报；1 分钟复核未上界面；滑点仍靠全品种一刀切 |
| 评估准确性 | PF / R 期望 / Calmar / 回撤 / 连亏 / 震荡组 / 压力测试 / 参数扰动 | 健康对照拿「任意最近一次回测」比实盘；无连续偏离停开；无策略档案；无退役线 |

**一句话**：规则层已经够用，缺的是「量尺对齐」。本轮先把量尺修准，不加新策略。

### 已确认的口径缺口

1. **健康对照拿错对象**：`health.py:92-177` 直接读 `data/backtest_last.json`，不比对引擎、品种、周期。拿燃油 5 分钟回测去比生猪实盘也会给出「正常 / 偏差」。
2. **回测侧口径未强制记录**：旧结果没有 `params_snapshot.engine` 时无从判断，只能当「未知」处理，不能假装对齐。
3. **连续偏离没有累计**：单次 `watch` 只写告警，没有「连续 N 个交易日」的证据，也没有可选的停开闸。
4. **滑点建议是全局值**：生猪与燃油共用同一个跳数，和 G3、S2 的目标不一致。

## 三、升级路线（R 系列）

原则：**先量尺、后优化；默认不改行为；每个开关默认关；一次交付只升一次版本。**

### R1 — 评估口径闭环（本轮实施）

| 项 | 内容 | 验收 |
|---|---|---|
| R1.1 | 健康对照校验引擎 / 品种 / 周期；不一致显示「未对照」，不误报 | 拿错品种时 `status=skip`，消息含「未对照」 |
| R1.2 | 旧回测缺口径时明确标「未记录，仅供参考」，仍可比数字 | 旧 `backtest_last.json` 行为不退化为报错 |
| R1.3 | 连续 `watch` 交易日累计（`data/health_state.json`），报告显示天数 | 同一天多次检查只累计一次 |
| R1.4 | 可选停开闸 `runtime.health_block_entry`（默认 `false`）、`health_block_days`（默认 5） | 默认关时行为与 49.6.16 完全一致；打开且达标只拦开新仓，止损 / 清仓不受影响 |
| R1.5 | 滑点按品种汇总（70 分位 → 建议跳数），复盘页分品种展示 | 至少两个品种时能分别给出建议 |

**不改**：健康阈值（20 笔、胜率降 20 点、PF 不足一半）、告警冷却、开平规则。

### R2 — 一致性差异表进复盘（下一步）

把三样东西合成一页「今日一致性」：

- 镜像闸门命中：`stale_block` / `slip_block` 各几次，对应哪根 K；
- 1 分钟复核差异：哪些仓会更早止损、早多少；
- 实盘闸门真实命中：过期 K、追价放弃、日亏、暂停报单。

验收：任一平仓单能追到「回测会不会开、实盘为什么没开 / 追价多少」。

**R2 实施结果（49.7.0）**：新增 [src/review/consistency.py](../src/review/consistency.py)，复盘正文增加「十二、今日一致性」，原「综合」顺延为第十三节。

- 回测镜像：读 `backtest_last.json` 的 `mirror_gate_hits`，先核对引擎 / 品种 / 周期；不一致显示「未对照」，不拿别的回测解释今天。
- 1 分钟复核：只检查当天重放已平仓的仓，显示「更早碰到止损 N 笔」及最多 3 条明细；取不到 1 分钟数据时写明沿用信号周期。
- 实盘闸门：读 `events.jsonl` 复盘的时段与品种，统计过期K、追价、风控拦截、健康停开、无价格、品种冻结、下单失败。
- 结论行只比较次数并提示查分笔，不自动调闸门或改参数。

### R3 — 策略档案与退役线

- `docs/系统评估升级/策略档案.md` 每个正式引擎一节：开平规则、周期、是否隔夜、是否听公共 ADX / 清仓、已知失效行情、退役线。
- 评估报告头写引擎中文名、隔夜、清仓口径。
- 退役线只给建议，不自动换策略。

**R3 实施结果（49.7.0）**：新增 [src/strategy/profile.py](../src/strategy/profile.py) 与 [策略档案.md](策略档案.md)。

- 15 个正式引擎各有一张规则卡：开仓、离场、周期、隔夜、公共过滤、慎用行情。
- 隔夜口径按引擎代码里的 `flatten_at_close` 默认值登记，不靠界面文字猜。
- 回测报告与复盘重放抬头显示「中文名 / 隔夜 / 清仓 / 公共过滤」。
- 退役线写在档案末尾，统一 6 条建议阈值，只提示不自动执行。
- `tests/test_strategy_profile.py` 检查正式引擎无漏登记、别名可换算、文档与代码同步。

### R4 — 成交质量回流

- 按品种 / 方向 / 时段统计滑点与拒单；
- 回测提供「基线 / 压力 / 实测」三档滑点；
- 写入配置仍需人工确认，研究结果不自动进实盘。

**R4 实施结果（49.7.0）**：滑点统计扩到方向与时段，拒单进复盘；回测结果新增三档滑点对照，回填仍要人工确认。

- [slippage_log.py](../src/account/slippage_log.py) 新增按买卖方向、按日盘 / 夜盘分组：真实成交优先，GUI 假定成交不掺入，每组满 3 笔才给建议。
- `reject_summary` 从 `data/events.jsonl` 汇总近 30 天柜台拒单、没有价格、风控拦截、品种冻结、健康停开，按品种和原因分开计数；没有事件日志时如实写「没有记录」。
- 复盘尾部新增「成交质量（滑点与拒单）」，方向、时段、拒单三块一次看完。
- 新增 [src/backtest/slippage.py](../src/backtest/slippage.py)：基线（本次回测滑点）/ 压力（基线 + `slippage_extra_ticks`）/ 实测（同品种真实成交 70 分位，满 3 笔）。回测摘要和「用实盘滑点建议填入」对话框都显示三档。
- 三档只用于对照与选择；写回仍在回测页点确认，不自动写配置文件，也不进实盘参数。
- `tests/test_backtest_slippage.py` 与扩展后的 `tests/test_slippage_log.py` 覆盖分方向、分时段、拒单窗口、三档计算与无样本降级。

### R5 — 影子盘与上线评审单

- 仿真通道与实盘同参数并排记账；
- 一页评审单：数据门禁、样本外、镜像差异率、仿真滑点、人工签字。

**R5 实施结果（49.8.0）**：两本 CTP 账并排对照，五项证据收成一页评审单；签字只留档，不改交易参数。

- [shadow.py](../src/review/shadow.py) 只读 `signal_account_ctp_sim.json` / `signal_account_ctp_live.json`，各自汇总平仓、盈亏、胜率、盈利因子和未平手数，再按「同品种 / 同方向 / 同开仓日」粗对齐，列出仿真独有、实盘独有和开仓均价差。复盘正文新增「十三、影子盘（仿真 vs 实盘）」，原「十三、综合」改为「十四、综合」。
- [release_sheet.py](../src/review/release_sheet.py) 生成上线评审单：数据门禁（口径、真实数据区间、回测自身审计）、样本外（优化检验段）、镜像差异率（回测闸门放弃率 + 实盘近 30 天被拦）、仿真滑点（仿真账 70 分位对照压力档）、人工签字。
- 复盘页新增「生成上线评审单」，可预览、只保存（`data/release_sheet.md`）或签字并保存（`data/release_sheet.json`）。签字只记录「继续观察 / 允许小资金挂机」，不改配置、不放宽风控、不自动开仓；「不通过」时仍可留档，但会二次确认。
- 滑点记录新增 `account` 列（sim / live），评审单的仿真滑点只统计仿真账；旧记录没有该列，明确标「未分账」。
- 实盘被拦统计补上 `stale_block_open`（K线过期）和 `slip_block_open`（追价过大），和柜台拒单、风控、冻结、健康停开一起数。
- 未做：同时连接仿真和实盘两条通道——当前仍一次只连一个柜台；两边不同时段的成交只能看分布和同日同向粗对齐，不能当成逐笔偏差。

### R6 — 稳定性专项

- 账本锁重试与空账保护回归；
- 对账超时后的恢复策略（仅在仓一致时自动恢复，须评审）；
- 交易台 / 常驻双连接互斥；
- 断电、杀进程、断网三类演练记录。

## 六、明确不做

- 不做震荡专用引擎，不用回测曲线反向调参。
- 不自动切换实盘策略、自动放风险、自动改滑点上限。
- 不为了「架构好看」先拆巨型文件；拆文件排在上述主线之后。
- 不把 GUI 假定成交写成柜台真实成交。
- 不在有仓时强制升级；升级按「关掉再打开」。
