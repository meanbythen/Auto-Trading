# 策略迭代进化说明

对应程序版本 **13.7.1**。给人看的操作说明，不是马上全部做成全自动的清单。

规划背景在 [系统蓝图.md](系统蓝图.md)。准备挂机的选品种、选策略、调参数顺序在 README「7.5 实盘挂机」。

---

## 先记住一句话

**发现可以自动，调参可以自动，换实盘驾驶员必须你点。**

「自动迭代进化」不是让程序自己改开仓公式、自己换实盘策略。正确做法是：程序负责发现和对照，你负责判断和切换。实盘主推始终由你点一下才换。

---

## 一、先分清三件事

机构里常说的进化，其实是三层，不能混成一步：

| 层 | 在干什么 | 本程序现在 | 会不会自己下单 |
|----|----------|------------|----------------|
| **发现** | 市场里哪些规律稳 | 有：「规律候选」页 | 不会 |
| **调参对照** | 同一套规则换旋钮，看会不会更好 | 有：策略优化、交叉测试、自适应权重对照引擎 | 不会自动换实盘 |
| **换实盘驾驶员** | 真的改「哪根 K 线开仓」 | 要你点「写入配置 / 切换引擎」 | **默认永远不要自动** |

蓝图里写得很死：扫描层自己不下单；自适应权重是对照引擎，不是自动替换主推；全面优于旧策略，才允许你点切换。

如果你让 AI「看着亏了就改公式」，那叫过拟合，不是进化。

---

## 二、进化该绕的圈

把程序当成工厂流水线，人站在闸门旁：

```
行情质量过关
    → 规律候选（发现，不下单）
    → 交叉测试粗筛（哪个合约配哪套策略好看）
    → 历史回测细看 + 因子衰减图
    → 策略优化（前一段挑、后一段只验收）
    → 多品种再验一遍
    → 模拟挂机跑够笔数
    → 你对比：回撤、赚钱稳不稳、是不是同一套逻辑
    → 通过才写入配置 / 换引擎
    → 小仓实盘
    → 每天复盘 + 账户分析 + 健康报警
    → 衰减了：先停开或减仓，再回到上面重跑，不要当场改公式
```

任何一步没过，主推不动。

这和蓝图第三期「有监督的进化」是同一套：影子/模拟里重搜 → 样本外 + 多品种 → 模拟盘跑够笔数 → 全面更好你才点切换。

## 三、每一环具体怎么做

### 1. 数据先过关

进化用的是本地清洗库 `data/klines/market.sqlite`。质量差的那一家不要拿去优化。

1. 历史回测页点「查看本地K线库存」，看有没有、时间齐不齐。会打开 Excel 统计表。抽查某一根是否和同花顺对得上，点「查看这根K线」。
2. 点「检查行情质量」，看各家开高低收差几跳。
3. 某一家很差：用「删除本地K线」只删那一家 / 那个合约 / 那段时间，再重新拉或从同花顺图再读。

数据在撒谎时，优化只会把谎言学得更像。

K 线怎么存：清洗库 `market.sqlite`（开仓看这份）、原样库 `raw.sqlite`，另有 csv 备份。新浪库存名是 `fu2701`，东方财富带 `@eastmoney`，天勤带 `@tq`，同花顺图带 `@ths`。

### 2. 发现层：规律候选（已经有）

打开顶部「规律候选」：

1. 选行情来源、周期、时间段。品种和配置页关注名单是同一份。可以只扫当前这一个，也可以扫名单里全部。
2. 多个品种时，打开「至少两个合约都过关才进池」，避免只对一个合约碰巧有效。
3. 点「开始扫描规律」。程序只用事先写清经济学逻辑的因子（以及说得通的双因子组合），看它们和后面 3/6/12 根涨跌是否同向。历史从中间切开，两半都显著才算过关。再把这段切成几段，看是不是大部分时间都同向。
4. 右边说明书最上面会写类型倾向。常用几类：
   - **趋势跟踪**：涨了还容易继续涨。可去交叉测试双均线、SuperTrend、SAR、海龟、多因子、长线趋势。
   - **突破**：靠近区间上沿或放量后，后面更容易顺着冲。可去交叉测试日内实体、早盘箱体、布林突破、海龟。
   - **震荡回归**：涨多了后面更容易往回走。本程序没有单独的高抛低吸引擎，倾向回归时不要硬做趋势。
   - **波段/结构**：影线、跳空这类 K 线结构后面更容易走出一段。可去交叉测试 Casper、长线趋势加减仓。
5. 左边勾「我认可这条逻辑」，再点「保存勾选（仍不下单）」。结果在 `data/规律候选池.json`。

勾选和类型倾向都不会改现在哪根 K 线开仓，也不会下单、不会自动换策略。要用某条规律，还得另外写成完整开平仓规则（例如加进多因子），那是大更新，需要你明确提出。

不做：全市场乱挖、扫到什么就当下单信号；也不做「专门去找下一次开仓时机」的机会扫描。

### 3. 对照层：交叉测试 → 回测 → 优化（已经有）

这是「同一套驾驶员换旋钮」，不是换大脑。

1. **交叉测试**：固定现在的参数，看哪些合约 + 策略这段历史上相对好看。记下 2～5 个候选，不要只认一个。标成「较好」只表示这一轮相对好看，不代表以后会赚钱。
2. **历史回测**：单组合细看成交、回撤、开关。多因子再点「画出因子衰减图」，看四个因子最近 20 笔滚动盈亏——哪根弦在偷懒。
3. **策略优化**：
   - 前一段（训练）挑参数，后一段（检验）只验收。
   - 先用「一次切断」；样本够长再试「滚动前进」。
   - 搜索深度用精简或标准；完整组合很多，靠抽样，更容易过拟合。
   - 滚动时：检验效率太低、赚钱段不到一半、参数乱跳 → 不能写入。
   - 其它关注品种超过一半大亏 → 不能写入。
4. 写入只改这一套策略的参数，不会偷偷改正在用的策略名、品种、周期。策略、品种、周期要另点历史回测页「把本页参数写入配置页」。
5. 写入前自动留参数版本，坏了在策略优化页「回溯」。常驻正在跑时，不能一键应用配置存档。

主推多因子是固定权重。自适应权重是另一套对照引擎：只在平仓后慢改权重，有上下限和步长，优化不搜权重，默认不切到实盘。

### 4. 实盘层：模拟够笔数，再小仓

回测好看不等于以后赚钱。公开分钟线往往偏短。

1. 模拟模式打开，挂机。
2. 若走同花顺点击：测试工具里「点击下单自检」。
3. 小仓实盘（1 手）。1 手不会被回撤减仓强平。
4. 运行台看健康：近 20 笔对照最近一次历史回测。胜率低很多或盈利因子腰斩只报警，默认不停手。
5. 钱用账户最高点回撤管：大约掉 5% 下一笔减半，掉 10% 暂停开新仓；日亏熔断另算。这是管钱，不是改策略公式。

### 5. 衰减以后怎么进化（最容易走错）

因子衰减图、复盘成绩单变差时：

**该做的**

- 先看是不是行情质量、换月、主力合约变了。
- 动态减仓会自动少开，不必先改公式。
- 用另一段日期、另一个合约再回测、再优化。
- 策略优化页打开「对照正在用的参数」再点「开始策略优化」：和现在这套对照，**默认不改实盘**。
- 新旧两套并排：回撤、盈利因子、检验效率、多品种是否翻车。
- 新的全面更好，写入按钮会变成「写入并切实盘（先存档）」：留下整页配置存档和参数版本。不好就不要确认那次额外询问，或事后回溯 / 重置出厂。

**不该做的**

- 对着刚亏完的那一段把参数搜到曲线最美。
- 每根 K 线改权重。
- 程序自动把实盘从「加权打分」切成自适应或另一套引擎。
- 把规律候选里刚勾的条目直接当成买卖点。

蓝图里还缺一扇闸：连续偏离历史就禁止开新仓（现在健康只报警）。缺的时候用人看复盘和健康行代替，不要用「自动改策略」来补。

## 四、建议用的节奏

**每天（收盘后，大约 10～20 分钟）**

- 复盘页：当天信号对不对、有没有该开没开。
- 账户分析：余额、回撤。
- 运行台健康行：只看提醒，不因为一天就改参数。

**每周（一次完整对照）**

- 库存 + 行情质量（数据有没有烂）。
- 因子衰减图（用多因子时）。
- 若健康连续变差：模拟盘上用对照引擎或新参数跑，不改实盘主推。

**每月或明显衰减时（才允许进化）**

1. 规律候选：有没有新的、跨时段仍显著的逻辑（仍不下单）。
2. 交叉测试缩小候选。
3. 优化：训练 / 检验 / 滚动 / 多品种全过。已经在用时打开「对照正在用的参数」再搜，不要直接写入。
4. 模拟再挂一段时间（笔数太少不算数）。
5. 下面第五节清单全过，才写入。

**永远不要自动做的**

- 自动切换实盘策略引擎。
- 自动把优化结果写进正在跑的常驻进程。
- 无约束全市场挖规律并下单。

自动切换是最后才打开的开关。现在一次只盯一个合约，前置、组合、订单中台都还没有，打开它等于让一个半成品自己换大脑。

## 五、什么叫「全面优于旧策略」

点切换或写入之前，新旧两套用同一段样本外、同一滑点手续费口径、同一合约比：

1. 检验段不是大亏；滚动时赚钱段至少一半。
2. 最大回撤没有明显恶化。
3. 盈利因子仍大于 1，净赚能盖住回撤。
4. 其它关注品种没有大面积翻车。
5. 逻辑你还讲得通（不是黑箱碰运气）。
6. 模拟盘方向和回测大致同向，不是回测赚、模拟亏。

回测还能不能信，再对这四条（蓝图第二节）：

1. 没有用未来数据（本程序默认这根收盘确认、下一根开盘成交）。
2. 有样本外，不是同一段又训练又验收。
3. 成本要算（回测有手续费和滑点跳数；账户分析页还不扣）。
4. 网格不能搜到过拟合（优化网格故意很小；检验段由赚变大亏不能写入）。

一条不过，曲线再漂亮也不上实盘。

## 六、现在有什么、还缺什么

**已经有**

- 规律扫描（不下单）
- 优化检验闸、参数版本回溯、重置出厂
- 衰减后打开「对照正在用的参数」再优化：对照现在这套，默认不切实盘
- 全面更好时「写入并切实盘（先存档）」：整页配置存档 + 参数版本；可回溯、可重置出厂
- 多因子自适应权重对照（不替换主推）
- 因子衰减图、复盘成绩单
- 策略健康报警（默认不停手）
- 账户最高点回撤减仓、日亏熔断、波动缩仓

**还没有、也不该抢着做**

- 衰减自动弹出模拟重跑（现在要你自己点按钮）
- 影子盘跑够若干笔才允许切
- 连续偏离就禁止开新仓的总闸
- 每一笔单打上「用的是哪一版参数」
- 异常自动回滚
- 多策略组合进化（一次只能盯一个合约）

这些做成之前，进化的正确姿势仍是：程序出对照，人按清单点闸。模拟重跑已经落地，仍然默认不切实盘。

## 七、和挂机准备流程怎么接

第一次上实盘，按 README「7.5」走完：关注名单 → 交叉测试 → 历史回测 → 策略优化 → 写入 → 模拟 → 小仓。

上线之后的每周、每月，改走本文第二节的圈：质量 → 发现 → 对照 → 模拟 → 你点闸。不要跳过检验，直接把优化结果写进正在跑的常驻。
