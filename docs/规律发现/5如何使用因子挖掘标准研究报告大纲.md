一句话定位
这份大纲不是写完再填结果的作文模板，是一套带强制校验顺序的研究流水线、审计清单、入库预审单；绑定你的Notebook，先写假设 → 代码逐章节产出证据 → 对照标准打分、淘汰伪因子，用来管住“随便调参数、挖到好看IC就直接上实盘”的数据窥探问题。
适用：期货CTA时序因子、Regime状态因子，和你前面这套 IC / MI / Hurst / Kmeans / 置换检验 / WFA 完全对齐。
一、使用原则（机构最看重的3条红线，先记住）
1. 假设前置，禁止先跑数据再编逻辑
摘要里的【因子逻辑假设】必须是跑任何代码之前就写好的。
❌ 错误：跑出来IC很好，回头解释“这个指标代表趋势”
✅ 正确：先提出假说：Hurst高的时候趋势延续，Hurst低的时候容易反转，我用Hurst+波动率聚类做状态依赖信号，再用数据检验假说是否成立。
2. 顺序不可逆：前面不通过，直接终止，不往下跑
描述统计 → IC → MI → Hurst → Regime聚类 → 置换检验 → WFA。
置换检验p值不达标，直接驳回，不做WFA，避免浪费时间在随机噪声上。
3. 样本严格隔离：In-Sample / OOS滚动 / Lock保留集三分开
Lock保留集全程不能用来调参、看结果，只在全部检验做完、决定入库前最后打开一次，做盲测。
二、标准使用流程（和你的Notebook单元格一一对应）
Step1：新建一份因子文档 + 配套Notebook（一对一一绑定）
1. 先填文档头部元信息：因子名称、类别、标的池、K线周期、数据区间、样本划分。
2. 在Notebook第一单元格固定：数据源、随机种子、预处理规则（Winsor、缺失值），保证可复现。
规范：一个因子 = 一份报告 + 一个独立Notebook，不要在同一个Notebook里反复试几十个因子、改参数。
Step2：章节1 研究摘要（先写文字假设，后面再填结果）
摘要本质是给你自己和PM看的一页结论卡：
● 先写：预期机制、预期IC方向、预期状态特性；
● 跑完所有检验之后，回来填【关键指标汇总表】和【是否推荐入库】；
● 入库三档结论：驳回 / 进入第二轮WFA / 准入因子池。
打分参考（期货CTA时序因子，你可以固定下来）
● Rank IC IR ≥ 0.5、置换检验p<0.05、WFA夏普>1.2、参数扰动稳定 → 可进入WFA
● IC不错但置换检验p很高、分组收益分化差 → 驳回，属于随机幻觉
● IC一般，但MI很高、状态分化极强 → 标记为状态型因子，不单独作为单因子，用来做Regime开关
Step3：章节2 因子定义与计算说明（审计核心，防未来函数）
这一章是复现保证书：
● 精确写公式、窗口参数；
● 重点标注：future_ret_N是T时刻的因子，预测T+N收益，时间对齐；
● 预处理规则写死：Winsor是1%/99%还是MAD；
● 坑点：在这里提前锁定参数，不要后面看到结果好看再改窗口。
Step4：章节3 单因子描述统计（初筛，过滤垃圾因子）
Notebook输出：时序图、分布直方图、ACF/PACF、因子半衰期、分组分箱收益。
检查点：
● 因子分布是否稳定，有没有某一段凭空突变；
● 因子半衰期太短（比如1~2根K线），交易成本扛不住，直接淘汰；
● 分5组/10组收益是否单调，分组乱跳=因子不稳定。
Step5：章节4 Rank IC检验（线性预测能力）
Notebook输出：IC时序、IC均值、ICIR、IC>0占比、分状态IC。
重点：一定要看分Regime的IC，同一个因子在趋势态有效、震荡态失效，这就是状态依赖，CTA最常见。
ICIR是机构第一优先级指标，比单纯IC均值更重要。
Step6：章节5 互信息MI检验（非线性增量信息）
对比：MI vs Rank IC
● IC低、MI高：非线性规律，适合放进树模型、状态条件策略；
● IC高、MI也高：线性强信号，简单阈值策略就可以用；
● MI接近0：因子几乎没有增量信息，直接淘汰。
额外：和已有因子池的互信息，判断是否冗余。
Step7：章节6 Hurst指数分形特性检验
Notebook输出：滚动Hurst时序、H分布占比、高H/低H分组IC对比。
目标：验证假说——高H趋势、低H均值回归，看两组IC方向是否符合预期。
注意：R/S Hurst本身噪音大，不能单独作为交易信号，只能作为状态特征。
Step8：章节7 Regime聚类分析（Kmeans/GMM）
输出：轮廓系数、聚类中心画像、样本分布、状态转移矩阵、各状态下收益&IC。
这里要人工命名Cluster：低波动震荡、高波动趋势、极端反转。
核心产出：条件表——哪个状态下，这个因子才有效。
后续策略用法：只在有效状态下开信号，无效状态屏蔽。
Step9：章节8 置换检验（防假阳性，最重要的守门关卡）
这一步是区分“真规律”和“数据窥探”的闸门，不通过直接停止研究
流程：固定因子，打乱收益标签，重复500~1000次，得到随机分布；
判断：真实IC/收益落在分布尾部，p<0.05，才认为统计显著。
批量挖因子时，在这里加上FDR/Bonferroni多重检验校正。
Step10：章节9 WFA滚动样本检验（模拟实盘，样本外验证）
置换检验过了，才跑WFA。
输出：滚动绩效曲线、分状态绩效、参数敏感性测试。
重点看：
● 不是看整体夏普，而是看每一段滚动窗口绩效是否稳定；
● 参数扰动测试：窗口±1、k±1，绩效不能断崖下跌（断崖=过拟合）。
Step11：章节10 共线性&增量检验
VIF、和存量因子的相关性、叠加之后组合IC是否提升。
如果新因子和已有因子高度相关、没有增量Alpha → 不入库，避免因子池冗余。
Step12：章节11 局限性、失效情景（风控章节）
强制写：这个因子什么时候失效、缺陷是什么（比如Kmeans硬聚类假设球形分布、R/S Hurst小窗口偏差）；
滑点、手续费衰减测试，算净收益。
机构要求：任何因子文档必须写清楚失效场景，不能只写优点。
Step13：章节12 后续实验计划
基于当前结果，写下一轮迭代方向：
● 换GMM/HMM替代Kmeans；
● 换预测周期标签；
● 加入订单流Tick特征；
● 构建状态切换策略。
Step14：章节13 附录
粘贴Notebook链接、所有图表、原始表格，保证任何人拿到文档，点开Notebook就能复现全部结果。
三、两种使用模式（你个人研究 / 多人团队）
模式A：你自己做期货研究（vnpy+notebook）
1. 固定模板，每一个候选因子单独一份；
2. 把Notebook最后一个单元格写一段自动生成Markdown摘要的代码，跑完直接粘贴进报告；
3. 建一个因子台账：因子名称、入库状态、最后一次校验时间、Lock集绩效；
4. 定期淘汰：每隔一段时间用新数据重跑WFA，IC持续衰减的因子移出因子池。
模式B：团队评审（模拟机构评审）
● 你写完整报告+Notebook；
● 评审人只看：前置假设、置换检验p值、WFA样本外、Lock盲测集；
● 评审人有权要求：更换随机种子、换数据区间重跑，检验是否稳健。
四、配套的避坑检查清单（你可以贴在报告首页）
✅ 因子和标签时间对齐，无未来函数
✅ 样本划分提前锁定，没有事后调整区间
✅ 置换检验已经做，多重检验校正（批量挖掘时）
✅ WFA是时序滚动，不是随机K-fold
✅ 参数敏感性测试完成，不是单点最优参数
✅ 已经做滑点手续费扣减
✅ Lock保留集没有被用来调参
五、举一个极简的实操例子（Hurst状态因子）
1. 前置假设：Hurst>0.5为趋势态，动量因子有效；Hurst<0.5为回归态，动量因子失效；
2. 跑描述统计、动量因子Rank IC；
3. 计算MI，看动量和未来收益非线性关系；
4. 用Hurst+波动率聚类得到3个市场状态；
5. 分状态看IC：Cluster1（高H）IC显著为正，Cluster0（低H）IC接近0；
6. 置换检验p=0.02，通过；
7. WFA滚动夏普1.4，参数扰动后绩效没有崩塌；
8. 报告结论：作为状态依赖因子入库，策略逻辑：仅在Cluster1趋势态启用动量信号；
9. 记录失效场景：流动性枯竭、跳空行情下Hurst失真。
