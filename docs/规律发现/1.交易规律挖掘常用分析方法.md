交易规律挖掘常用分析方法（CTA/日内、期货、股票都适用，按用途分类，附带交易场景）
你提到的：相关性分析、聚类分析 放在里面，同时区分【统计分析】【时序分析】【模式识别】【量价微观】【回测验证类】，适合写进vnpy策略、因子挖掘、Tick/分钟级数据研究。
一、相关性 & 共线性类（看变量联动）
1. Pearson相关系数：线性相关，适合价格、指标、因子之间线性联动；缺点抓不到非线性。
2. Spearman秩相关：单调相关（不要求线性），交易里最常用，不怕极值、适合排名类因子。
3. 互信息 Mutual Information：捕捉非线性关联，相关性系数为0也可能有强关系，适合挖掘隐藏量价规律。
4. 协方差矩阵、偏相关：剔除中间变量干扰，比如研究纯碱和燃油，排除大盘/原油的共同驱动。
5. VIF方差膨胀因子：不是找规律，是排查因子多重共线性，多因子建模必用。
二、聚类分析（你提到的，用于分组、行情状态归类）
目标：把相似行情/样本归为一类，识别不同市场状态
1. K-Means：最常用，对特征标准化后聚类，例如：把K线形态、波动率、成交量聚成【高波动趋势、低波动震荡、放量反转】几类，不同状态用不同参数。
2. DBSCAN密度聚类：不需要预先指定类别数量，适合抓异常样本、稀有行情模式（尖刺行情、爆量拐点），Tick高频很好用。
3. 层次聚类 Hierarchical Clustering：看品种板块聚类，比如把化工品聚类，找板块联动组。
4. 高斯混合模型 GMM：软聚类，每个样本属于各类别的概率输出，适合马尔可夫状态切换（波动率状态概率）。
三、时序专项分析（金融数据核心，价格是时间序列）
1. 自相关ACF / 偏自相关PACF：判断序列是否趋势、是否均值回归，识别AR/MA结构，判断价格是否有动量/反转。
2. ADF平稳性检验、KPSS检验：检验序列平稳性，很多模型要求平稳序列（价差、收益率序列）。
3. 协整检验（EG两步法、Johansen）：配对交易核心！两个非平稳品种，线性组合平稳 → 套利机会（跨期、跨品种）。
4. 马尔可夫状态转换模型 MS-AR：把行情分成两种/多种状态（牛市/熊市/震荡），自动切换，很多趋势CTA底层在用。
5. 傅里叶变换FFT、小波变换Wavelet：频率域分析，分离长周期趋势、短周期噪音，识别周期规律；小波适合非平稳时序。
6. Hurst指数（重标极差R/S）：判断序列是趋势（H>0.5）、随机游走（0.5）、均值回归（H<0.5），非常适合CTA前期筛选品种。
四、回归 & 因子建模（找特征→收益的映射关系）
1. 线性回归、多元线性回归：基础因子收益拟合。
2. Lasso / Ridge / ElasticNet：带正则化的回归，自动筛选有效因子、抑制过拟合，因子挖掘标配。
3. 分位数回归：不预测均值，预测涨跌分布尾部，抓极端行情下的规律（大波动时因子效应）。
4. 逻辑回归 Logistic：分类任务：预测下一根K线涨/跌（0/1标签）。
五、机器学习模式识别（非线性规律，适合复杂模式）
1. 决策树、随机森林、XGBoost/LightGBM/CatBoost：交易因子挖掘最主流，自动学习特征交互，输出特征重要性；可做涨跌分类、收益回归。
2. SVM支持向量机：适合小样本、寻找涨跌超平面，早期用得多，现在不如树模型普及。
3. KNN K近邻：形态匹配！用历史K线特征找最相似的历史片段，看后续盈亏，K线模板匹配思路。
4. 神经网络（MLP、CNN、Transformer）：CNN提取K线图像形态；时序Transformer（Temporal Fusion、TST）做多因子时序预测；风险：极易过拟合。
六、分布、极值、风险统计方法
1. 核密度估计KDE：不假设正态分布，画出收益率分布，看肥尾、双峰结构，识别常见收益区间。
2. GARCH族（GARCH、EGARCH、TGARCH）：波动率聚类建模（波动聚集：大涨之后容易大波动），ATR本质是简化版，期权、波动率策略常用。
3. 极值理论EVT：专门研究尾部黑天鹅，最大回撤、极端涨跌分布。
4. Q-Q图、KS检验：检验收益是否符合某分布。
七、量价微观 & 订单流专项（Tick、盘口规律）
1. VP成交量分布、POV、成交分布：成交量在价格上的分布，找支撑阻力、价值区。
2. 买卖盘失衡、盘口斜率、冲击成本分析：看大单、吃单挂单规律，高频/短线日内。
3. 变差方差、价差时序统计：盘口流动性规律。
八、信息论、非线性动力学（偏进阶）
1. 样本熵、近似熵：衡量时序复杂度，熵越高行情越随机难预测；熵低代表规律性强。
2. 李雅普诺夫指数：判断时序混沌性，金融市场大多是弱混沌，不是纯随机。
3. 置换熵 Permutation Entropy：抗噪强，识别趋势、震荡切换。
九、回测&假设检验（用来验证“是不是真规律，还是数据挖掘偏差”，非常关键）
很多人前面分析一通，漏掉这一步，挖到的都是过拟合幻觉：
1. t检验、卡方检验：检验策略收益均值是否显著大于0
2. Bootstrap自助抽样：重采样，评估绩效分布，规避幸存者偏差
3. 置换检验 Permutation Test：打乱标签，看原策略收益是不是显著优于随机
4. PCP、多重检验校正（Bonferroni、FDR）：多次挖掘因子，控制假阳性（数据窥探bias）
5. ** walk-forward analysis 滚动样本（滚动训练+滚动测试）**：最核心，模拟实盘，防止未来函数、过拟合
