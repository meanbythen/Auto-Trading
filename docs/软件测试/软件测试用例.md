# Auto-Trading 软件测试用例库

对应版本 **53.7.11**（2026-11-24）。本文件是 [软件测试方案](软件测试方案.md) 的可执行用例目录，方案讲「怎么测」，这里列「测什么、在哪测、期望是什么」。

## 1. 使用说明

### 1.1 编号规则

| 前缀 | 含义 | 主要方法 |
|---|---|---|
| `TC-SIG` | 信号与开平仓 | 场景法、状态迁移、边界值 |
| `TC-RSK` | 风控链 | 判定表、边界值、错误猜测 |
| `TC-ACC` | 账本、成交与对账 | 状态迁移、等价类、故障注入 |
| `TC-DAT` | 行情数据 | 等价类、边界值、属性测试 |
| `TC-BKT` | 回测 | 金标准、蜕变测试、边界值 |
| `TC-OPS` | 告警与运维 | 判定表、故障注入 |
| `TC-SEC` | 安全与配置 | 等价类、错误猜测 |
| `TC-GUI` | GUI、打包与兼容 | 场景法、人工检查 |
| `TC-CTP` | CTP 上线 | 人工演练、对账 |
| `TC-U-*` | 单元白盒用例 | 语句/分支/条件/循环/路径/异常 |
| `IT-*` | 组件集成用例 | 接口契约、数据流 |
| `E2E-*` | 系统端到端用例 | 场景法 |
| `PT-*` | 专项用例 | 性能、安全、并发、恢复 |
| `MAN-*` | 人工验收用例 | 演练清单 |

### 1.2 自动化标记

- **自动**：`pytest` 在本机离线可重复执行。
- **半自动**：需要固定夹具、仿真通道或人工触发，但结果可脚本断言。
- **人工**：真实柜台、真实行情、高 DPI 真机或签字演练。

### 1.3 执行命令

```powershell
# 全量
.\.venv\Scripts\python.exe -m pytest -q

# 覆盖率
.\.venv\Scripts\python.exe -m pytest -q --cov=src --cov-branch --cov-report=term-missing

# 本轮新增的 7 个单元文件
.\.venv\Scripts\python.exe -m pytest -q tests\test_ctp_symbols.py tests\test_ctp_limits.py `
  tests\test_order_pricing_unit.py tests\test_fill_reconcile_unit.py `
  tests\test_flatten_manager_unit.py tests\test_login_flow_unit.py tests\test_session_audit_trigger.py
```

### 1.4 数据与环境红线

- 每个用例使用 `tmp_path` 工作区，不读写真实 `data/`、`secrets.local.yaml`。
- 固定时钟、固定随机种子；涉及网络的用例必须可在离线环境跳过或使用夹具。
- 断言必须写预期值，禁止只断言「不抛异常」。
