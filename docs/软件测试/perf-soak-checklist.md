# 长稳执行检查表

对应版本 **53.7.7**（2026-11-24）。配合 [P3 性能与长稳测试方案](P3性能与长稳测试方案.md) 第 7 章与 `tools/perf_soak.py` 使用，把 24h/72h 长稳做成可复现、可留证的流程。

---

## 1. 开始前

| 检查项 | 要求 | 完成 |
|---|---|---|
| 机器 | 插电、高性能电源、关闭睡眠/屏保/自动更新 | ☐ |
| 后台程序 | 关闭无关程序，记录白名单 | ☐ |
| 工作区 | 使用临时工作区或专用测试账号，不碰真实账本 | ☐ |
| 目录可写 | `logs/`、`data/`、`build/perf/` 均可写 | ☐ |
| 日志轮转 | 单文件 20 MB 轮转生效 | ☐ |
| 起始状态 | 记录 `data/trading.db`、WAL、`logs/`、告警文件大小 | ☐ |
| 品种与数据 | 固定 10 个品种，使用本地缓存/demo 数据 | ☐ |
| 版本 | 记录 `VERSION` 与依赖哈希 | ☐ |

启动命令：

```powershell
# 先启动采样器，由它拉起目标程序
.\.venv\Scripts\python.exe tools\perf_soak.py --hours 24 --symbols 10

# 已有独立启动方式时，指定目标命令
.\.venv\Scripts\python.exe tools\perf_soak.py --hours 24 --command ".venv\Scripts\python.exe -m src.main"

# 只验证采样器本身（不启动交易程序）
.\.venv\Scripts\python.exe tools\perf_soak.py --dry-run --hours 0 --max-samples 3 --interval 0
```

产物：

- `build/perf/soak-<时间>.jsonl`：每 30 秒一条资源采样，每小时附存储指标；
- `build/perf/soak-<时间>.md`：每 6 小时刷新一次摘要，结束时写最终摘要。

## 2. 执行中

| 时点 | 动作 |
|---|---|
| 前 30 分钟 | 预热，不计入内存趋势 |
| 每 1 小时 | 看一次 JSONL 是否有 `storage` 记录；确认发件箱 pending 不持续上涨 |
| 每 6 小时 | 打开摘要，记录 RSS、线程、句柄、DB/WAL、日志大小，填下方记录表 |
| 每 24 小时 | 做一次只读功能检查：切页签、查持仓、看告警、查对账结果 |

每 6 小时记录表：

## 3. 自动终止条件

采样器遇到以下情况会停止并写入终止原因：

| 条件 | 判定 |
|---|---|
| 目标进程退出 | 返回码非 0 直接停止 |
| 磁盘剩余空间 | 低于 1 GB |
| 内存 | 预热后 RSS 连续 3 个采样点上升且累计超过 200 MB |

人工发现以下情况也应立即停止并留证：

- 卡死超过 2 分钟，或主循环停止超过 3 个扫描周期；
- 线程/句柄持续增长且无回落；
- 重复入账、账实漂移、无法恢复的数据库锁。

---

## 4. 结束时

| 检查项 | 要求 | 完成 |
|---|---|---|
| 摘要 | `soak-*.md` 已生成，样本数与时长对得上 | ☐ |
| 原始数据 | `soak-*.jsonl` 保留，不覆盖 | ☐ |
| 内存 | 24h RSS 增长 ≤ 50 MB 且无单调上升 | ☐ |
| 线程/句柄 | 线程 ≤ +2，句柄 ≤ +50 | ☐ |
| 日志 | 按 20 MB 轮转，无单文件失控 | ☐ |
| SQLite | DB 与 WAL 不持续增大，WAL 可回收 | ☐ |
| 发件箱 | pending/failed 无积压 | ☐ |
| 账实一致 | 对账无差异，无重复入账 | ☐ |
| 异常日志 | 统计 ERROR/CRITICAL 条数并归因 | ☐ |

## 5. 结论模板

```text
长稳结论：通过 / 有条件通过 / 失败
时长：24h（或 72h）
样本数：____ 条
RSS：起点 ____ MB，结束 ____ MB，峰值 ____ MB
线程：____ → ____；句柄：____ → ____
DB/WAL：____ MB → ____ MB；日志：____ MB → ____ MB
发件箱：pending ____，failed ____
异常：____
结论与后续动作：____
```

结论为「失败」时必须附最小复现步骤、异常日志片段与对应的 `soak-*.jsonl` 时间段。
