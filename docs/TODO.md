- [ ] 因子相关性检查（Spearman）与自动淘汰：权重现在固定，四个因子可能高度同向。
- [ ] 因子计算下沉到 `src/features`（先做搬家，不改分数）。

### 3.2 凯利手数

- [ ] 用滚动窗口胜率替代手填胜率。
- [ ] 组合级相关性与保证金约束。
- [ ] 单笔风险封顶（当前默认每笔最多 2%，需要评估是否放宽到 3%）。

### 3.3 长线箱体突破（`swing_box`）

- [ ] 箱体中继加仓。
- [ ] 周线共振过滤。

- [ ] 多周期共振确认。
- [ ] 二次扫损后的再入场规则。

### 3.5 规则 DSL / 策略编辑器

- [ ] 涨跌停过滤与流动性过滤（属于引擎层，规则文件管不到）。

- [ ] ADX 算法与 tqsdk 原版对齐（当前口径不同，回测数字不能直接对比）。
- [ ] 加减仓、反手、分批止盈（DSL 目前明确不支持）。

### 3.6 研究工具

- [ ] 独立参数扫描脚本（不依赖界面）与分组筛选（按品种/时段/波动分组出报告）。

## 四、评估与回测

完整评估与四阶段规划见 [策略研究体系评估与全闭环方案.md](策略研究体系评估与全闭环方案.md)：单策略单品种链路已齐备，缺组合层与研究治理层。实施顺序与优先级见该文第 8 节，第一批只做指标补齐、试验留痕、稳健性报告与滑点校准，均不改交易链路。

- [ ] **组合回测**：多品种共享资金与保证金，输出组合权益、组合回撤、保证金峰值、品种贡献与相关性矩阵；交叉测试增加资金口径排名。
- [ ] **统计稳健性**：补 Sharpe/Sortino/Ulcer、bootstrap 置信区间、Deflated Sharpe、PBO，以及参数平原热力图与多参数联合扰动。
- [ ] **研究治理**：假设登记、失败实验库、决策日志、上线后变更冻结与再优化节奏。
- [ ] **执行校准**：用实盘滑点日志反推回测滑点与成交率；健康对照扩展到分品种/分时段、滑点与拒单率。
- [ ] **执行可行性与容量**：按成交量、时段、涨跌停核对单笔规模，给出资金放大 2/5/10 倍后的滑点与容量上限。
- [ ] **上线变更与再认证**：变更必须带回滚预案；按周期重跑冻结外验证，并核对手续费、保证金、合约乘数与交易时段变化。

回测–实盘一致性与策略档案的分阶段方案见 [系统评估升级/回测实盘一致性与评估体系升级方案.md](系统评估升级/回测实盘一致性与评估体系升级方案.md)。S1 镜像闸门已于 49.1.0 交付（默认关）；回测与实盘的口径差异已在 49.21.0 修正或标注；S2 滑点回流尚未开工。

评估体系（Calmar、最大连亏、回撤持续期、ADX 分组、滑点与扰动压力、优化拦截）已完成，下面是从当时的「本次不做」清单延续下来的：

- [ ] 全参数曲面、多参数联合扰动、蒙特卡洛成交模拟。
- [ ] 自动调门槛 / 自动改参数 / 自动停开策略（当前一律要人点）。
- [ ] 审计结果 UI、完整权益持久化、检验段独立评分。
