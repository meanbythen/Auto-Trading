## 三、策略功能

### 3.1 多因子 CTA（`multi_factor`）

- [ ] 因子相关性检查（Spearman）与自动淘汰：权重现在固定，四个因子可能高度同向。
- [ ] 因子计算下沉到 `src/features`（先做搬家，不改分数）。

### 3.2 凯利手数

- [x] **分策略腿动态凯利 + 固定风险双保险**（49.39.0）：按每腿最近 50 笔净平仓统计，至少 30 笔启用四分之一凯利；样本不足退回固定风险，负期望拒开。固定风险始终是硬上限，每手风险已包含止损、乘数、开平费用和双边滑点，回测与实盘共用公式。
- [x] **组合级热度与在途风险预留（P2，49.40.0）**：组合检查改用「持仓到止损的最大亏损 ÷ 权益」，替换总手数敞口；开仓通过后先记在途预留，同轮其它品种一并计入；读持仓失败按开仓失败关闭，平仓不受影响。回测共享资金账同步按 `risk.portfolio.max_heat_pct` 累计拒开，并输出热度峰值。
- [x] **精简闸门（P3，49.40.0）**：回测开仓限制直接调用实盘同一个 `RiskGuardian.allow`，时间轴换成 K 线时间；`sizing_mode: fixed` 只作为策略上限，仍先按风险%和止损算仓再取小。
- [ ] **健康停开仿真 A/B**：ATR 硬暂停已按对照结论在 50.0.0 删除（112 笔样本次未触发），健康停开先保留。影子重放初步结果：112 笔样本停开 34 笔（26 个交易日）、这些交易合计约 -4 元，净影响 +4 元，接近中性。下一步用仿真账号分别设 `runtime.health_block_entry=false/true`，比较被停开次数与错过的盈亏，再决定是否删除。P2 热度对照用 `python tools/sim_p2_heat_compare.py --heat-pcts 1,2,3,5`。
- [ ] **组合相关性纳入热度预算**：当前热度只按止损风险累加，尚未按品种相关性折减。
- [ ] **保证金约束与热度合并预算**：保证金上限和热度上限仍分别判断，尚未统一成一个组合预算。

## 四、评估与回测

完整评估与四阶段规划见 [策略研究体系评估与全闭环方案.md](策略研究体系评估与全闭环方案.md)：单策略单品种链路已齐备，缺组合层与研究治理层。实施顺序与优先级见该文第 8 节，第一批只做指标补齐、试验留痕、稳健性报告与滑点校准，均不改交易链路。

- [ ] **组合回测**：多品种共享资金与保证金，输出组合权益、组合回撤、保证金峰值、品种贡献与相关性矩阵；交叉测试增加资金口径排名。
- [ ] **统计稳健性**：补 Sharpe/Sortino/Ulcer、bootstrap 置信区间、Deflated Sharpe、PBO，以及参数平原热力图与多参数联合扰动。
- [ ] **研究治理**：假设登记、失败实验库、决策日志、上线后变更冻结与再优化节奏。
- [ ] **执行校准**：用实盘滑点日志反推回测滑点与成交率；健康对照扩展到分品种/分时段、滑点与拒单率。
- [ ] **执行可行性与容量**：按成交量、时段、涨跌停核对单笔规模，给出资金放大 2/5/10 倍后的滑点与容量上限。
- [ ] **上线变更与再认证**：变更必须带回滚预案；按周期重跑冻结外验证，并核对手续费、保证金、合约乘数与交易时段变化。

回测–实盘一致性与策略档案的分阶段方案见 [系统评估升级/回测实盘一致性与评估体系升级方案.md](系统评估升级/回测实盘一致性与评估体系升级方案.md)。S1 镜像闸门已于 49.1.0 交付（默认关）；回测与实盘的口径差异已在 49.21.0 修正或标注；S2 滑点回流尚未开工。

评估体系（Calmar、最大连亏、回撤持续期、ADX 分组、滑点与扰动压力、优化拦截）已完成，下面是从当时的「本次不做」清单延续下来的：

- [x] **全参数曲面、多参数联合扰动、蒙特卡洛成交模拟**（50.1.0）：优化器 trials 可直接画两参数得分热力图并导出 CSV；单参数扰动之外增加前两个参数同时 ±10% 的四组角点；成交层蒙特卡洛在原有打乱/重抽之外，给每笔开平叠加执行滑点、延迟和可选部分成交，输出净盈亏与回撤分布，只供对照、不参与写入闸。
- [ ] **执行噪声校准**：成交层蒙特卡洛的默认噪声（每边 0.5±1 跳、0～0.5 跳延迟）是估值，需用实盘滑点日志和拒单记录反推；`exec_mc_partial_fill_prob` 有样本后再打开。
- [ ] 自动调门槛 / 自动改参数（当前一律要人点；自动停开已由 `runtime.health_block_entry` 覆盖，默认关）。
