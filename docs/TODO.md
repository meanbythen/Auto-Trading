## 三、策略功能

### 3.1 多因子 CTA（`multi_factor`）

- [ ] 因子相关性检查（Spearman）与自动淘汰：权重现在固定，四个因子可能高度同向。
- [ ] 因子计算下沉到 `src/features`（先做搬家，不改分数）。

### 3.2 凯利手数

- [ ] 用滚动窗口胜率替代手填胜率。
- [ ] 组合级相关性与保证金约束。
- [ ] 单笔风险封顶（当前默认每笔最多 2%，需要评估是否放宽到 3%）。

### 3.3 长线箱体突破（`swing_box`）

- [ ] 箱体中继加仓。
- [ ] 周线共振过滤。
- [ ] 长假前自动停手。
- [ ] 移仓换月时沿用策略止损（现在回测移仓会重置为新合约 2×ATR，见审阅报告 P2-22）。

### 3.4 以损定开（`liq_stop`）

- [ ] VPVR（成交量分布）作为止损聚集区的替代/补充。
- [ ] 多周期共振确认。
- [ ] 二次扫损后的再入场规则。

### 3.5 规则 DSL / 策略编辑器

- [ ] 涨跌停过滤与流动性过滤（属于引擎层，规则文件管不到）。
- [ ] 夜盘品种的夜盘平仓时间。
- [ ] ADX 算法与 tqsdk 原版对齐（当前口径不同，回测数字不能直接对比）。
- [ ] 加减仓、反手、分批止盈（DSL 目前明确不支持）。

### 3.6 研究工具

- [ ] 独立参数扫描脚本（不依赖界面）与分组筛选（按品种/时段/波动分组出报告）。
- [ ] 规律候选池与交叉测试的自动联动（扫出规律后自动跑对应策略组合）。
