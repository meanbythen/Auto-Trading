# 评估系统好坏的常用指标

升级规划（自评估打分、回测实盘差异、分阶段实施）见同目录 [回测实盘一致性与评估体系升级方案.md](回测实盘一致性与评估体系升级方案.md)。

我想知道我们这套交易系统回测和实盘交易的一致性，请结合程序现有的评估体系，参照系统评估目录的资料，再借鉴各种优秀系统再，一方面对程序自身的稳定性、实盘回测一致性等方面进行自评估，一方面对各个交易策略建立完整的评估体系。
> 这里的**系统**是广义系统（AI系统、业务系统、交易系统、信息系统都适用，区分不同维度）
## ✅ 1. 效果/能力类
1. **可信度（置信度、可靠性）**：输出结果真实、可复现，少幻觉、少错误，遇到不确定内容不会强行编造
2. **准确率 / 精确率 / 召回率 / F1**：分类、识别、检索类系统核心指标，判断对错、漏检误检
3. **有效性（达成目标能力）**：能不能完成预设任务，比如交易策略能不能达到预期盈亏逻辑、问答系统能不能解决问题
4. **鲁棒性（抗干扰）**：输入模糊、有错别字、异常输入、边界case时，系统不会直接崩溃或给出离谱结果
5. **泛化能力**：在没见过的新样本、新场景下依旧稳定工作，不是只能跑给定测试集

## ✅ 2. 性能&效率类
1. **延迟（响应时间）**：从发请求到返回结果耗时（日内交易系统是核心指标）
2. **吞吐量**：单位时间能处理多少请求/任务，高并发下能不能扛住
3. **资源消耗**：CPU、内存、显存、磁盘占用，成本开销
4. **执行速度**：批量任务、推演、回测的耗时

## ✅3. 稳定&可用类
1. **可用性SLA**：系统正常可用时间占比，宕机频率、故障时长
2. **容错性 & 故障恢复（灾备）**：局部报错能不能降级，故障后多久自动恢复
3. **可复现性**：相同输入+相同环境，多次运行得到一致结果（量化策略非常看重）

## ✅4. 安全、合规与伦理
1. **安全性**：防注入、防越权访问、数据防泄露，抵御攻击
2. **合规性**：符合监管、行业规范（尤其量化交易、金融系统）
3. **公平性 / 偏见控制**：输出不存在明显不合理偏置
4. **可解释性**：能不能解释得出结果的理由（黑盒程度，比如策略为什么触发开仓）

## ✅5. 用户&业务侧指标
1. **易用性**：上手门槛、交互体验，是否容易操作
2. **满意度 / 任务完成率**：使用者能不能靠系统完成目标
3. **收益&风险指标（金融/交易系统专属）**：夏普比率、最大回撤、胜率、盈亏比、卡尔玛比率等

### 快速区分小例子
- 可信度：系统会不会编造不存在的行情数据
- 可解释性：系统可以说明“本次开仓是ADX突破阈值+ATR试仓触发”
- 鲁棒性：突然收到脏K线数据，策略不会直接乱下单爆仓
