# 华泰穿透式测试：恢复后要做什么

连通恢复后，按这份清单做完、勾报告、把截图和 Word 一起发给客户经理审核。  
截图要求：**带时间戳**，或**电脑全屏**（右下角能看到本机时间）。

软件：运行页 → **仿真柜台测试**。  
账号建议：公用 `10001437`（指引里的测试账户1）。  
AppID：`client_AutoTrading_1.0`（日志里要能看见）。

---

## 一、报告封面怎么填（核对一遍）

| 栏 | 填什么 |
|----|--------|
| 系统名称 | Auto-Trading |
| 版本号 | 以窗口左上角为准（例如 4.0.1） |
| AppID | client_AutoTrading_1.0 |
| 连接模式 | 勾 **直连** |
| 测试账号 | 10001437（若用个人仿真就写个人号） |
| 交易信息系统 | 勾 **CTP** 仿真系统 |
| 测试时间 | 你这次重测的日期 |

电脑信息、提测方联系方式按你已填的保留即可。

## 五、最短操作顺序（怕漏项时按这个点）

1. 连接登录 → 截连通性（含账号、AppID）  
2. 买开 → 卖平 → 远价挂单再撤 → 截基础交易  
3. 断网再恢复 → 截断开与重连  
4. 多报几笔、撤几笔 → 截笔数；再报到预警 → 截预警；顺带截 yaml 阈值  
5. 错误合约 / 错误价位 / 超过手数 各点一次 → 截拦截  
6. 故意触发柜台拒单（资金/持仓/休盘）→ 截错误提示  
7. 暂停报单后再点开仓 → 截暂停  
8. 挂机满 10 分钟 → 截长时间日志  
9. 截 logs 路径 + IP/MAC  
10. 勾满报告 → 发出去审核
